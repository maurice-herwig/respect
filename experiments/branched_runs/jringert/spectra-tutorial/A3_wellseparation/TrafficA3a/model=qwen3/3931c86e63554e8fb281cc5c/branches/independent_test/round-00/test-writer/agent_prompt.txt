The environment is assumed to behave according to the following constraints. Additionally, infinitely often, it is not the case that cars are present at both intersections simultaneously; that is, the state where both `carA` and `carB` are true must be false infinitely often.

The system must satisfy the following guarantee. At all times, the lights for A and B must not be green simultaneously; specifically, it is never the case that both `greenA` and `greenB` are true.
