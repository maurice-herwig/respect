The Minepump specification defines a reactive control system where the environment provides sensor readings and the system controls a water pump. The environment controls two boolean inputs: `highwater`, which indicates if the water level is high, and `methane`, which indicates if methane gas is present. The system controls one boolean output: `pump`, which determines whether the pump is active.

The specification imposes the following assumption on the environment: at every step, if `methane` is false, then the `pump` must have been false in the previous step.

The system must satisfy the following guarantees regarding the next state of the `pump`:
1. At every step, if `methane` is true, then the `pump` must be false in the next step.
2. At every step, if `methane` is false and `highwater` is true, then the `pump` must be true in the next step.

These requirements ensure that the pump turns off whenever methane is detected and turns on whenever the water level is high provided no methane is present.
