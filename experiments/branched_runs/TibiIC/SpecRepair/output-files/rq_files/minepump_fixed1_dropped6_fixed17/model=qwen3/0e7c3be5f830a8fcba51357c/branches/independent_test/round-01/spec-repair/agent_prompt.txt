The system controls one boolean output: `pump`, which determines whether the pump is active.

2. At every step, if `methane` is false and `highwater` is true, then the `pump` must be true in the next step.

These requirements ensure that the pump turns off whenever methane is detected and turns on whenever the water level is high provided no methane is present.
