Use $respect-method-2.

The system controls two motor commands, `leftM` and `rightM`, which can be set to forward, backward, or stop. The environment provides a `distance` input, which is an integer between 0 and 100. 

The environment is assumed to provide a valid `distance` value. 

The system guarantees that whenever the `distance` is less than or equal to 20, it will not continue moving forward in the next state. Moving forward is defined as setting both `leftM` and `rightM` to forward. 

In other words, if the `distance` is 20 or less, the system must change its motor commands so that it is no longer moving forward at the next step.
