The system interacts with an environment that provides two inputs: `atStation` and `cargo`, which indicate whether the system is currently at a station and whether cargo is present, respectively. The system controls two outputs: `mot` (motion), which can be in one of three states (STOP, FWD, or BWD), and `lift`, which can be in one of two states (LIFT or DROP).

The environment is assumed to always eventually be at a station, as indicated by the `atStation` input becoming true infinitely often. Additionally, when the system is stopped, the environment's station position remains the same. The environment also behaves in a way that lifting the cargo clears the cargo sensor, dropping the cargo sets the cargo sensor, and backing up clears the cargo sensor.

The system guarantees that it will behave in accordance with these environmental assumptions. Specifically, the system ensures that when it lifts the cargo, the cargo sensor will be cleared in the next state, when it drops the cargo, the cargo sensor will be set in the next state, and when it backs up, the cargo sensor will be cleared in the next state. Furthermore, the system ensures that when it is stopped, the environment's station position remains the same in the next state. 

Note that `atStation` and `cargo` are environment-controlled inputs, while `mot` and `lift` are system-controlled outputs.
