When the robot is at the right edge (i.e., `robX` equals 4), the system must not move the robot right. Similarly, when the robot is at the top edge (i.e., `robY` equals 0), the system must not move the robot up, and when the robot is at the bottom edge (i.e., `robY` equals 4), the system must not move the robot down. These constraints must always hold, ensuring the robot remains within the specified grid boundaries.
