The system interacts with an environment that provides two input signals: a request signal (`req`) and a clear signal (`cl`). The system responds with two output signals: a grant signal (`gr`) and a validation signal (`val`).

The environment is assumed to never assert the clear signal (`cl`). Additionally, the environment is expected to periodically drop the request signal (`req`), and the clear signal (`cl`) should never be asserted at any point in time.

The system guarantees that whenever the clear signal (`cl`) is asserted, the validation signal (`val`) will be inactive. Furthermore, the system ensures that it will infinitely often grant the request (`gr`) and validate (`val`) simultaneously.

Note that the clear signal (`cl`) is assumed to be always inactive, which implies that the first guarantee may seem redundant, but it still defines the system's behavior in case the clear signal were to be asserted. The system's primary obligation is to periodically grant and validate, regardless of the environment's request signal.
