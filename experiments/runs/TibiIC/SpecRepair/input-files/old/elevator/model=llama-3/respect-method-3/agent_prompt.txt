The Elevator system interacts with its environment, which controls the current floor, indicated by one of the following values: LOWER, MIDDLE, UPPER, or NONE. The system, in turn, controls two outputs: the door motor (doorMot), which is a boolean value, and the elevator motor (elevMot), which can be in one of three states: moving forward (FWD), moving backward (BWD), or stopped (STOP).

Initially, the elevator motor must be in the STOP state. The system aims to eventually move the elevator forward (FWD) at some point. 

When the elevator reaches the LOWER floor, it must change direction to move forward (FWD). Conversely, when it reaches the UPPER floor, it must change direction to move backward (BWD).

The environment is assumed to ensure that whenever the elevator motor is stopped, the current floor is not NONE, meaning the elevator must be at a valid floor when it is not moving. 

These conditions collectively define the expected behavior of the Elevator system in response to the environment's control over the current floor.
