The Door system is a reactive system that interacts with its environment. The environment controls the following inputs: a bell being pressed, a bell ringing, a door being hit, and a knock sound being made. The system controls one output: whether the door is answered.

The environment is assumed to behave in the following ways: initially, the bell is not ringing, the door is not being hit, the bell is not being pressed, and no knock sound is being made. Additionally, the environment is assumed to always behave such that if the door is hit, the bell rings, and if the bell is pressed, the bell rings.

The system guarantees the following behavior: whenever the bell rings, the door will be answered, and whenever a knock sound is made, the door will be answered. Initially, the door is not answered. 

At all times, the system ensures that if the bell rings, the door is answered, and if a knock sound is made, the door is answered.
