The Minepump system is a reactive system that interacts with its environment, which controls the presence of high water and methane. The system controls the operation of a pump. 

The environment-controlled inputs are the presence of high water and methane. The system-controlled output is the state of the pump.

The environment is assumed to behave in the following ways: when the water is high and the pump is not running, it will not start the pump. Additionally, when methane is present, the environment will not start the pump if it was not already running. The environment will also not start the pump if the water is high, regardless of the current state of the water. Furthermore, if the water is high and methane is about to be present, the environment will not start the pump if it was not already running.

The system guarantees the following behavior: the pump will always be started at the next step. However, if methane is present, the pump will be stopped at the next step.

In summary, the system will always start the pump, unless methane is present, in which case it will stop the pump. The environment's behavior is restricted to not starting the pump under certain conditions, such as when the water is high or methane is present.
