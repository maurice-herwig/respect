The Minepump system interacts with an environment that controls two inputs: highwater and methane, which are boolean values indicating whether the water level is high and whether methane is present, respectively. The system controls one output: pump, a boolean value indicating whether the pump is active.

The environment is assumed to behave in such a way that if methane is not present, then the pump was not active in the previous state.

The system must satisfy two guarantees. Firstly, if methane is present, then either the pump must be active in the next state or the water level must not be high. Secondly, if methane is not present, then the pump must not be active in the next state.

In summary, the system must control the pump based on the presence of methane and the water level, while the environment controls the methane and highwater inputs, with certain restrictions on its behavior.
