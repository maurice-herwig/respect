The Minepump system is a reactive system that interacts with its environment, which controls the presence of high water and methane. The system controls the operation of a pump. 

The environment provides two inputs: highwater and methane, which indicate whether the water level is high and whether methane is present, respectively. The system has one output: pump, which indicates whether the pump is operating.

The environment is assumed to behave in a way that if the pump was not operating in the previous state and is still not operating in the current state, then it was also not operating in the state before the previous one.

The system must satisfy two guarantees. Firstly, if methane is present, then the pump must be turned on at the next state, unless the water level is not high. Secondly, if methane is not present, then the pump must be turned off at the next state. 

There are no explicitly stated initial conditions or liveness requirements for the system. The system's behavior is defined solely by the safety requirements specified in the guarantees, which dictate the next-state relationships based on the current state of the environment and the system.
