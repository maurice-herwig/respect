The Minepump system is a reactive system that interacts with its environment. The environment controls two inputs: `highwater` and `methane`, which indicate the presence of high water and methane, respectively. The system controls one output: `pump`, which represents the state of the pump.

The environment is assumed to behave in such a way that if the pump is off, it will remain off unless it was previously off. 

The system must guarantee two conditions. Firstly, if methane is detected, the pump must be turned on at the next opportunity. Secondly, if no methane is detected, the pump must be turned off at the next opportunity.

Note that the `highwater` input does not have any specified requirements or assumptions associated with it in this specification.
