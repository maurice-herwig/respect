The Minepump system is a reactive system that interacts with its environment. The environment controls two inputs: highwater and methane, which are boolean values indicating the presence of high water and methane, respectively. The system controls one output: pump, a boolean value indicating whether the pump is on or off.

The environment is assumed to behave in the following ways: if the pump was on in the previous state and is still on in the current state, then in the next state, there will be no high water. Additionally, if there was methane in the previous state, then in the current state, either there is no high water or there is no methane.

The system must satisfy the following guarantees: if the water is high, then in the next state, the pump must be either on or off. Furthermore, if there is methane, then in the next state, the pump must be off.

In summary, the Minepump system must control the pump based on the environment's highwater and methane inputs, while the environment is expected to behave according to certain rules regarding the presence of high water and methane when the pump is on or off.
