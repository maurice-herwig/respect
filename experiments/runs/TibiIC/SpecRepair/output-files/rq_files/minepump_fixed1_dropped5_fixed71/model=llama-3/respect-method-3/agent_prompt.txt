The Minepump system interacts with an environment that controls two inputs: highwater and methane. The system controls one output: pump. 

The environment is assumed to behave in a way that if the water is not high in the next state, then it will remain not high in the subsequent state, unless the pump is off.

The system must satisfy two guarantees. Firstly, if methane is present, then the pump must be turned on in the next state. Secondly, if methane is not present, then the pump must be turned off in the next state.

In essence, the system's pump output is directly controlled by the environment's methane input, with no explicit consideration for the highwater input in the system's guarantees. The highwater input is only relevant in the assumption about the environment's behavior.
