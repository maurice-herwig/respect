The Minepump system interacts with its environment, which controls two inputs: highwater and methane, indicating the presence of high water and methane, respectively. The system controls one output: pump, which represents the state of the pump.

The environment is assumed to behave in the following ways: if the pump is currently on and was also on in the previous state, then in the next state, there will be no high water. Additionally, the environment will not have both high water and methane present at the same time.

The system guarantees the following behavior: if there is high water, then in the next state, the pump will be on. Furthermore, if there is methane, then in the next state, the pump will be off. These guarantees ensure the system responds appropriately to the environmental conditions of high water and methane.
