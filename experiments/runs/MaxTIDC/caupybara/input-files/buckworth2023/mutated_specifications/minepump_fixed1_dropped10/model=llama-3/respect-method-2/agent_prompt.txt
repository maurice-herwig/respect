The Minepump system is a reactive system that interacts with its environment. The environment controls two inputs: highwater and methane, which indicate the presence of high water and methane, respectively. However, only the methane input is relevant to the system's behavior. The system controls one output: pump, which indicates whether the pump is active or not.

The environment is assumed to never activate the pump. 

The system must satisfy two guarantees. Firstly, if methane is present, then the pump must be activated in the next state. Secondly, if methane is not present, then the pump must not be activated in the next state. 

Note that the highwater input does not affect the system's behavior as specified. The system's behavior is solely determined by the presence or absence of methane.
