The system interacts with an environment that controls the robot's position, represented by coordinates `robX` and `robY`, within a 5x5 grid. The system determines the robot's movement, which can be in one of five directions: up, down, left, right, or staying in place.

The environment is assumed to start the robot at the origin (0, 0) of the grid. Additionally, whenever the system decides to move the robot up, the environment is assumed to update the robot's vertical position by decreasing its `robY` coordinate by 1.

The system guarantees that when the robot reaches the edge of the grid, it will not attempt to move outside the grid boundaries.
