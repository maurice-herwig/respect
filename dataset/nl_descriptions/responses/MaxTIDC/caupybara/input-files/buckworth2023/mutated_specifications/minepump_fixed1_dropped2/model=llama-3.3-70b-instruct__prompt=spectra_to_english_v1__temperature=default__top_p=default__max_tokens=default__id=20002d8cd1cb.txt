The Minepump system operates in an environment where two conditions are monitored: the presence of high water and the presence of methane. The system controls a pump. 

The environment determines the levels of high water and methane. The system must ensure that if methane is present, then either the pump will be activated in the next state or there is no high water. Additionally, if methane is not present, the system guarantees that the pump will not be activated in the next state.

It is assumed that the environment will not activate the pump if it was not activated in the previous state. 

Initially, there are no specified conditions. At all times, the system must adhere to the guarantees regarding the pump's activation based on the presence of methane and high water, given the environment's behavior.
