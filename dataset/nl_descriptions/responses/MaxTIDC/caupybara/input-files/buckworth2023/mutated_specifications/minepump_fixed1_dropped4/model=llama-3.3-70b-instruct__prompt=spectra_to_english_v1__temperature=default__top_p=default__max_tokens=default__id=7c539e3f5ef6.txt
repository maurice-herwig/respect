The Minepump system operates in an environment where two conditions are monitored: high water levels and the presence of methane. The system controls a pump. 

The environment provides input on whether the water level is high and whether methane is present. The system's output is the state of the pump, which can be either on or off.

It is assumed that the pump is initially off and remains off at all times, as per the environment's behavior.

The system must guarantee two conditions. Firstly, if methane is present, then the pump must be turned on at the next opportunity, unless the water level is not high. Secondly, the system must ensure that methane is never present.

At the start and at all times, these guarantees must hold, ensuring the system behaves correctly in response to the environment's conditions.
