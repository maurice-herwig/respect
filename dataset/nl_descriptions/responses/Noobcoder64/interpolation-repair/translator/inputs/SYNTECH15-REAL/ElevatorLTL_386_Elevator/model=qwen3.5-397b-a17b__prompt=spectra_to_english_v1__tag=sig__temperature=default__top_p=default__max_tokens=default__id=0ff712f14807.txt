

Specification name: Elevator

Environment variables:
- floor: {LOWER,MIDDLE,UPPER,NONE}

System variables:
- elevMot: {FWD, BWD, STOP}

**Environment Assumptions**
The environment must ensure that whenever the elevator motor is stopped (`elevMot=STOP`), the floor sensor does not report `NONE`.

**System Guarantees**
*Initial Condition:*
Initially, the elevator motor is set to `STOP`.

*Liveness Requirements:*
1. The elevator motor must be set to `FWD` infinitely often.
2. It must occur infinitely often that if the floor is `LOWER`, the elevator motor is set to `FWD`.
3. It must occur infinitely often that if the floor is `UPPER`, the elevator motor is set to `BWD`.
