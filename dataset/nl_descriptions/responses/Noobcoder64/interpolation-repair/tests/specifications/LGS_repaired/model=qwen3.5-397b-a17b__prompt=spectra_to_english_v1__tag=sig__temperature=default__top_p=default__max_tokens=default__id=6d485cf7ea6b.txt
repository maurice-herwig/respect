

Specification name: LGS

Environment variables:
- handle_up: boolean
- handle_down: boolean

System variables:
- gear_extended: boolean

**Requirements Description**

The LGS specification describes a reactive system that manages a gear extension mechanism based on environment-controlled handle inputs.

**Environment Assumptions**
The environment controls the boolean inputs `handle_up` and `handle_down`. The behavior of these inputs is restricted by the following constraints, which must hold at all times:
1. The inputs `handle_up` and `handle_down` must never both be true simultaneously.
2. The inputs `handle_up` and `handle_down` must never both be false simultaneously.
3. The specific state where `handle_up` is false and `handle_down` is true is prohibited.

**System Guarantees**
The system controls the boolean output `gear_extended`. The system must satisfy the following conditions globally:
1. Whenever `handle_down` is true, in the immediately following state, either `handle_down` becomes false or `gear_extended` becomes true.
2. Whenever `handle_up` is true, in the immediately following state, either `handle_up` becomes false or `gear_extended` becomes false.
