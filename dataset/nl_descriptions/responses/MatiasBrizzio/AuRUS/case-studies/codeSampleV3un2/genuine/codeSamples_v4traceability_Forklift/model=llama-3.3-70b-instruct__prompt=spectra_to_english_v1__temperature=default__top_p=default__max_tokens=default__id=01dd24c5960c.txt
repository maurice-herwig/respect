The Forklift system is a reactive system that interacts with its environment. The environment controls two inputs: an obstacle sensor that can be either BLOCKED or CLEAR, and an emergency stop signal emgOff. The system controls two outputs: the left motor direction (lMot) and the right motor direction (rMot), each of which can be set to STOP, FWD (forward), or BWD (backward).

The system must always ensure that both motors are stopped initially. At all times, the system must guarantee that if the obstacle is detected as BLOCKED, it will not move both motors forward simultaneously. Additionally, whenever the emergency stop signal emgOff is active, the system must stop both motors. The system must also ensure that it will infinitely often either move both motors forward or have the emergency stop signal active.

The environment is assumed to behave in certain ways. Specifically, if both motors are stopped, the obstacle detection will remain unchanged from one moment to the next. Furthermore, the environment is assumed to respond to the system's actions in a specific manner: whenever the system sets either motor to move backward, the environment will eventually respond by either clearing the obstacle or having both motors stopped.

In more detail, this response mechanism works as follows: once the system triggers a response by moving a motor backward, the environment will eventually respond, and once it has responded, it will remember this response until the trigger is deactivated. The environment will respond infinitely often, ensuring that the system's actions do not go unnoticed.
