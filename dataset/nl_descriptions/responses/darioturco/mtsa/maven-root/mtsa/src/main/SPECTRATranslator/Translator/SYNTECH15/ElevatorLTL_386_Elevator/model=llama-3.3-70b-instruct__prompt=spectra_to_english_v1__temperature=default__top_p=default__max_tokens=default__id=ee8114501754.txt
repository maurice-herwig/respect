The Elevator system is a reactive system that interacts with its environment, which controls the current floor location. The environment can be at one of four floors: LOWER, MIDDLE, UPPER, or NONE. The system controls the elevator's motor direction, which can be set to move forward (FWD), backward (BWD), or stop (STOP).

The environment is assumed to always have a valid floor location whenever the elevator is stopped, meaning the floor will never be NONE when the elevator motor is in the STOP state.

The system guarantees that it will start in a stopped state, with the elevator motor set to STOP. The system also aims to continuously move the elevator forward, as indicated by the goal that the elevator motor will eventually be set to FWD and remain so indefinitely.

Additionally, the system guarantees that it will change the elevator's direction based on the current floor location. Specifically, when the elevator reaches the LOWER floor, it will start moving forward (FWD), and when it reaches the UPPER floor, it will start moving backward (BWD). These direction changes will occur infinitely often, ensuring the elevator continuously moves between the floors.

In summary, the Elevator system is designed to start from a stopped state, continuously move the elevator forward, and change direction at the lower and upper floors, while assuming the environment provides a valid floor location when the elevator is stopped. The environment-controlled input is the current floor location, and the system-controlled output is the elevator's motor direction.
