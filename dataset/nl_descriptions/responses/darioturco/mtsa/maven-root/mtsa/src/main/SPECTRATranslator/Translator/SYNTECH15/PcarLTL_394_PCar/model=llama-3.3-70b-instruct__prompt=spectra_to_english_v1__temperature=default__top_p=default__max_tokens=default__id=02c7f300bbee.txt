The system, referred to as PCar, interacts with its environment through several variables. The environment controls the state of an obstacle, which can be either clear, blocked, or an object, and the state of a side sense, which can be clear, partially obstructed (P_O), or blocked. In response, the system controls the throttle, which can be set to forward (FWD), backward (BWD), or stop, and the steering, which can be set to right, left, or center.

The environment is assumed to behave in certain ways. Specifically, whenever the throttle is set to backward, the obstacle will be clear in the next state. Additionally, the environment is expected to respond to certain system actions: when the throttle is forward, the steering is centered, and the side sense is blocked, the side sense will eventually become clear.

The system must guarantee certain behaviors. If an obstacle is blocked, the system must not set the throttle to forward. When both the obstacle and the side sense are clear, the system must steer to the center. The system must also ensure that it will infinitely often move forward with the steering centered. Furthermore, if the obstacle is clear and the side sense is blocked, the system must not move forward while steering to the right.

Initially, there are no explicitly defined conditions. However, the system's safety and liveness requirements dictate its ongoing behavior. The system must always avoid moving forward when an obstacle is present and must steer to the center when both the obstacle and side sense are clear. The liveness requirement ensures that the system periodically moves forward with centered steering, indicating ongoing activity.
