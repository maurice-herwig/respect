

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

**Requirements Description**

This specification defines the behavior of a mine pump control system interacting with its environment. The environment controls the sensor inputs `highwater` and `methane`, while the system controls the output `pump`.

**Initial Conditions**
At the start of operation, the environment ensures that both the `highwater` level and the `methane` level are false. The system must initialize the `pump` to false.

**Environment Assumptions**
The environment behaves according to the following constraints:
1.  Whenever the `pump` was on in the previous step and remains on in the current step, the environment ensures that the `highwater` level becomes false in the next step.
2.  Always, if the `highwater` level is false, then either the `highwater` level is false or the `methane` level is false.

**System Guarantees**
The system must satisfy the following requirements whenever the environment satisfies its assumptions:
1.  Whenever the `highwater` level is true, the system ensures that either `methane` is detected immediately or the `pump` is turned on in the next step.
2.  Whenever `methane` is detected, the system ensures that the `pump` is turned off in the next step.
