

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system manages a pump based on environmental water and methane levels. Initially, the environment variables `highwater` and `methane` are false, and the system variable `pump` is false.

The environment behavior is restricted by the following assumptions:
- Always, if `pump` was true in the previous step and is true in the current step, then `highwater` must be false in the next step.
- Always, if `highwater` is false, then either `highwater` is false or `methane` is false.

The system must satisfy the following guarantees:
- Always, if `highwater` is true, then `pump` must be true in the next step.
- Always, if `methane` is true, then either `highwater` is true or `pump` must be false in the next step.
