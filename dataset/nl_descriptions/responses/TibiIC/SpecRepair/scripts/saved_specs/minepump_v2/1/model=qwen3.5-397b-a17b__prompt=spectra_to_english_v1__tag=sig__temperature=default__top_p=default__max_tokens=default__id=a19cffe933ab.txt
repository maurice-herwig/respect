

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump specification describes a reactive system that controls a pump based on environmental water and methane levels.

**Initial Conditions**
At the start of operation, the environment indicates that `highwater` is false and `methane` is false. The system initializes the `pump` to false.

**Environment Assumptions**
The environment behaves according to the following constraints:
1. Initially, both `highwater` and `methane` are false.
2. Globally, if the `pump` was true in the previous step and is true in the current step, then `highwater` must be false in the next step.
3. Globally, whenever `highwater` is false, it must be the case that either `highwater` is false or `methane` is false.

**System Guarantees**
The system must satisfy the following requirements:
1. Initially, the `pump` is false.
2. Globally, whenever `highwater` is true, the system ensures that either `highwater` is true or the `pump` becomes true in the next step.
3. Globally, whenever `methane` is true, the system ensures that the `pump` becomes false in the next step.
