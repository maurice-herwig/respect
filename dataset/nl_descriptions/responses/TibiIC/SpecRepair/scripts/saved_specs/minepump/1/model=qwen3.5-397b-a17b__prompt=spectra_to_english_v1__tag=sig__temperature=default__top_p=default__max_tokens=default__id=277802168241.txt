

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system controls a pump based on environmental inputs regarding water levels and methane presence.

**Initial Conditions**
At the beginning of operation, the environment ensures that `highwater` is false and `methane` is false. The system ensures that the `pump` is false.

**Environment Assumptions**
The environment is assumed to adhere to the following behaviors:
1.  Whenever the `pump` was true in the previous step and remains true in the current step, the environment ensures that `highwater` becomes false in the next step.
2.  Always, if `highwater` is false, then either `highwater` is false or `methane` is false.

**System Guarantees**
The system must satisfy the following requirements:
1.  Always, if `highwater` is true, then either `highwater` is true or the `pump` becomes true in the next step.
2.  Always, if `methane` is true, the `pump` must be false in the next step.
