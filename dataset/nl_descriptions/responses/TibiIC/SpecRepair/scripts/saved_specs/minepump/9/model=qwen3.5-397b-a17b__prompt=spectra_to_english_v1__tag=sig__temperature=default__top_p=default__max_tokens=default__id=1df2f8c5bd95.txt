

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system controls a pump based on water level and methane presence. Initially, the environment starts with `highwater` false and `methane` false, and the system starts with `pump` false.

The environment behaves according to the following assumptions. Always, if the pump was true in the previous step and remains true in the current step, the environment ensures that `highwater` becomes false in the next step. Additionally, it is always the case that if `highwater` is false, then either `highwater` is false or `methane` is false.

The system must satisfy the following guarantees. Always, if `highwater` is true, the system ensures that either `pump` is false or `pump` becomes true in the next step. Furthermore, always, if `methane` is true, the system ensures that either `highwater` is true or `pump` becomes false in the next step.
