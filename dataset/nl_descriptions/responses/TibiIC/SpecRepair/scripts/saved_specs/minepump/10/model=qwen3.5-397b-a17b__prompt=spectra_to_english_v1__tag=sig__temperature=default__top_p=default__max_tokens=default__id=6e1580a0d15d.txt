

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

**Initial Conditions**
At the start of operation, the environment variables `highwater` and `methane` are both false. The system variable `pump` is initially false.

**Environment Assumptions**
The environment is assumed to adhere to the following behavior constraints:
1. Always, if the `pump` was true in the previous step and remains true in the current step, then `highwater` must be false in the next step.
2. Always, if `highwater` is false, then either `highwater` is false or `methane` is false.

**System Guarantees**
The system must satisfy the following requirements:
1. Always, if `highwater` is true, then either `highwater` is true or the `pump` becomes true in the next step.
2. Always, if `methane` is true, then either `methane` is true or the `pump` becomes false in the next step.
