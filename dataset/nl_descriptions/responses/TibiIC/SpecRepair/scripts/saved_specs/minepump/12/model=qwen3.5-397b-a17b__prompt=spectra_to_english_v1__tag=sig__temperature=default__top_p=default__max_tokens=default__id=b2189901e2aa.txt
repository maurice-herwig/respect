

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

**Requirements Description**

The Minepump system controls a pump based on environmental inputs indicating water levels and methane presence. The variables `highwater` and `methane` are inputs controlled by the environment, while `pump` is an output controlled by the system.

**Initial Conditions**
At the start of operation, the environment signals `highwater` and `methane` are both false, and the system sets the `pump` to false.

**Environment Assumptions**
The environment is assumed to adhere to the following constraints:
1. Whenever the `pump` is true, either `highwater` is false or `methane` is false.
2. If the `pump` was true in the previous step and is true in the current step, then `highwater` must be false in the next step.

**System Guarantees**
The system must satisfy the following requirements:
1. Whenever `methane` is true, the `pump` must be false in the next step.
2. Whenever `highwater` is true, either `highwater` remains true in the next step, or the `pump` becomes true in the next step.
