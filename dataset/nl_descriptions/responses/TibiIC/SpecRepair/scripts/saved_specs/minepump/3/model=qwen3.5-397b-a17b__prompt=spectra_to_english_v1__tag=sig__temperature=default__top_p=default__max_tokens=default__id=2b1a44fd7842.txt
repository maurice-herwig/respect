

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The system controls the `pump` output based on the `highwater` and `methane` inputs provided by the environment.

**Initial Conditions**
At the start of operation, the environment signals `highwater` and `methane` are both false. The system initializes with the `pump` set to false.

**Environment Assumptions**
The environment behavior is restricted by the following rules:
1. Whenever the `pump` was true in the previous step and remains true in the current step, the environment ensures that `highwater` will be false in the next step.
2. At every step, if `highwater` is false, then either `highwater` is false or `methane` is false.

**System Guarantees**
The system must satisfy the following requirements:
1. Whenever `highwater` is true, the system must ensure that either `methane` is true or the `pump` becomes true in the next step.
2. Whenever `methane` is true, the system must ensure that either `methane` is true or the `pump` becomes false in the next step.
