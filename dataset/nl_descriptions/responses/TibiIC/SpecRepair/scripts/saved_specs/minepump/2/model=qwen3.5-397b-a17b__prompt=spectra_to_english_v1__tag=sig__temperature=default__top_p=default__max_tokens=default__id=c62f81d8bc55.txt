

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

**Initial Conditions**
At the start of operation, the environment signals indicate that the water level is not high and there is no methane present. Simultaneously, the system initializes with the pump turned off.

**Environment Assumptions**
The environment is assumed to adhere to the following constraints during operation:
1. If the pump output was true in the previous step and remains true in the current step, the environment must ensure the highwater input is false in the next step.
2. At every step, if the highwater input is false, then either the highwater input is false or the methane input is false.

**System Guarantees**
The system must satisfy the following requirements at every step:
1. If the highwater input is true, then either the highwater input is true or the system ensures the pump output is true in the next step.
2. If the methane input is true, then either the pump output is currently true or the system ensures the pump output is false in the next step.
