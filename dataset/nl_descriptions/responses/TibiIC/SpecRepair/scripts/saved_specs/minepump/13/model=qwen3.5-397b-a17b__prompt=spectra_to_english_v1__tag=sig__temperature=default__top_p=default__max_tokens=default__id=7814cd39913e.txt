

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system manages a pump based on environmental inputs regarding water and methane levels. The environment controls the `highwater` and `methane` inputs, while the system controls the `pump` output.

Initially, the environment sets both `highwater` and `methane` to false, and the system sets `pump` to false.

The environment must adhere to the following constraints regarding its inputs:
- If the `pump` was true in the previous step and remains true in the current step, the environment must ensure `highwater` becomes false in the next step.
- Whenever the `pump` is true, at least one of `highwater` or `methane` must be false.

The system must satisfy the following behavioral requirements:
- Whenever `highwater` is true, either `methane` must also be true, or the system must set `pump` to true in the next step.
- Whenever `methane` is true, the system must set `pump` to false in the next step.
