

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

**Initial Conditions**
At the beginning of operation, the environment variables `highwater` and `methane` are both false. The system variable `pump` is initially false.

**Environment Assumptions**
The environment behavior is restricted by the following rules:
1. Whenever `highwater` is false, it must be the case that either `highwater` is false or `methane` is false.
2. If the `pump` was true in the previous step and remains true in the current step, the environment ensures that `highwater` becomes false in the next step.

**System Guarantees**
The system must satisfy the following requirements regarding the `pump` output:
1. Whenever `highwater` is true, either `methane` is true or the `pump` must be set to true in the next step.
2. Whenever `methane` is true, either `highwater` is true or the `pump` must be set to false in the next step.
