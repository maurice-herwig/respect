**Requirements for the Minepump System**

The minepump system controls a pump in response to two environment-controlled signals: **highwater** and **methane**. The environment determines when these signals are active, while the system controls the **pump** output.

### **Initial Conditions**
- At startup, the environment ensures **highwater** and **methane** are both *false*.
- The system initializes the **pump** to *false* (off).

### **Assumptions on the Environment**
1. If the pump has been running continuously (i.e., **pump** was *true* in the previous state and remains *true* in the current state), the environment guarantees that **highwater** will become *false* in the next state.
2. The environment ensures that whenever the pump is *on*, at least one of the following must hold:
   - **highwater** is *false*, or
   - **methane** is *false*.

### **System Guarantees**
1. If **highwater** becomes *true*, the pump must either:
   - Remain *off* in the current state, or
   - Turn *on* in the next state.
2. If **methane** becomes *true*, the pump must turn *off* in the next state.

The system must adhere to these guarantees whenever the environment satisfies the given assumptions.
