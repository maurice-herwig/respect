

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system controls a pump based on environmental water and methane levels. Initially, the environment variables `highwater` and `methane` are both false, and the system variable `pump` is false.

The environment is assumed to behave according to the following constraints. Always, if the pump was true in the previous step and is true in the current step, then `highwater` will be false in the next step. Additionally, always, if `highwater` is false, then either `highwater` is false or `methane` is false.

The system must satisfy the following guarantees. Always, if `highwater` is true, then either the `pump` is currently false or it will become true in the next step. Always, if `methane` is true, then either the `pump` is currently true or it will become false in the next step.
