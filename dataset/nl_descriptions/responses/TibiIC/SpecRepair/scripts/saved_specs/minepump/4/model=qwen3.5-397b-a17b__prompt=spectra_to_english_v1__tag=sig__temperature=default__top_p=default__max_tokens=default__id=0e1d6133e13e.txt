

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system manages a pump based on environmental inputs regarding water levels and methane presence. The environment controls the `highwater` and `methane` signals, while the system controls the `pump` output.

**Initial Conditions**
At the start of operation, the environment indicates that `highwater` is false and `methane` is false. The system initializes with the `pump` set to false.

**Environment Assumptions**
The environment adheres to the following constraints:
1. If the `pump` was true in the previous step and remains true in the current step, then `highwater` must be false in the next step.
2. Always, if `highwater` is false, then either `highwater` is false or `methane` is false.

**System Guarantees**
The system must satisfy the following requirements:
1. Whenever `highwater` is true, either `methane` is currently true or the system must set `pump` to true in the next step.
2. Whenever `methane` is true, either the `pump` is currently true or the system must set `pump` to false in the next step.
