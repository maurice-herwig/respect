The Minepump system is a reactive system that interacts with its environment, which controls the presence of high water and methane. The system controls a pump. 

Initially, the environment is assumed to have no high water and no methane, and the system's pump is initially off.

The environment is assumed to behave in such a way that if the pump was previously on and is currently on, then in the next state, there will be no high water. Additionally, the environment is assumed to ensure that if there is no high water, then either there will still be no high water or there will be no methane in the next state.

The system guarantees that if high water is present, then either methane is present or the pump will be turned on in the next state. Furthermore, the system guarantees that if methane is present, then the pump will be turned off in the next state.

In this system, the environment-controlled inputs are the presence of high water and methane, while the system-controlled output is the state of the pump. The system's behavior is constrained by the assumptions on the environment, and it must satisfy the specified guarantees to ensure correct operation.
