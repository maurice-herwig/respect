

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

**Initial Conditions**
At the start of operation, the environment signals indicate no high water and no methane. The system initializes with the pump off.

**Environment Assumptions**
The environment behavior is constrained by the following rules. Whenever the pump is on, the environment must ensure that either there is no high water or there is no methane. Additionally, if the pump remains on for two consecutive steps (being on in both the previous step and the current step), the environment must ensure that the high water signal becomes false in the following step.

**System Guarantees**
The system must satisfy the following requirements. Whenever methane is detected, the system must ensure the pump is off in the next step. Whenever there is high water, the system must ensure that either the pump is currently off or it will be on in the next step.
