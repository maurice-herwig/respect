

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system controls the `pump` output based on the `highwater` and `methane` inputs provided by the environment. Initially, the environment sets both `highwater` and `methane` to false, and the system sets `pump` to false.

The environment is assumed to adhere to specific constraints regarding the interaction with the system. If the `pump` is true in the previous state and remains true in the current state, the environment must ensure that `highwater` becomes false in the next state. Additionally, whenever the `pump` is true, the environment ensures that either `highwater` is false or `methane` is false.

The system must satisfy the following guarantees. Always, if `highwater` is true, then either `methane` is true or the system must set `pump` to true in the next state. Furthermore, always, if `methane` is true, the system must set `pump` to false in the next state.
