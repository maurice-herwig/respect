

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system manages a pump based on environmental sensors indicating water levels and methane presence. The environment controls the boolean inputs `highwater` and `methane`, while the system controls the boolean output `pump`.

Initially, the environment signals that neither high water nor methane is present, and the system starts with the pump turned off.

Regarding system behavior, whenever the `highwater` input is true, the system must turn the `pump` on in the next step. Additionally, if the `methane` input is true, the system must ensure the `pump` is off either in the current step or in the next step.

The environment operates under specific constraints. If the `pump` has been on continuously for the previous step and the current step, the environment must ensure the `highwater` input becomes false in the next step. Furthermore, whenever the `pump` is on, the environment ensures that either the `highwater` input is false or the `methane` input is false.
