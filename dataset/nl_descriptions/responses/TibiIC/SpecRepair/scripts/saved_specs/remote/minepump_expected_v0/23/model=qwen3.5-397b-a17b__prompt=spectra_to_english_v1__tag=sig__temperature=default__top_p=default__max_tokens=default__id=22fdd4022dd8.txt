

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

Requirements Description

Initial Conditions
At the start of the system operation, the environment must indicate that both highwater and methane are false. The system must initialize with the pump set to false.

Environment Assumptions
The environment is constrained by the following behavior:
- If the pump is on in the current step and was also on in the previous step, the environment must ensure that highwater becomes false in the next step.

System Guarantees
The system must satisfy the following requirements whenever the environment satisfies its assumptions:
- Whenever highwater is true, the system must set pump to true in the next step.
- Whenever methane is true, the system must ensure that at least one of the following conditions holds: highwater is true, pump is currently false, or pump will be false in the next step.
