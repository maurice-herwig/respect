

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The system controls a pump based on environmental water and methane levels. Initially, the environment variables `highwater` and `methane` are both false, and the system variable `pump` is false.

Regarding the environment behavior, the following assumptions hold at all times. If `pump` was true in the previous step and remains true in the current step, then `highwater` must be false in the next step. Additionally, at all times, if `highwater` is false, then either `highwater` is false or `methane` is false.

Regarding the system behavior, the following guarantees must be satisfied at all times. If `highwater` is true, then either `methane` is true or the system must set `pump` to true in the next step. If `methane` is true, then either `pump` is false or the system must set `pump` to false in the next step.
