

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system manages a pump based on environmental sensors for water levels and methane gas. The environment controls the `highwater` and `methane` inputs, while the system controls the `pump` output.

Initially, the environment starts with both `highwater` and `methane` set to false. The system starts with the `pump` set to false.

The environment must adhere to specific behavioral assumptions. At every step, if the `highwater` level is false, then either `highwater` remains false or `methane` is false. Additionally, if the `pump` was true in the previous step and is true in the current step, the environment must ensure that `highwater` becomes false in the next step.

The system must satisfy the following guarantees. At every step, if `highwater` is true, the system must ensure the `pump` is true in the next step. Furthermore, at every step, if `methane` is true, then either the `pump` is currently true or the system must ensure the `pump` becomes false in the next step.
