

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system manages a pump based on environmental conditions. The variables `highwater` and `methane` are inputs controlled by the environment, while `pump` is an output controlled by the system.

**Initial Conditions**
At the start of operation, the environment sets `highwater` to false and `methane` to false. The system initializes with `pump` set to false.

**Environment Assumptions**
The environment behaves according to the following constraints:
1. Always, if `pump` was true in the previous step and is true in the current step, then `highwater` must be false in the next step.
2. Always, if `pump` is true, then either `highwater` is false or `methane` is false.

**System Guarantees**
The system must satisfy the following requirements:
1. Always, if `highwater` is true, then either `pump` is false or `pump` will be true in the next step.
2. Always, if `methane` is true, then either `methane` is true or `pump` will be false in the next step.
