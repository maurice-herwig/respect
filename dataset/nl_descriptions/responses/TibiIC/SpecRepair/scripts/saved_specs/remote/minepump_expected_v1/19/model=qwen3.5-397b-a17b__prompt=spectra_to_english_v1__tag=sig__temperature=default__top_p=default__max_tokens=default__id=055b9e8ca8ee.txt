

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

**Requirements Description**

The system controls a pump based on environmental water levels and methane presence.

**Initial Conditions**
At the start of operation, the high water level is false, the methane level is false, and the pump is off.

**Environment Assumptions**
The environment behaves according to the following constraints:
1. If the pump remains on for two consecutive steps (the previous step and the current step), the high water level must become false in the following step.
2. Whenever the pump is on, it is never the case that both high water and methane are true simultaneously. Specifically, if the pump is on, either the high water level is false or the methane level is false.

**System Guarantees**
The system must satisfy the following behaviors:
1. Whenever high water is detected, if the pump is currently on, it must remain on in the next step.
2. Whenever methane is detected, if the pump is currently on, it must turn off in the next step.
