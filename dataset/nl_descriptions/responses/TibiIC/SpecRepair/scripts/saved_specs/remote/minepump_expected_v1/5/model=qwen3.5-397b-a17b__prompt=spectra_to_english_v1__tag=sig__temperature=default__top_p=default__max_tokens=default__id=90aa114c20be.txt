

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system controls a pump based on environmental water and methane levels. The environment provides inputs indicating whether the water level is high (`highwater`) and whether methane is present (`methane`). The system controls the output `pump`, which indicates whether the pump is active.

**Initial Conditions**
At the start of operation, the environment ensures that both `highwater` and `methane` are false. The system ensures that the `pump` is initially false.

**Environment Assumptions**
The environment behaves according to the following constraints:
1. If the `pump` was true in the previous step and is true in the current step, the environment ensures that `highwater` becomes false in the next step.
2. Whenever `highwater` is false, the environment ensures that either `highwater` is false or `methane` is false at that time.

**System Guarantees**
The system must satisfy the following requirements:
1. Whenever `highwater` is true, either the `pump` is currently false or it becomes true in the next step.
2. Whenever `methane` is true, either `methane` remains true in the next step or the `pump` becomes false in the next step.
