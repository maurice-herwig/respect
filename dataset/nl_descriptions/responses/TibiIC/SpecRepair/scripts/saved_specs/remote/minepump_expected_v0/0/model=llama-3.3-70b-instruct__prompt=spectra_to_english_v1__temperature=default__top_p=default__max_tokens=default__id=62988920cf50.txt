Additionally, the environment is assumed to maintain a condition where if there is no high water, then either there will still be no high water or there will be no methane in the next state.

The system must satisfy two main guarantees. Firstly, if high water is present, then the system must ensure that if methane is also present, the pump will be turned on in the next state. Secondly, if methane is present, then the system must turn off the pump in the next state.

In summary, the system's pump is controlled based on the environment's conditions of high water and methane, with specific rules governing when the pump should be turned on or off to ensure safe operation. The environment's behavior is restricted by assumptions that dictate how the water level and methane presence change over time.
