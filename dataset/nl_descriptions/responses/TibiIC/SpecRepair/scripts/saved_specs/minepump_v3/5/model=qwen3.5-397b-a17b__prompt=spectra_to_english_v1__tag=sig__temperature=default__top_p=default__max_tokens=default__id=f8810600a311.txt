

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump specification defines the behavior of a reactive system controlling a pump based on environmental signals. The environment controls the boolean inputs `highwater` and `methane`, while the system controls the boolean output `pump`.

Initially, the environment signals `highwater` and `methane` are both false, and the system output `pump` is false.

The environment behavior is restricted by the following assumptions. Whenever the pump is active, the environment ensures that either `highwater` is false or `methane` is false. Additionally, if the pump has been active for two consecutive steps (the previous step and the current step), the environment must ensure that `highwater` becomes false in the next step.

The system must satisfy the following guarantees. Always, if the `methane` signal is active, the system must ensure the `pump` is inactive in the next step. Furthermore, the system satisfies the requirement that whenever `highwater` is active, either `highwater` is active or the `pump` becomes active in the next step.
