

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system controls a pump based on environmental water and methane levels. Initially, the environment signals indicate that the water level is not high and methane is not detected. The system starts with the pump turned off.

Regarding environmental behavior, it is assumed that at all times, if the highwater signal is false, then either the highwater signal is false or the methane signal is false. Additionally, if the pump has been on continuously (true in the previous step and true in the current step), the environment ensures that the highwater signal becomes false in the next step.

The system must satisfy the following guarantees. Whenever the highwater level is high, the system ensures that either the pump is currently off, or it will be on in the next step. Furthermore, whenever methane is detected, the system ensures that the pump is off in the next step.
