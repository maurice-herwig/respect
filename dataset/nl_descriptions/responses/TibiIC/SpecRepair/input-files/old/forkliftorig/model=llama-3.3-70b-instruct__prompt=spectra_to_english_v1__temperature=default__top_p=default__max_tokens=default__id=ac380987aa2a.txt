The system, a fork lift, interacts with its environment, which controls the distance between the fork lift and an object, either far or close. The system controls its own commands: lift, drop, go, or idle.

The environment is assumed to behave in the following ways: 
- If the fork lift is idle and the distance is far, the distance will remain far in the next state.
- If the fork lift is idle and the distance is close, the distance will remain close in the next state.
- If the command is to go, the distance will become close in the next state.
- If the distance is close and the command is not to lift, the distance will remain close in the next state.
- If the distance is close and the command is to lift, the distance will not be close in the next state.

The system guarantees the following behavior: 
- The initial command is to lift.
- If the distance is far, the system will not drop in the next state.
- If the distance is close, the system will not go in the next state.

Note that the system-controlled outputs are the commands (lift, drop, go, idle), and the environment-controlled input is the distance (far or close).
