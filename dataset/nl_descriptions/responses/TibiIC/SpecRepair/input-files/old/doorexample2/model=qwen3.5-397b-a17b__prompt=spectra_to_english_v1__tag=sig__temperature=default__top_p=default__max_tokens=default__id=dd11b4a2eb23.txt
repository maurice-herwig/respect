

Specification name: Door2

Environment variables:
- onebellpressed: boolean
- onebellrings: boolean
- onedoorhit: boolean
- oneknocksound: boolean
- twobellpressed: boolean
- twobellrings: boolean
- twodoorhit: boolean
- twoknocksound: boolean

System variables:
- onedooranswered: boolean
- twodooranswered: boolean

The system manages two distinct door answering mechanisms, referred to as "one" and "two". The environment provides input signals indicating bell presses, bell rings, door hits, and knock sounds for each mechanism. The system controls the output signals indicating whether each door is answered.

Initially, all environment variables are false. Additionally, the system starts with both `onedooranswered` and `twodooranswered` set to false.

Throughout operation, the environment behavior is constrained by the following assumptions. Whenever `onedoorhit` is true, `onebellrings` must also be true. Whenever `onebellpressed` is true, `onebellrings` must also be true. For the second mechanism, whenever `twobellpressed` is true, `twobellrings` must also be true. Furthermore, whenever `twodoorhit` is true, `twoknocksound` must also be true.

The system must satisfy the following guarantees. Whenever `onebellrings` is true, the system must set `onedooranswered` to true. Similarly, whenever `oneknocksound` is true, the system must set `onedooranswered` to true. For the second mechanism, whenever `twobellrings` is true, the system must set `twodooranswered` to true. Likewise, whenever `twoknocksound` is true, the system must set `twodooranswered` to true.
