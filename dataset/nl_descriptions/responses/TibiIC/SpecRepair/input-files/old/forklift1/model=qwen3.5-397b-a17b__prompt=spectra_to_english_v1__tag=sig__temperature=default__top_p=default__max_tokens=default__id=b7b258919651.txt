

Specification name: ForkLift1

Environment variables:
- fardistance: boolean

System variables:
- liftcommand: boolean
- dropcommand: boolean
- gocommand: boolean
- idlecommand: boolean

**Requirements Description**

This specification defines the behavior of a fork lift control system. The environment provides the status of the fork distance, while the system issues control commands.

**Environment Assumptions**
The environment controls the variable `fardistance` and must adhere to the following constraints regarding its behavior:
1.  **Idle Stability:** If the system sets `idlecommand` to true, the value of `fardistance` must remain unchanged in the next step.
2.  **Go Command Precondition:** Whenever the system sets `gocommand` to true, the current value of `fardistance` must be false.
3.  **Lift Command Effect:** If `fardistance` is currently false:
    *   If the system does not set `liftcommand` to true, `fardistance` must remain false in the next step.
    *   If the system sets `liftcommand` to true, `fardistance` must become true in the next step.

**System Guarantees**
The system controls the variables `liftcommand`, `dropcommand`, `gocommand`, and `idlecommand`. The system must satisfy the following requirements:
1.  **Initial Condition:** Initially, `liftcommand` must be true.
2.  **Safety Constraints:**
    *   Whenever `fardistance` is true, the system must ensure `dropcommand` is false in the next step.
    *   Whenever `fardistance` is false, the system must ensure `gocommand` is false in the next step.
