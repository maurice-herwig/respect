

Specification name: Door

Environment variables:
- bellpressed: boolean
- bellrings: boolean
- doorhit: boolean
- knocksound: boolean

System variables:
- dooranswered: boolean

The system controls the `dooranswered` variable based on inputs from the environment. At the initial state, the system variable `dooranswered` is false. Simultaneously, the environment variables `bellrings`, `doorhit`, `bellpressed`, and `knocksound` are all false.

Throughout operation, the environment adheres to specific constraints. Whenever `doorhit` is true, `bellrings` must also be true. Similarly, whenever `bellpressed` is true, `bellrings` must also be true.

The system must satisfy the following guarantees at all times. Whenever `bellrings` is true, the system must ensure `dooranswered` is true. Additionally, whenever `knocksound` is true, the system must ensure `dooranswered` is true.
