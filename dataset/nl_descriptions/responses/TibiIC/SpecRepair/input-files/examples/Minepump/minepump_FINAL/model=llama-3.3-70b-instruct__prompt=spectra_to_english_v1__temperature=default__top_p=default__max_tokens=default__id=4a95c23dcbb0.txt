The Minepump system is designed to interact with an environment that provides two input signals: `highwater` and `methane`, indicating the presence of high water and methane, respectively. The system controls one output, `pump`, which represents the state of a pump.

Initially, the environment is assumed to be in a safe state, with no high water and no methane present. In this initial state, the pump is guaranteed to be off.

The system is required to behave as follows: if high water is detected and there is no methane, the pump must be turned on at the next step. Conversely, if methane is detected, the pump must be turned off at the next step.

The environment is assumed to behave in a way that, if the pump is currently on and was also on in the previous step, the high water condition will be resolved at the next step.

In summary, the system must control the pump based on the environmental conditions, prioritizing safety by avoiding operation in the presence of methane and ensuring the pump is on when high water is detected without methane. The environment is expected to provide input signals that allow the system to operate effectively, with the pump's state influencing the resolution of the high water condition.
