

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system controls a pump based on environmental water and methane levels. At the start of operation, the environment indicates that `highwater` is false and `methane` is false. The system initializes with the `pump` set to false.

The environment adheres to specific constraints regarding the sensor inputs. It is always the case that `highwater` and `methane` are not true simultaneously; at least one must be false. Additionally, the environment reflects the physical effect of the pump: if the `pump` was true in the previous step and remains true in the current step, the environment ensures that `highwater` becomes false in the next step.

The system must satisfy specific reaction rules to ensure safety and functionality. Whenever `highwater` is true, the system must set `pump` to true in the next step. Conversely, whenever `methane` is true, the system must set `pump` to false in the next step.
