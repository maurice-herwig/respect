

Specification name: simpletest

Environment variables:
- input1: boolean
- input2: boolean

System variables:
- output1: boolean
- output2: boolean

The `simpletest` specification defines a reactive system where the environment provides boolean inputs and the system produces boolean outputs. The environment controls `input1` and `input2`, while the system controls `output1` and `output2`.

The environment is assumed to satisfy two conditions. First, `input1` must be true at all times throughout the execution. Second, `input2` must be true infinitely often over the course of operation.

Provided the environment satisfies these assumptions, the system must guarantee two conditions. The system must ensure that `output1` is true at all times. Additionally, the system must ensure that `output2` is true at all times.
