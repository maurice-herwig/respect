**Requirements Description for `simpletest` Reactive System**

This system interacts with its environment through two boolean inputs and produces two boolean outputs. The environment controls the inputs, while the system controls the outputs.

**Environment Inputs:**
- `input1`: A boolean value provided by the environment.
- `input2`: Another boolean value provided by the environment.

**Assumptions on the Environment:**
1. The environment will *always* set `input1` to `true` (i.e., it must hold continuously without interruption).
2. The environment will set `input2` to `true` *infinitely often* (i.e., no matter how long the system runs, there must be future points where `input2` is `true`).

**System Outputs:**
- `output1`: A boolean value produced by the system.
- `output2`: Another boolean value produced by the system.

**Guarantees from the System:**
1. The system *always* sets `output1` to `true` (i.e., it must hold continuously under the given assumptions).
2. The system *always* sets `output2` to `true` (i.e., it must hold continuously under the given assumptions).

No initial conditions, next-state rules, or other temporal behaviors are specified for this system. The guarantees hold as long as the environment satisfies its assumptions.
