

Specification name: Door

Environment variables:
- bellpressed: boolean
- bellrings: boolean
- doorhit: boolean
- knocksound: boolean

System variables:
- dooranswered: boolean

The Door system controls the `dooranswered` variable based on environmental inputs. Initially, the system sets `dooranswered` to false. The environment starts with `bellpressed`, `bellrings`, `doorhit`, and `knocksound` all set to false.

The environment behavior is constrained such that whenever `bellpressed` is true, `bellrings` must also be true. Similarly, whenever `doorhit` is true, `knocksound` must also be true.

The system must satisfy the following requirements: whenever `bellrings` is true, `dooranswered` must be true. Additionally, whenever `knocksound` is true, `dooranswered` must be true.
