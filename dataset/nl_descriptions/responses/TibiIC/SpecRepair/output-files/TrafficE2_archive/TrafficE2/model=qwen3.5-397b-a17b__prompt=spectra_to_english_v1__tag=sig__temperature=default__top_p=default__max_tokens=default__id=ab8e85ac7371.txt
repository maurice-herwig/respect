

Specification name: TrafficE2

Environment variables:
- carA: boolean
- carB: boolean
- emergency: boolean

System variables:
- greenA: boolean
- greenB: boolean

This specification defines a reactive traffic light controller for two lanes, managed by the system, with car presence and emergency signals managed by the environment.

**Environment Assumptions**
The environment guarantees that carA is true infinitely often and carB is true infinitely often. The emergency signal is guaranteed to be false infinitely often. The environment also adheres to specific car movement rules: if carA is true and greenA is false, carA remains true in the next step. If carA is true and greenA is true, carA becomes false in the next step. Identical behavior applies to lane B: if carB is true and greenB is false, carB remains true in the next step; if carB is true and greenB is true, carB becomes false in the next step.

**System Guarantees**
The system must ensure that greenA and greenB are never true at the same time. If emergency is true, both greenA and greenB must be false. Additionally, the system must ensure that greenA becomes true infinitely often and greenB becomes true infinitely often.
