

Specification name: Door

Environment variables:
- bellpressed: boolean
- bellrings: boolean
- doorhit: boolean
- knocksound: boolean

System variables:
- dooranswered: boolean

**Requirements Description**

This specification defines the behavior of a door system interacting with an environment. The environment provides input signals regarding door activity, and the system controls whether the door is answered.

**Initial Conditions**
At the start of operation, the system variable `dooranswered` is initialized to false. Simultaneously, all environment variables (`bellpressed`, `bellrings`, `doorhit`, and `knocksound`) are initialized to false.

**Environment Assumptions**
The environment is expected to adhere to the following constraints throughout operation:
- Whenever `doorhit` is true, `bellrings` must also be true.
- Whenever `bellpressed` is true, `bellrings` must also be true.

**System Guarantees**
The system must satisfy the following requirements at all times:
- If `bellrings` is true, then `dooranswered` must be true.
- If `knocksound` is true, then `dooranswered` must be true.
