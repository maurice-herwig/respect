

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system controls a pump based on environmental inputs regarding water levels and methane presence. The environment provides the boolean inputs `highwater` and `methane`, while the system controls the boolean output `pump`.

The environment is assumed to satisfy the following condition: always, if `highwater` is true and `highwater` is false, then either `highwater` becomes false in the next step or the `pump` was false in the previous step.

The system must satisfy the following guarantees regarding its behavior. Always, if `methane` is false and `highwater` is true, then the `pump` must be true in the next step. Additionally, always, if `methane` is true, then the `pump` must be false in the next step. These requirements ensure that the pump activates when water is high and methane is absent, and deactivates when methane is present.
