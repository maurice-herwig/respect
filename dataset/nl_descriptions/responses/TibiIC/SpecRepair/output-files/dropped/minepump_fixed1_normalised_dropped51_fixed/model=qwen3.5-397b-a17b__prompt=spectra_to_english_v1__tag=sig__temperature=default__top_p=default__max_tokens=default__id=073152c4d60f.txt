

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system controls the pump variable based on the environmental inputs highwater and methane. The following requirements describe the assumed behavior of the environment and the guaranteed behavior of the system throughout operation.

Regarding the environment, it is assumed that at any step, if the water level is high (highwater is true) and the pump is active (pump is true), then either the water level will not be high in the next step (next highwater is false) or the pump was inactive in the previous step (PREV pump is false).

Regarding the system, the following guarantees must hold at every step. First, if methane is not present (methane is false) and the water level is high (highwater is true), the system must ensure the pump is active in the next step (next pump is true). Second, if methane is present (methane is true), the system must ensure the pump is inactive in the next step (next pump is false).
