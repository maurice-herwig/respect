

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump specification describes a reactive system where the environment controls the boolean inputs `highwater` and `methane`, and the system controls the boolean output `pump`.

The specification includes an assumption regarding the operating context: the `pump` variable is assumed to be false at all times.

The system must satisfy the following guarantees. First, the system guarantees that at all times, either the `methane` variable is true or the `highwater` variable is false. Second, the system guarantees that at all times, if the `methane` variable is true, then the `pump` variable must be false in the next state.
