

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system controls a pump based on environmental inputs regarding water levels and methane presence. The environment provides the `highwater` and `methane` signals, while the system determines the `pump` status.

**Environment Assumptions**
The environment must satisfy the following constraint at all times: Whenever there is no methane and the pump is currently on, either the high water level will be false in the next step, or the pump was off in the previous step.

**System Guarantees**
The system must ensure the following conditions hold at all times:
- If there is no methane and the water level is high, the pump must be on in the next step.
- If there is methane, the pump must be off in the next step.
