

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system controls the boolean output variable `pump` based on the boolean input variables `highwater` and `methane`, which are controlled by the environment. The system operates continuously, adhering to the following assumptions and guarantees.

The environment is assumed to satisfy the condition that always, if methane is false and methane is true, then either highwater becomes false in the next step or the pump was false in the previous step.

The system must satisfy the following guarantees at all times. First, if methane is false and highwater is true, the system must set the pump to true in the next step. Second, if methane is true, the system must set the pump to false in the next step. These requirements ensure that the pump activates when water is high in the absence of methane, and deactivates when methane is present.
