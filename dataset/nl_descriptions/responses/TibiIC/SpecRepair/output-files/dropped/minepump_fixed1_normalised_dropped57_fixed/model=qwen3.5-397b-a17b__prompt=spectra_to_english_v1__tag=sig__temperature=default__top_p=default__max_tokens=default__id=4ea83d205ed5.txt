

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

**Requirements Description**

This specification defines a reactive system controlling a mine pump based on environmental sensor inputs. The environment provides signals indicating water levels and methane presence, while the system controls the pump activation.

**Environment Assumptions**
The environment behavior is constrained by the following assumption:
*   Globally, if highwater is false and highwater is true simultaneously, then either highwater becomes false in the next state or the pump was false in the previous state.

**System Guarantees**
The system must satisfy the following guarantees regarding the pump output:
*   **Pump Control based on Methane:** Globally, the system must ensure the following conditions regarding the methane level and the pump state in the next step:
    *   If methane is false, the pump must be set to true in the next state.
    *   If methane is true, the pump must be set to false in the next state.

These requirements ensure that the pump activation in the next step is determined by the current absence or presence of methane.
