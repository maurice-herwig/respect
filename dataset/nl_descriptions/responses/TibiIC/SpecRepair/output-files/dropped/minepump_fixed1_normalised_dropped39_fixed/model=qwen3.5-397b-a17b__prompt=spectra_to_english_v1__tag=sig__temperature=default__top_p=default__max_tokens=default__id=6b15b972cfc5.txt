

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump specification describes a reactive system that controls a pump based on environmental conditions. The environment provides inputs indicating the water level and methane presence, while the system controls the pump state.

**Environment Assumptions**
The environment is assumed to satisfy the following constraint regarding the water level dynamics relative to the pump status:
- Always, if `pump` is true and `highwater` is true, then either `highwater` will become false in the next step, or `pump` was false in the previous step.

**System Guarantees**
The system must satisfy the following requirements at all times:
- Always, if `methane` is false and `highwater` is true, then `pump` must be true in the next step.
- Always, if `methane` is true, then `pump` must be false in the next step.
