

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump specification describes a reactive system where the environment controls the boolean inputs `highwater` and `methane`, and the system controls the boolean output `pump`.

The specification operates under the assumption that the `pump` output is always false.

The system must satisfy the following guarantees at every step of its operation:
1.  At all times, at least one of the following conditions must hold: `methane` is true, the `pump` will be true in the next step, or `highwater` is false.
2.  At all times, the `pump` must be false in the next step.

These requirements define the safety and temporal behavior expected of the system throughout its interaction with the environment.
