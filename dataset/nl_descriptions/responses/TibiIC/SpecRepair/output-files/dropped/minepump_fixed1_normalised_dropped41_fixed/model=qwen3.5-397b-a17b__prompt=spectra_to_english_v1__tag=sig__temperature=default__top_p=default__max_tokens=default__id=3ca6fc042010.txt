

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

This specification describes a reactive system that controls a pump based on environmental sensor inputs. The environment provides the `highwater` and `methane` boolean signals, while the system controls the `pump` boolean signal.

The environment is assumed to satisfy the following condition globally: at all times, if the `pump` variable is simultaneously true and false, then either the `highwater` variable must be false in the next state or the `pump` variable must have been false in the previous state.

The system must satisfy the following guarantees globally:
1. At all times, if the `methane` variable is false, then the `pump` variable must be true in the next state.
2. At all times, if the `methane` variable is true, then the `pump` variable must be false in the next state.

These requirements ensure that the system updates the pump state in the next step based on the current state of the methane sensor, while operating under the stated environmental assumption regarding the pump and highwater signals.
