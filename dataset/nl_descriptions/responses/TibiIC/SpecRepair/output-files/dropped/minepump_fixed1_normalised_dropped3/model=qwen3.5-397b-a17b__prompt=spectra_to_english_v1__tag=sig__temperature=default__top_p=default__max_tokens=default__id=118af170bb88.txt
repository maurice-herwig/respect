

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump specification describes a reactive system where the environment controls the boolean inputs highwater and methane, and the system controls the boolean output pump. The behavior is defined by assumptions on the environment and guarantees required from the system, all of which must hold at every step of the interaction.

The environment is assumed to adhere to the following constraint: whenever the pump is currently on, the environment must ensure that highwater is false in the next step.

The system must satisfy the following guarantees regarding the next state of the pump based on the current state of the inputs:
1. Whenever methane is currently true, the system must ensure the pump is off in the next step.
2. Whenever highwater is currently true and methane is currently false, the system must ensure the pump is on in the next step.
