The Minepump system interacts with its environment, which controls two inputs: highwater and methane, indicating whether the water level is high and whether methane is present, respectively. The system controls one output: pump, which represents whether the pump is active or not.

The environment is assumed to behave in such a way that if the pump is not active in the previous state, then the water level will not be high in the next state.

The system must satisfy two guarantees. Firstly, if methane is present, then the pump must be active in the next state, unless the water level is not high. Secondly, if methane is not present, then the pump must not be active in the next state.

These guarantees imply that the system's pump output is dependent on the environment's methane input and highwater input, ensuring safe operation of the mine pump under various environmental conditions.
