

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The system controls the `pump` output based on the `highwater` and `methane` inputs provided by the environment. The behavior is governed by the following assumptions and guarantees.

**Environment Assumptions**
It is assumed that the environment satisfies the following condition globally: if the `pump` is false and the `pump` is true, then either the `highwater` variable will be false in the next step or the `pump` variable was false in the previous step.

**System Guarantees**
The system must ensure the following conditions hold globally:
1. If the `methane` variable is false and the `highwater` variable is true, then the `pump` variable must be true in the next step.
2. If the `methane` variable is true, then the `pump` variable must be false in the next step.
