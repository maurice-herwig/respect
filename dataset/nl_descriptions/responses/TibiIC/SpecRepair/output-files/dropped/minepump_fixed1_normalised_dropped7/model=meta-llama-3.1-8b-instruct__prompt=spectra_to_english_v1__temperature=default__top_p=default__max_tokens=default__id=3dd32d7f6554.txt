The Minepump system interacts with its environment through the highwater and methane signals, which are controlled by the environment. The system controls the pump output.

The environment's behavior is assumed to be restricted by the following conditions: highwater and methane signals are either both true or both false at any given time.

The Minepump system must satisfy the following guarantees: 

1. When methane is present, the pump must be activated, and the highwater signal must be false.
2. When methane is absent, the pump must not be activated.

In other words, the system ensures that the pump is only activated when methane is present and highwater is not present, and it remains deactivated when methane is absent.
