

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The system controls the `pump` output based on the `highwater` and `methane` inputs provided by the environment. The system must satisfy the following safety guarantees regarding the next state of the pump at all times:

1.  Whenever `highwater` is true and `methane` is false, the system must ensure that `pump` is true in the next state.
2.  Whenever `methane` is true, the system must ensure that `pump` is false in the next state.
