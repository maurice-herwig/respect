The TrafficE2 system is a reactive system that interacts with its environment, which controls the presence of a car, emergency situations, and police presence. The system controls the state of a traffic light, specifically whether it is green.

The environment is expected to behave in certain ways. Specifically, it is assumed that the police will not be present indefinitely, and there will be times when the police are not present. Additionally, when the traffic light was previously green and is now red, the car will not be present unless there is an emergency or the light is still green. The environment is also assumed to behave such that if the police are present, the car will either not be present or will move when the light is green.

The system guarantees certain behavior. The traffic light will turn green when a car is present, and this will happen infinitely often. Furthermore, the system ensures that there will be times when no car is present.

Initially, the system starts in a state where it is waiting for a car to arrive. The system then responds to the presence of a car by turning the traffic light green. If a car is present and the light is not green, the system transitions to a state where it is waiting for the light to turn green. Once the light turns green, the system transitions back to its initial state, ready to respond to the next car. The system always eventually returns to this initial state, ensuring that it can respond to cars infinitely often.
