The TrafficE2 system is a reactive system that interacts with its environment, which controls the presence of a car, emergency situations, and police presence. The system controls the state of a traffic light, indicated by the green signal.

The environment is expected to behave in certain ways: it should not have police presence indefinitely, and there should be periods where there are no cars. Additionally, when the traffic light is not green, a car should not start moving unless there is an emergency or the car is already moving. If the police are not present, a car should not be moving when the traffic light is not green.

The system guarantees that it will respond to the presence of a car by eventually turning the traffic light green when a car is present. Furthermore, the system ensures that there will be periods where there are no cars.

Initially, the system is in a state where it is waiting for a car. The system then enters a cycle where it waits for a car, and when a car is present, it turns the traffic light green. If the traffic light is green when a car is present, the system remains in the waiting state. If a car is present and the traffic light is not green, the system transitions to a state where it is waiting for the traffic light to turn green. Once the traffic light turns green, the system returns to the waiting state.

The system-controlled output is the green traffic light signal, while the environment-controlled inputs are the presence of a car, emergency situations, and police presence.
