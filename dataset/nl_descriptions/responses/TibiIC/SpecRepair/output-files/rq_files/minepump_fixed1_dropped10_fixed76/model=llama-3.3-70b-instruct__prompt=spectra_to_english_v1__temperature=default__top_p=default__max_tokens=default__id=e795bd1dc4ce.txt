The Minepump system interacts with its environment, which controls two inputs: highwater and methane. The system controls one output: pump. 

The environment is assumed to behave in such a way that if the pump is currently off, it will remain off. 

The system must satisfy two guarantees. Firstly, if methane is present, the system must turn on the pump at the next opportunity. Secondly, if methane is not present, the system must turn off the pump at the next opportunity.

Note that the highwater input from the environment does not have any specified influence on the system's behavior in this description.
