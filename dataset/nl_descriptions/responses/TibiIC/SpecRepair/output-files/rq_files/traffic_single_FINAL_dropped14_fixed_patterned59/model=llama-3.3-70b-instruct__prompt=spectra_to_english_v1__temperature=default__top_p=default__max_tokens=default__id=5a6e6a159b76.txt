The TrafficE2 system controls a traffic light, interacting with its environment, which includes the presence of a car, an emergency situation, and police intervention. The environment controls the variables "car" (indicating whether a car is present), "emergency" (indicating an emergency situation), and "police" (indicating police intervention). The system controls the variable "green" (indicating whether the traffic light is green).

The environment is assumed to behave in certain ways: it is expected that the police will not be present indefinitely, meaning there will be times when the police are not intervening. Additionally, the car will not start moving when the light is not green unless there is an emergency or the light turns green. When the light is green, the car is allowed to move. If the light is not green, the car should not be moving.

The system guarantees that it will respond to the presence of a car by eventually turning the light green when a car is present. This response is defined by a pattern that outlines the system's behavior in terms of states (S0 and S1) that track its response to the car's presence and the light's state. Initially, the system is in state S0. The system remains in state S0 as long as there is no car present or if a car is present and the light is green. If a car is present and the light is not green, the system transitions to state S1. In state S1, if the light turns green, the system returns to state S0; otherwise, it remains in state S1. The system ensures that it will infinitely often be in state S0, which corresponds to the light being green when a car is present, thus ensuring the car can proceed.
