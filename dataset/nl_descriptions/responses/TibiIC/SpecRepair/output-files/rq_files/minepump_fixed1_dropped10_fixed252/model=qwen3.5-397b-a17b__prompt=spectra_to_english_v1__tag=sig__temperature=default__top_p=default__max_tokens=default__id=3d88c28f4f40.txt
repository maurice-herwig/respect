

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The system controls the `pump` output based on the `methane` input provided by the environment. The `highwater` input is available from the environment but is not constrained by the following requirements.

**Assumptions on the Environment**
The specification operates under the assumption that at every step, if `methane` is false, then `pump` is currently false.

**System Guarantees**
The system must satisfy the following requirements at every step of the interaction:

1.  If `methane` is false, the system must set `pump` to true in the next step.
2.  If `methane` is true, the system must set `pump` to false in the next step.

These guarantees ensure that the state of the `pump` in the next step is determined by the current state of `methane`, toggling the pump off when methane is present and on when methane is absent, subject to the assumption regarding the current pump state when methane is absent.
