

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system manages a pump based on water levels and methane presence. The environment controls the inputs `highwater` and `methane`, while the system controls the output `pump`. All variables are boolean.

The environment is assumed to behave according to the following constraints. Always, if `pump` was `true` in the previous step and is `true` in the current step, then `highwater` must become `false` in the next step. Additionally, always, whenever `highwater` is `false`, either `highwater` is `false` or `methane` is `false`.

The system must satisfy the following guarantees. Always, whenever `highwater` is `true`, either `methane` is `true` or `pump` must become `true` in the next step. Furthermore, always, whenever `methane` is `true`, `pump` must become `false` in the next step.
