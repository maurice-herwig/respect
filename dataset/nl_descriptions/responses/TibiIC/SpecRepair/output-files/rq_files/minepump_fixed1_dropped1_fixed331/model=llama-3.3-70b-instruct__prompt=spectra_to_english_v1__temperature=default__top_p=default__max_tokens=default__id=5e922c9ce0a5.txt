The Minepump system interacts with its environment, which controls the presence of high water and methane. The system controls the operation of a pump. 

The environment is assumed to behave in a way that when there is no high water, the next state will also have no high water, unless the pump is turned off.

The system must satisfy two guarantees. Firstly, if methane is present, then either the pump must be turned on at the next step, or there must be no high water. Secondly, if there is no methane, then the pump must be turned off at the next step.

In summary, the system must operate the pump based on the presence of methane and high water, while the environment's behavior regarding high water is constrained when the pump is on.
