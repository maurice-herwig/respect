

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump specification describes a reactive system where the environment provides input signals regarding water levels and methane presence, and the system controls a pump. The environment controls the boolean inputs `highwater` and `methane`. The system controls the boolean output `pump`.

The specification imposes the following assumption on the behavior of the system and environment interaction:
- Always, if the pump is off, then either the pump is off in the current step or it was off in the previous step.

The system must satisfy the following guarantees whenever the environment satisfies the assumptions:
- Always, in the next step, the pump must be either off or on.
- Always, if methane is present, the pump must be off in the next step.
