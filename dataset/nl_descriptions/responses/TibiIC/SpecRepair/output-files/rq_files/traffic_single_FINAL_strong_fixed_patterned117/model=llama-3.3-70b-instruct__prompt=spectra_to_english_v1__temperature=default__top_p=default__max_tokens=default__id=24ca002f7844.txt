The TrafficE2 system is a reactive system that interacts with its environment, which controls the presence of a car, emergency situations, and police interventions. The system controls the state of a traffic light, indicated by the green signal.

The environment is expected to behave in certain ways. Specifically, it is assumed that police interventions do not occur frequently, and there are periods where police are not present. Additionally, when the traffic light is red and there is no police intervention, if a car is present, it will remain present in the next moment. On the other hand, when the traffic light is green and a car is present, the car will move and not be present in the next moment.

The system guarantees certain behavior. It ensures that the traffic light turns green frequently, and this happens in response to the presence of a car. Furthermore, the system guarantees that there will be periods where no car is present.

Initially, the system starts in a state where it is ready to respond to the presence of a car. The system's behavior can be described by its response pattern to the presence of a car. If a car is present and the traffic light is green, or if no car is present, the system remains in its current state. If a car is present but the traffic light is not green, the system transitions to a state where it is waiting for the traffic light to turn green. Once the traffic light turns green, the system returns to its initial state. The system always eventually returns to its initial state, ensuring that it periodically responds to the presence of a car.
