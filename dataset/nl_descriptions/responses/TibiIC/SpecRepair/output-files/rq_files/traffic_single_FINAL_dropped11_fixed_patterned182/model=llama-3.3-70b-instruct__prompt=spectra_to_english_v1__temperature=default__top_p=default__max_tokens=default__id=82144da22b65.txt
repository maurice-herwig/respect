The TrafficE2 system is a reactive system that interacts with its environment, which controls the presence of a car, emergency situations, and police intervention. The system controls the state of a traffic light, specifically whether it is green.

The environment is expected to behave in certain ways: it should not have police intervention infinitely often, and when a car is present, it should either be an emergency situation, the traffic light should be green, or the car should not be moving towards the traffic light when it is red. Additionally, when the traffic light was previously not green, the environment should ensure that either police are present, there is no car, or the traffic light remains not green, unless it is safe to turn green.

The system guarantees that it will respond to the presence of a car by eventually turning the traffic light green. This response is governed by a state machine that ensures the system will periodically turn the traffic light green when a car is present, as long as the environment behaves according to its assumptions. The system starts in an initial state where it is not responding to a car, and it will remain in this state as long as there is no car or the traffic light is already green. If a car is present and the traffic light is not green, the system will transition to a state where it is attempting to respond to the car, and it will turn the traffic light green as soon as possible. The system will then return to its initial state, repeating this cycle to ensure that the traffic light is green often enough to allow cars to pass through.
