

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system controls a pump based on environmental inputs regarding water levels and methane presence. The environment provides the boolean inputs `highwater` and `methane`, while the system controls the boolean output `pump`.

The specification includes an assumption regarding the history of the pump signal. It is assumed that globally, whenever the pump is false, either the pump is false or the pump was false in the previous step.

The system must satisfy two main guarantees regarding the pump's behavior in the next step. First, if methane is not present and the water level is high, the pump must be set to true in the next step. Second, if methane is present, the pump must be set to false in the next step. These requirements ensure that the pump activates to lower water levels when safe to do so, and deactivates immediately when methane is detected.
