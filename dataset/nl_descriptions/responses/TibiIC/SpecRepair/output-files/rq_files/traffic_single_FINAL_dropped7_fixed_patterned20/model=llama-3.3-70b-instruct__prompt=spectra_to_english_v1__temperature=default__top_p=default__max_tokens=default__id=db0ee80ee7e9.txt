The TrafficE2 system is a reactive system that interacts with its environment, which controls the presence of a car, an emergency, and police. The system controls the state of a traffic light, indicated by the green signal.

The environment is expected to behave in certain ways. Specifically, it is assumed that the police will not be present indefinitely, and there will be times when the police are not present. Additionally, when the traffic light is not green, a car will not start moving. However, if the car is not moving and the traffic light turns green, the car may start moving. It is also assumed that if the police are present, the car will not move, and if the car is moving, it will stop when the police arrive or the traffic light turns red.

The system must guarantee certain behaviors. The traffic light must turn green periodically when a car is present. Furthermore, the system must ensure that there will be times when no car is present.

Initially, the system starts in a state where it is not responding to the presence of a car. The system then enters a loop where it either remains in this state if there is no car or the car is present and the traffic light is green, or it transitions to a new state if a car is present and the traffic light is not green. If the system is in this new state, it will return to the initial state when the traffic light turns green. The system will periodically return to its initial state, indicating that it has responded to the presence of a car.
