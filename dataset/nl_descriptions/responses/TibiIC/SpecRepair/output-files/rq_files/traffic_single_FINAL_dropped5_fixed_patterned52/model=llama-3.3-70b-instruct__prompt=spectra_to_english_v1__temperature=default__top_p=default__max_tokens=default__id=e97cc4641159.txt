The TrafficE2 system is a reactive system that interacts with its environment, which controls the presence of a car, emergency situations, and police presence. The system controls the state of a traffic light, specifically whether it is green.

The environment is assumed to behave in certain ways. When there is no emergency, the car will either remain stopped or start moving only when the traffic light is green. Additionally, when the police are present, the car will either not be moving or will stop moving, unless the traffic light is not green.

The system guarantees that it will often respond to the presence of a car by turning the traffic light green. This is achieved through a specific pattern of behavior, where the system starts in an initial state. In this state, if a car is present, the traffic light will be green. If a car is present and the traffic light is not green, the system will transition to a different state. In this new state, the system will turn the traffic light green, and once it does, it will return to the initial state. The system will always eventually return to this initial state.

The system's behavior is constrained by safety requirements, which dictate that it must always follow specific rules. For example, if the system is in the initial state and a car is not present, or if a car is present and the traffic light is green, it will remain in that state. If a car is present and the traffic light is not green, it will transition to the new state. In the new state, if the traffic light is green, it will return to the initial state, but if the traffic light is not green, it will remain in the new state.

The environment-controlled inputs are the presence of a car, emergency situations, and police presence. The system-controlled output is the state of the traffic light, specifically whether it is green.
