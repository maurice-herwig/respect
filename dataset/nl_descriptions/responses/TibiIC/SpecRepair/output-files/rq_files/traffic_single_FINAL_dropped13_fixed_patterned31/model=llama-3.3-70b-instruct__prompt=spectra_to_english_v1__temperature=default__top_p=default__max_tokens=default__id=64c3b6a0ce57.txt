The TrafficE2 system is a reactive system that interacts with its environment, which controls the presence of a car, emergency situations, and police interventions. The system controls the state of a traffic light, specifically whether it is green.

The environment is expected to behave in certain ways. Specifically, it is assumed that there will be periods where police are not present. Additionally, when the traffic light is green, the environment will ensure that if a car is present, it will either continue to be present or the light will remain green at the next time step, or the car will not be present. Furthermore, when the traffic light is about to change, if a car is present, the environment will ensure that the car is not present at the next time step.

The system guarantees that it will often respond to the presence of a car by turning the traffic light green. This response is defined by a pattern where the system starts in an initial state (S0) and remains in this state as long as a car is not present or is present and the light is green. If a car is present and the light is not green, the system transitions to a different state (S1), where it remains until the light turns green, at which point it returns to the initial state (S0). The system ensures that it will infinitely often be in the initial state (S0), effectively guaranteeing that the traffic light will turn green in response to a car's presence.
