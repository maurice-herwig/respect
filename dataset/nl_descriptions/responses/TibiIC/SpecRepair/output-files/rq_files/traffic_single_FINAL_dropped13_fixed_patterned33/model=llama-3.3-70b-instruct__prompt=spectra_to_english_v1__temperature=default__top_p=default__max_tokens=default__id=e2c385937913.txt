The TrafficE2 system is a reactive system that interacts with its environment, which controls the presence of a car, emergency situations, and police interventions. The system controls the state of a traffic light, specifically whether it is green or not.

The environment is assumed to behave in certain ways: it is expected that police interventions do not occur infinitely often, allowing for periods without police presence. Additionally, the environment ensures that when the traffic light is not green, a car is either not present or does not move to the next state unless the light turns green or the car is already moving. The environment also guarantees that when there is no police intervention, if a car is present and the light turns green, the car will move on the next step.

The system guarantees that it will often respond to the presence of a car by turning the traffic light green. This response is defined by a pattern where the system initially starts in a state S0. The system remains in state S0 as long as there is no car present or if a car is present, the light is green. If a car is present and the light is not green, the system transitions to state S1. In state S1, if the light turns green, the system returns to state S0; otherwise, it remains in state S1. The system is required to infinitely often be in state S0, ensuring that it periodically responds to the car's presence by turning the light green.
