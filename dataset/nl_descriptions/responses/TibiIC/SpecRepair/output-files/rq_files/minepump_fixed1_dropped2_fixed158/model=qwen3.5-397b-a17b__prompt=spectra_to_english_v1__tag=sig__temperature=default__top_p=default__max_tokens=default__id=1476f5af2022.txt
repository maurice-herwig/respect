

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system controls the `pump` output based on the `highwater` and `methane` inputs. The behavior is defined by the following assumptions and guarantees.

**Assumptions**
The specification assumes that at every step, if `highwater` was true in the previous step, then either `pump` is false in the current step or `pump` was false in the previous step.

**Guarantees**
The system guarantees the following safety and next-state requirements:
1. At every step, if `methane` is false and `highwater` is true, then `pump` must be true in the next step.
2. At every step, if `methane` is true, then `pump` must be false in the next step.
