

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system manages a pump based on environmental signals indicating water levels and methane presence. The system operates continuously, adhering to specific assumptions about the environment and guarantees regarding its own control logic.

**Assumptions on the Environment**
It is assumed that globally, whenever the pump is false, either the highwater variable becomes false in the next step or the pump is false.

**Guarantees Required from the System**
The system must satisfy the following conditions at all times:
1. If the water level is high and methane is not detected, the system must ensure the pump is true in the next step.
2. If methane is detected, the system must ensure the pump is false in the next step.

All conditions apply globally throughout the system's operation, with state updates occurring in the next step following the detection of environmental conditions.
