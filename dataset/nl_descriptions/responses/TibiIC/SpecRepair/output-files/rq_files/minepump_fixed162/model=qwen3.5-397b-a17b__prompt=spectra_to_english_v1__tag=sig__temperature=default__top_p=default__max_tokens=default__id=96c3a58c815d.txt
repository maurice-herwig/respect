

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system manages a pump based on environmental conditions monitored by the environment. The environment controls the boolean inputs `highwater` and `methane`, while the system controls the boolean output `pump`.

The environment is assumed to behave according to the following constraint: If the pump was active in the previous step and remains active in the current step, then the environment ensures that the `highwater` signal will be inactive in the next step. This implies that continuous pumping reduces the water level.

The system must satisfy the following guarantees at all times:
1. Whenever the `highwater` signal is active and the `methane` signal is inactive, the system must activate the `pump` in the next step.
2. Whenever the `methane` signal is active, the system must deactivate the `pump` in the next step.
