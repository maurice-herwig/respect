

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump specification defines a reactive system where the environment controls the boolean inputs `highwater` and `methane`, and the system controls the boolean output `pump`. The behavior is constrained by assumptions on the environment and guarantees required from the system.

**Environment Assumptions**
The following conditions are assumed to hold globally throughout the system operation:
- Whenever `highwater` is true and the `pump` is false, it must be the case that either the `pump` is false or the `pump` was false in the previous state.
- Whenever `methane` is true, either the `pump` is false or the `pump` was false in the previous state.
- Whenever `highwater` is true, either the `pump` is false or the `pump` was false in the previous state.
- Whenever `highwater` is true and `methane` will be true in the next state, either the `pump` is false or the `pump` was false in the previous state.

**System Guarantees**
The system must satisfy the following conditions globally:
- At all times, the `pump` must be true in the next state.
- At all times, either `methane` is false or the `pump` must be false in the next state. Equivalently, if `methane` is true, the `pump` must be false in the next state.
