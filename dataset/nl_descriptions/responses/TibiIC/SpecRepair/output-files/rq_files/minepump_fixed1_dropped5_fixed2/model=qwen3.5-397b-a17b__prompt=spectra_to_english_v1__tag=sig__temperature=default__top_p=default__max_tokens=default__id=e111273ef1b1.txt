

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump specification defines the behavior of a reactive system where the environment provides sensor inputs and the system controls a pump output.

**Environment Assumptions**
The environment is assumed to satisfy the following constraint at all times: If `methane` will be true in the next state, then either `highwater` will be false in the next state or the `pump` is currently false.

**System Guarantees**
The system must ensure the following requirements hold at all times:
1. If `methane` is false, the `pump` must be true in the next state.
2. If `methane` is true, the `pump` must be false in the next state.
