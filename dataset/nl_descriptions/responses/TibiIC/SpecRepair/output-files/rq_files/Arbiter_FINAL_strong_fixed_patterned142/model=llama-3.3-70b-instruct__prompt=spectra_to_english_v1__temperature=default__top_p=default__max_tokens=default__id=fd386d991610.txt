The Arbiter system interacts with its environment through inputs `a`, `r1`, and `r2`, and outputs `g1` and `g2`. The environment controls `a`, `r1`, and `r2`, while the system controls `g1` and `g2`.

The environment is assumed to always maintain its state once it sets `a` to true, meaning that if `a` becomes true, it will remain true.

The system guarantees the following behavior: 
- When `r1` is true and `r2` is false, the system will eventually set `g1` to true.
- When `r2` is true, the system will set `g2` to true.
- If `a` is false, then the system will ensure that `g1` and `g2` are both false as long as `a` remains false.
- The system ensures that if `r2` is false, then either `g1` or `g2` (or both) will be false.

The system's behavior is also guided by a pattern that defines how it responds to certain stimuli. Initially, the system is in a state where it is not responding to a stimulus. The system remains in this state as long as the stimulus is not present or if the stimulus is present and the system is responding to it. If the stimulus is present and the system is not responding, it transitions to a state where it is waiting for a response. In this waiting state, the system will return to its initial state if it starts responding, otherwise, it will remain in the waiting state. The system will infinitely often be in its initial state.
