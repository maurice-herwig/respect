The Arbiter system interacts with its environment through four boolean variables: two environment-controlled inputs, `r1` and `r2`, and two system-controlled outputs, `g1` and `g2`. The environment also controls a boolean variable `a`.

The environment is assumed to behave in a way that whenever `r1` is false, `a` is true. This assumption restricts the environment's allowed behavior.

The system must guarantee the following behavior: 
- Whenever `r1` is true and `a` is false, the system must set `g1` to true.
- Whenever `r2` is true and `a` is false, the system must set `g2` to true.
- As long as `a` is false, the system must ensure that if `a` remains false, then both `g1` and `g2` are false.
- The system must also ensure that if `r1` is true, then either `g1` is false or `g2` is false.

The system's behavior is further defined by a pattern that describes how it responds to certain stimuli. Initially, the system is in a state where it is ready to respond to stimuli. The system remains in this state as long as the stimulus is not present or is present and the system is responding to it. If the stimulus is present and the system is not responding, it transitions to a different state. In this different state, the system will remain until it responds to the stimulus, at which point it returns to the initial state. The system must infinitely often be in its initial state, indicating that it periodically returns to a state where it is ready to respond to stimuli.
