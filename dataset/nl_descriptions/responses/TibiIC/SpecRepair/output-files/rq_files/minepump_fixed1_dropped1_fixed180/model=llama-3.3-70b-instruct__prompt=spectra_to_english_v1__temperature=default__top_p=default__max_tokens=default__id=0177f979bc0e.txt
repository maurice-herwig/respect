The Minepump system interacts with an environment that provides two input signals: `highwater` and `methane`, indicating whether the water level is high and whether methane is present, respectively. The system controls one output, `pump`, which determines whether the pump is active or not.

The environment is assumed to behave in such a way that if the pump is currently active, then the water level will not be high in the next state, unless the pump was inactive in the previous state.

The system must guarantee two conditions. Firstly, if methane is detected, then the pump must be active in the next state. Secondly, if no methane is detected, then the pump must be inactive in the next state. 

Note that the system's behavior is solely defined in terms of the next-state relationships with respect to the methane detection, and the environment's behavior regarding the water level when the pump is active.
