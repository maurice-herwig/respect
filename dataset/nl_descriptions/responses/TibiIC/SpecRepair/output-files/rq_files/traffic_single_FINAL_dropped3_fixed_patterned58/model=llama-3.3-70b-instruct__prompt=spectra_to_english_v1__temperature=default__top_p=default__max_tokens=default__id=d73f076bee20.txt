The TrafficE2 system is a reactive system that interacts with its environment, which controls the presence of a car, emergency situations, and police presence. The system controls the state of a traffic light, indicated by the green signal.

The environment is expected to behave in certain ways: it is assumed that police will not be present indefinitely, and there will be times when no police are present. Additionally, when the police are present, the car will not start moving unless the traffic light is green or the car is already moving. The environment is also assumed to ensure that when the car is not moving, it will either remain stationary or start moving only when the traffic light is green.

The system guarantees two main behaviors: the traffic light will turn green periodically, and there will be times when no car is present. Furthermore, the system ensures that when a car is present, the traffic light will eventually turn green.

Initially, the system starts in a state where it is not responding to the car's presence. The system then continuously monitors the car's presence and the traffic light's state, switching between two states: one where it is not responding to the car, and another where it is waiting for the traffic light to turn green. The system remains in the non-responding state as long as there is no car present or the traffic light is green when a car is present. If a car is present and the traffic light is not green, the system transitions to the waiting state. Once in the waiting state, the system will return to the non-responding state when the traffic light turns green. The system will infinitely often return to the non-responding state, ensuring that the traffic light turns green periodically in response to the car's presence.
