

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system manages a pump based on environmental conditions regarding water levels and methane presence. The environment controls the `highwater` and `methane` inputs, while the system controls the `pump` output.

**Assumptions on the Environment**
The environment is assumed to satisfy the following condition globally: whenever the `methane` level is set to true in the next step, the `pump` must have been false in the previous step.

**Guarantees from the System**
The system must satisfy the following behaviors globally:
1. Whenever the `highwater` level is true and `methane` is false, the system must set `pump` to true in the next step.
2. Whenever `methane` is true, the system must set `pump` to false in the next step.
