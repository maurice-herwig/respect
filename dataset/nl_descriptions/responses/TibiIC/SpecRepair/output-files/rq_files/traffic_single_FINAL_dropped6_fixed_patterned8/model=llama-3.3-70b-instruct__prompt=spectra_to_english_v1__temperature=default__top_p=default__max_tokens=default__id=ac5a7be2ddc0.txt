The TrafficE2 system is a reactive system that interacts with its environment, which controls the presence of a car, emergency situations, and police intervention. The system controls the state of a traffic light, indicated by the green signal.

The environment is expected to behave in certain ways: it should not have police intervention infinitely often, and when a car is present, it should either remain present or be accompanied by an emergency situation or a green light in the next state. Additionally, the environment should ensure that when a car is moving, it is either not a police situation, there is no car, the car will not be present in the next state, or the light is not green.

The system guarantees two main behaviors: the green light will be on infinitely often when a car is present, and there will be periods where no car is present infinitely often.

Initially, the system starts in a state where it is prepared to respond to the presence of a car. The system's response to a car's presence is governed by a pattern that ensures the green light is turned on when a car is present, and this pattern repeats infinitely often. Specifically, when a car is present and the light is not green, the system transitions to a state where it awaits the green light. Once the green light is on, the system returns to its initial state, ready to respond to the next car. If a car is present and the light is green, or if no car is present, the system remains in its initial state.
