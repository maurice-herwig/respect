

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump specification defines a reactive system where the environment monitors water levels and methane presence, and the system controls a pump. The environment provides the boolean inputs `highwater` and `methane`, while the system controls the boolean output `pump`.

**Assumptions**
The system operates under the assumption that the following condition always holds: whenever the water level is high (`highwater` is true), the pump is currently off (`pump` is false).

**Guarantees**
The system must satisfy the following requirements globally:
1. Whenever there is no methane detected (`methane` is false) and the water level is high (`highwater` is true), the pump must be turned on in the next step (`pump` becomes true).
2. Whenever methane is detected (`methane` is true), the pump must be turned off in the next step (`pump` becomes false).
