

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump specification defines a reactive system where the environment provides input signals regarding water and methane levels, and the system controls the state of a pump. The environment controls the boolean inputs `highwater` and `methane`, while the system controls the boolean output `pump`.

The specification imposes the following assumption on the environment's behavior. Globally, if the `highwater` signal was true in the previous step, then either the `pump` is currently false or the `pump` was false in the previous step.

The system must satisfy the following guarantees. Globally, at every step, the system must ensure that the `pump` is assigned a value of either false or true in the next step. Additionally, globally, if the `methane` signal is true at any step, the system must ensure that the `pump` is false in the following step.
