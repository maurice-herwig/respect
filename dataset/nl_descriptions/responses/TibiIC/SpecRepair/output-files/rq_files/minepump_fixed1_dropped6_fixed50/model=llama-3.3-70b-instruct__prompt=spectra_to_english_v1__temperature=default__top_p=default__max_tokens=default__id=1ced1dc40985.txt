The Minepump system interacts with its environment, which controls the presence of high water and methane. The system controls the operation of a pump. 

The environment is assumed to behave in such a way that if there is no high water, then the pump was not operating in the previous state.

The system must satisfy two guarantees. Firstly, if methane is present, then either the pump must be turned on at the next state or there must be no high water. Secondly, if there is no methane, then the pump must be turned off at the next state.

In this system, the environment-controlled inputs are the presence of high water and methane, while the system-controlled output is the operation of the pump.
