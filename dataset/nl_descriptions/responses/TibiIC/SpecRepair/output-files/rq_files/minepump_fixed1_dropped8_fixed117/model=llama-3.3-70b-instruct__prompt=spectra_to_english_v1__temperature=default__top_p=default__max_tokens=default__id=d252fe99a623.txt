The Minepump system is designed to interact with its environment, which controls the presence of high water and methane. The system controls the operation of a pump. 

The environment's behavior is restricted by the assumption that if the pump is not operating, it will remain off unless it was previously off.

The system must satisfy two guarantees. Firstly, if methane is present, the pump must be turned on at the next opportunity. Secondly, if there is no methane, the pump must be turned off at the next opportunity.

In summary, the system's pump operation is directly tied to the presence or absence of methane in the environment, with specific rules governing its next-state behavior based on the current state of methane detection. The environment is assumed to maintain a consistent state regarding the pump's operation when it is off.
