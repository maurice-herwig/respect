The TrafficE2 system is a reactive system that interacts with its environment, which controls the presence of a car, emergency situations, and police presence. The system controls the state of a traffic light, specifically whether it is green.

The environment is expected to behave in certain ways. Specifically, it is assumed that the police will not be present indefinitely, and there will be times when they are not present. Additionally, when the traffic light is not green, a car will not start moving unless there is an emergency or the car is already moving. Furthermore, when the police are not present, if a car is moving, it will either stop or the traffic light will turn red.

The system guarantees certain behavior. The traffic light will turn green whenever a car is present, and this will happen repeatedly over time. Moreover, there will be times when there are no cars present.

Initially, the system starts in a state where it is not responding to the presence of a car. The system then continuously checks for the presence of a car and updates its state accordingly. If a car is present and the light is not green, the system moves to a state where it is waiting for the light to turn green. Once the light turns green, the system returns to its initial state. This process repeats indefinitely, ensuring that the traffic light turns green in response to the presence of a car.
