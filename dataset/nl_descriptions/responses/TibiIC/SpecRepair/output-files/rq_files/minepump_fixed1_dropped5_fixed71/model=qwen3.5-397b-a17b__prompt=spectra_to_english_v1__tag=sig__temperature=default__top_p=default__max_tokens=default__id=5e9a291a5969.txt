

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system controls a pump based on environmental sensor inputs. The environment provides boolean signals for highwater and methane levels, while the system determines the boolean status of the pump.

The specification includes an assumption on the environment behavior. Globally, if highwater is false in the next state, then it must be the case that either highwater is false in the next state or the pump is false in the current state.

The system must satisfy two guarantees globally. First, at every step, either methane is true or the pump will be true in the next state. Second, at every step, either methane is false or the pump will be false in the next state. These requirements ensure that the pump's state in the next step is constrained by the current presence or absence of methane.
