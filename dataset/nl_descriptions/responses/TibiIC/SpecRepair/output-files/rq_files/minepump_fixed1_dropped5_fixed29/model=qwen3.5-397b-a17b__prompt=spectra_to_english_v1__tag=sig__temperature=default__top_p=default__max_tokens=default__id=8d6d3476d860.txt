

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system manages a pump based on environmental conditions monitored by the environment. The environment controls the boolean inputs `highwater` and `methane`, while the system controls the boolean output `pump`.

**Assumptions on the Environment**
The specification assumes the following behavior holds globally throughout the system operation: whenever `methane` is true, either the `highwater` level will be false in the next step, or the `pump` is currently false.

**Guarantees from the System**
The system must satisfy the following requirements globally at every step:
1. If `methane` is false, the system must ensure `pump` is true in the next step.
2. If `methane` is true, the system must ensure `pump` is false in the next step.
