The TrafficE2 system is a reactive system that interacts with its environment, which controls the presence of a car, emergency situations, and police interventions. The system controls the state of a traffic light, specifically whether it is green or not.

The environment is assumed to behave in certain ways. It is expected that police interventions do not occur infinitely often. Additionally, when the traffic light is not green, the car is not allowed to move unless there is an emergency or the car remains stationary. The car is also expected to move when the traffic light is green, unless there is a police intervention or the car is already stationary.

The system guarantees certain behavior. The traffic light will turn green often when there is a car present. Furthermore, the system ensures that there will be periods where there are no cars present.

The system's behavior is also governed by a specific pattern of response to the presence of a car. Initially, the system is in a state where it is not responding to the car's presence. The system remains in this state as long as there is no car present or if there is a car present and the traffic light is green. If a car is present and the traffic light is not green, the system transitions to a state where it is waiting for the traffic light to turn green. Once the traffic light turns green, the system returns to its initial state. The system will infinitely often be in its initial state, ensuring that it periodically resets and is ready to respond to the car's presence.
