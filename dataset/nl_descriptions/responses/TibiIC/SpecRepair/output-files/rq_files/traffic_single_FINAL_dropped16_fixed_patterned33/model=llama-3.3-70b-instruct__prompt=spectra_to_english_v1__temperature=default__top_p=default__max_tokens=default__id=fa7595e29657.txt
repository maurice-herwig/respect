The TrafficE2 system is a reactive system that interacts with its environment, which controls the presence of a car, an emergency situation, and police. The system controls the state of a traffic light, indicated by the green signal.

The environment is expected to behave in certain ways: when the car is not present, it will either remain absent or become present only if there is an emergency. Additionally, if the car is present, it will not start moving when the light is not green.

The system guarantees that the green light will be turned on frequently when a car is present. This is achieved through a pattern of responses to the car's presence, where the system initially starts in a state S0. In this state, if a car is present, the system will turn the green light on. If the green light is not turned on when a car is present, the system transitions to state S1. The system will remain in state S1 until the green light is turned on, at which point it returns to state S0. The system ensures that it will infinitely often be in state S0, where the green light is turned on in response to the car's presence.

The system's initial condition is that it starts in state S0. The safety requirements dictate that the system will only transition between states S0 and S1 based on the presence of the car and the green light. The liveness requirement is that the system will infinitely often be in state S0, ensuring that the green light is turned on frequently in response to the car's presence. The next-state relationships are defined by the transitions between states S0 and S1, which depend on the presence of the car and the green light.
