

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system controls a pump based on water levels and methane presence. The environment provides the `highwater` and `methane` inputs, while the system determines the `pump` output.

**Environment Assumptions**
The environment behavior is constrained by the following rule: Whenever the `highwater` signal is true, either the `highwater` signal must become false in the next step, or the `pump` was false in the previous step.

**System Guarantees**
The system must satisfy the following requirements at every step:
1. If `methane` is false and `highwater` is true, then `pump` must be true in the next step.
2. If `methane` is true, then `pump` must be false in the next step.
