The Minepump system is a reactive system that interacts with its environment. The environment controls two inputs: highwater and methane, which are boolean values indicating whether the water level is high and whether methane is present, respectively. The system controls one output: pump, a boolean value indicating whether the pump is active.

The environment is assumed to behave in such a way that if the pump is active in the current and previous states, then the water level will not be high in the next state.

The system must guarantee two conditions. Firstly, if the water level is high and there is no methane, then the pump must be active in the next state. Secondly, if methane is present, then the pump must not be active in the next state. 

Note that the initial state of the system is not explicitly defined in the provided specification.
