The Minepump system operates in an environment where two conditions are monitored: the presence of high water and the presence of methane. However, the system's behavior is only specified in relation to methane levels. The system controls a pump.

The environment is assumed to behave in such a way that if the pump is currently off, it will remain off unless some external condition not specified in the guarantee rules causes it to turn on.

The system must satisfy two guarantees. Firstly, if methane is detected, the pump must be turned on at the next opportunity. Secondly, if no methane is detected, the pump must be turned off at the next opportunity.

Note that the system's behavior in relation to high water levels is not specified. The initial state of the system and any liveness requirements (i.e., conditions that must happen infinitely often) are also not defined in this specification.
