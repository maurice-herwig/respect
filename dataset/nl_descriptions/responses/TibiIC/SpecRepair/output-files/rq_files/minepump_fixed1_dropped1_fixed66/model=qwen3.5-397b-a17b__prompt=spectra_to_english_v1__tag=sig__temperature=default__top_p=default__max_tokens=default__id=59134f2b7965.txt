

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system controls a pump based on environmental conditions regarding water levels and methane presence. The environment provides two boolean inputs: `highwater`, which indicates if the water level is high, and `methane`, which indicates if methane is detected. The system controls one boolean output: `pump`, which determines whether the pump is active.

**Assumptions on the Environment**
It is assumed that globally, whenever the water level becomes not high in the next step, either the water level becomes not high in the next step or the pump is currently off.

**Guarantees from the System**
The system must satisfy the following requirements at all times:
1.  If the water level is high and methane is not detected, the system must ensure the pump is on in the next step.
2.  If methane is detected, the system must ensure the pump is off in the next step.
