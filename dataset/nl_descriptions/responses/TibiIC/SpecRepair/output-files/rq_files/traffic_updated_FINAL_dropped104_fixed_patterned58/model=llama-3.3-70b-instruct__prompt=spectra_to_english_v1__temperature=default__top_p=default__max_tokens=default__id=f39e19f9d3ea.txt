The TrafficE2 system is a reactive system that controls traffic lights in response to cars approaching from two directions, A and B, and an emergency mode. The environment controls the presence of cars on approaches A and B, denoted by cara and carb, and the emergency mode, denoted by emergency. The system controls the traffic lights for approaches A and B, denoted by greena and greenb.

The environment is assumed to behave in the following ways: when the emergency mode is active, it will not start a car on approach A unless the traffic light for approach A is green or the emergency mode remains active. Similarly, it will not start a car on approach B unless the traffic light for approach B is green, the emergency mode remains active, or there is no car on approach B. Additionally, when the emergency mode is active, the environment will ensure that a car on approach A will move when the traffic light for approach A is green, unless the emergency mode remains active or there is no car on approach A. The same applies to approach B.

The system guarantees the following behavior: when a car is present on approach A, the system will eventually turn the traffic light for approach A green. The same guarantee applies to approach B.

The system's behavior can be described as follows: initially, the system is in a state where it is waiting for a car to arrive. When a car arrives on an approach, the system will turn the corresponding traffic light green if it is not already green. If the traffic light is already green when a car arrives, the system will keep it green. The system will return to its initial state when the traffic light is green and a car is present on the approach. This behavior is repeated infinitely often, ensuring that the system responds to cars on both approaches.
