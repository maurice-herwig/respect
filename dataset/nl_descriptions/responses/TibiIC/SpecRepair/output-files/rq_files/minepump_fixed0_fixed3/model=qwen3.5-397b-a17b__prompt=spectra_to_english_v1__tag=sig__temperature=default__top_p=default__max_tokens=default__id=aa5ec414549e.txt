

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

**Requirements Description**

This specification defines the behavior of a mine pump control system interacting with an environment. The environment controls the boolean inputs `highwater` and `methane`, while the system controls the boolean output `pump`.

**Environment Assumptions**
The environment is assumed to adhere to the following constraints:
*   If the `pump` output was true in the previous time step and remains true in the current time step, the environment ensures that the `highwater` input becomes false in the next time step.
*   Whenever the `pump` output is true, the environment ensures that either the `highwater` input is false or the `methane` input is false.

**System Guarantees**
The system must satisfy the following requirements regarding the `pump` output:
*   Whenever the `highwater` input is true, the system ensures that either the `pump` output is currently false or the `pump` output will be true in the next time step.
*   Whenever the `methane` input is true, the system ensures that the `pump` output will be false in the next time step.
