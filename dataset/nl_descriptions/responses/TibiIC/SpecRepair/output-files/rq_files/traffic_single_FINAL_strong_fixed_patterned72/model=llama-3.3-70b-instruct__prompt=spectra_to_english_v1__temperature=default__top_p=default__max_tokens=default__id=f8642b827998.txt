The TrafficE2 system is a reactive system that interacts with its environment, which controls the presence of a car, emergency situations, and police interventions. The system controls the state of a traffic light, specifically whether it is green.

The environment is expected to behave in certain ways. It is assumed that police interventions do not occur frequently, and there are periods where no police are present. Additionally, when the traffic light is not green and a car is present, the car will remain idle until the light turns green. However, when the light is green and a car is present, the car will move forward unless an emergency situation arises, in which case it will also move forward even if the emergency situation is anticipated in the next moment.

The system guarantees certain behaviors. The traffic light will turn green frequently, and this is related to the presence of cars. Specifically, when a car is present, the system will eventually turn the light green. Furthermore, the system ensures that there are periods where no cars are present.

Initially, the system starts in a state where it is not responding to the presence of a car. The system's behavior can be described by its state transitions. If the system is in a state where it is not responding to a car and a car is not present or is present and the light is green, it will remain in this state. If a car is present and the light is not green, the system will transition to a state where it is waiting for the light to turn green. Once the light is green, the system will return to its initial state. If the light remains green, the system will stay in the waiting state until the light turns green again.
