

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system manages a pump based on environmental conditions. The environment controls the `highwater` and `methane` variables, while the system controls the `pump` variable.

The environment must satisfy the following assumption regarding its behavior:
- Whenever `methane` is true, either `highwater` will be false in the next step, or `pump` was false in the previous step.

The system must satisfy the following guarantees regarding its behavior:
- Whenever `methane` is false and `highwater` is true, the system must ensure `pump` is true in the next step.
- Whenever `methane` is true, the system must ensure `pump` is false in the next step.
