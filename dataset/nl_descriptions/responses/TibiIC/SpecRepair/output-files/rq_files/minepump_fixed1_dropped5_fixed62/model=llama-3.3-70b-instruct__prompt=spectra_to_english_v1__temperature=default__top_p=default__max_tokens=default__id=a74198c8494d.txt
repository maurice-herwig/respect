The Minepump system interacts with its environment, which controls the presence of high water and methane. The system controls the pump. 

The environment is assumed to behave in such a way that if methane becomes present, then either the water is not high or the pump is not running.

The system must satisfy two guarantees. Firstly, if methane is present, then the pump must be turned on at the next step. Secondly, if methane is not present, then the pump must be turned off at the next step.

In other words, the pump's state is directly determined by the presence or absence of methane, with the system ensuring that the pump is on when methane is detected and off when methane is not detected.
