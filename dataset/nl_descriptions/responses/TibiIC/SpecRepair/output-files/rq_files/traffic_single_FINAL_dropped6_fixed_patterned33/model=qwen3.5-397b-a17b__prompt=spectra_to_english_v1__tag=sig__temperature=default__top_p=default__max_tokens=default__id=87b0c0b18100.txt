

Specification name: TrafficE2

Environment variables:
- car: boolean
- emergency: boolean
- police: boolean

System variables:
- green: boolean

**Requirements Description**

This specification describes a reactive traffic light system. The environment controls the presence of a car, an emergency signal, and police presence. The system controls the green traffic light signal.

**Environment Assumptions**
1.  **Police Presence:** The police signal is not permanently active; it must be false infinitely often.
2.  **Car Arrival:** If the car was absent in the previous step, then either the car will be present in the next step, or the emergency signal is currently true, or the green light is currently true.
3.  **Car Movement:** If the green light is true and the police signal is false, the car cannot be present in both the current step and the next step.

**System Guarantees**
1.  **Initial Condition:** Initially, the system starts in a state where no response to the car is pending.
2.  **Car Response:** Whenever the car is present while the green light is off, the system must eventually turn the green light on. The system must ensure that it returns to a state where this obligation is met infinitely often.
3.  **Car Absence:** The car signal must be false infinitely often.
