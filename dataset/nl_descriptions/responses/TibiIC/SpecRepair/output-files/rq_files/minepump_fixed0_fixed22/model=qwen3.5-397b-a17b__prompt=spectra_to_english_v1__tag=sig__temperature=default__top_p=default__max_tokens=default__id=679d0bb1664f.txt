

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system controls a pump based on environmental inputs regarding water levels and methane presence. The environment provides the boolean inputs `highwater` and `methane`, while the system controls the boolean output `pump`.

The environment is assumed to adhere to the following constraints:
1. If the `pump` was true in the previous step and remains true in the current step, the environment ensures that `highwater` becomes false in the next step.
2. Whenever the `pump` is false, the environment ensures that at least one of `highwater` or `methane` is false; specifically, it is not the case that both are true simultaneously.

The system must satisfy the following guarantees:
1. Whenever `highwater` is true, the system must ensure that the value of `pump` in the next step is either false or true.
2. Whenever `methane` is true, the system must ensure that `pump` is set to false in the next step.
