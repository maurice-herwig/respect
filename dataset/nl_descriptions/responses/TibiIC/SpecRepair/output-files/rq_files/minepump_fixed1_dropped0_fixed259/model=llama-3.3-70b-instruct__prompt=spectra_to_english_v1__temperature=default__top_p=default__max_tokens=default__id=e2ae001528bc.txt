The Minepump system interacts with its environment, which controls the `highwater` and `methane` conditions. The system controls the `pump` output. 

The environment is assumed to behave in such a way that if the water is high, then either the water will not be high in the next state or the pump was not running in the previous state.

The system must guarantee two conditions. Firstly, if methane is present, then either the pump must be turned on in the next state or the water is not high. Secondly, if methane is not present, then the pump must be turned off in the next state. 

These conditions must hold at all times, ensuring the system responds appropriately to the environmental conditions of methane presence and water level, while the environment follows its assumed behavior regarding water level changes in relation to the pump's state.
