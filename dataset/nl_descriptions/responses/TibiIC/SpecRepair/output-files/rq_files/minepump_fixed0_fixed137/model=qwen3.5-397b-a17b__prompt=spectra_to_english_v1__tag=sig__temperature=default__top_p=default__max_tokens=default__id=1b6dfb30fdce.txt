

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system manages a pump based on environmental conditions regarding water levels and methane presence. The environment controls the `highwater` and `methane` inputs, while the system controls the `pump` output.

The environment behavior is constrained by the following assumptions:
1. If the pump is on in the current step and was also on in the previous step, the `highwater` condition must become false in the next step.
2. Whenever the `pump` is on, either `highwater` is false or `methane` is false.

The system must satisfy the following guarantees:
1. Whenever `highwater` is true, either `methane` is true or the `pump` must be set to true in the next step.
2. Whenever `methane` is true, the `pump` must be set to false in the next step.
