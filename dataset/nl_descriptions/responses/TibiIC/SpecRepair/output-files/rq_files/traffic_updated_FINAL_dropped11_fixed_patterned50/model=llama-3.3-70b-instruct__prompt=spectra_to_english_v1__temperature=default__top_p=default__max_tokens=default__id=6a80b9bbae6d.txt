The TrafficE2 system is a reactive system that controls traffic lights at an intersection. The environment provides inputs indicating the presence of cars A and B, and whether there is an emergency. The system controls the traffic lights, setting them to green for either car A or car B.

The environment is expected to behave in certain ways: it should not have emergencies often, and when an emergency occurs, cars A and B should not move when their respective lights are red. Additionally, when the emergency light is on, cars A and B should not start moving when their lights are green.

The system must guarantee several conditions. First, it must ensure that both traffic lights are never red at the same time. Second, when car A is present, the system should eventually set its light to green. Similarly, when car B is present, the system should eventually set its light to green. Finally, during an emergency, both lights should be red.

The system starts in a state where it is prepared to respond to the presence of cars. When a car is present and its light is not green, the system moves to a state where it is waiting for the car's light to turn green. Once the light turns green, the system returns to its initial state, ready to respond to the next car. The system repeatedly returns to this initial state, ensuring that it always responds to the presence of cars.
