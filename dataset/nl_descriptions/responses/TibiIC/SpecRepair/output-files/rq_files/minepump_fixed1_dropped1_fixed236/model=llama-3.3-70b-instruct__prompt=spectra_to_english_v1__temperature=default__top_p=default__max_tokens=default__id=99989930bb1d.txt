The Minepump system interacts with an environment that controls two inputs: highwater and methane, which indicate the presence of high water and methane, respectively. The system controls one output: pump, which represents the state of a pump.

The environment is assumed to behave in such a way that if the pump is not running, then either the high water condition will not be present in the next state or the pump will still not be running.

The system must satisfy two guarantees. Firstly, if methane is detected, then the pump must be turned on in the next state, unless the high water condition is not present. Secondly, if methane is not detected, then the pump must be turned off in the next state.

In summary, the system must control the pump based on the presence of methane and high water, while the environment's behavior is constrained to ensure that the pump's state affects the high water condition in a specific way.
