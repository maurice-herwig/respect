

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system controls a pump based on environmental inputs regarding water and methane levels. The environment provides the `highwater` and `methane` signals, while the system controls the `pump` output. The behavior of the system and the constraints on the environment are defined as follows:

**Environment Assumptions**
The environment is assumed to behave according to these rules:
1.  Always, if the pump was true in the previous step and is true in the current step, then `highwater` will be false in the next step.
2.  Always, if `methane` is false, then either `highwater` is false or `methane` is false.

**System Guarantees**
The system must satisfy these requirements at all times:
1.  Always, if `highwater` is true, then either the `pump` is false or the `pump` will be true in the next step.
2.  Always, if `methane` is true, then either the `pump` is true or the `pump` will be false in the next step.
