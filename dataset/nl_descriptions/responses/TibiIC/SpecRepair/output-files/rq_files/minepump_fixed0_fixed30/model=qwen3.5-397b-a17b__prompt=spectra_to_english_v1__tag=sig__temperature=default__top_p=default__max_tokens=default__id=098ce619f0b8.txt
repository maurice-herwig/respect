

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system controls a pump based on environmental water and methane levels. The system operates continuously, reacting to changes in the environment variables `highwater` and `methane` by updating the system variable `pump`.

**System Guarantees**
The system must satisfy the following requirements at all times:
1.  Whenever `highwater` is true, the system must set `pump` to true in the next step.
2.  Whenever `methane` is true, the system must set `pump` to false in the next step.

**Environment Assumptions**
The system behavior is guaranteed only when the environment satisfies the following constraints at all times:
1.  If `pump` was true in the previous step and remains true in the current step, the environment must ensure `highwater` is false in the next step.
2.  Whenever `methane` is false, it must be the case that either `highwater` is false or `methane` is false.
3.  Whenever `highwater` is false, it must be the case that either `highwater` is false or `methane` is false.
4.  Whenever `pump` is true, it must be the case that either `highwater` is false or `methane` is false.
5.  Whenever `methane` was true in the previous step, it must be the case that either `highwater` is false or `methane` is false.
