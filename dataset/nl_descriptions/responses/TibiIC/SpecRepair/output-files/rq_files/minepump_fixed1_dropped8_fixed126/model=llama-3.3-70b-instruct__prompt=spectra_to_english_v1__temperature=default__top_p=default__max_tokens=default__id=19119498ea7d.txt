The Minepump system is a reactive system that interacts with its environment, which controls the presence of high water and methane. The system controls the operation of a pump. 

The environment provides two inputs: highwater and methane, which indicate whether the water level is high and whether methane is present, respectively.

The system has one output: pump, which indicates whether the pump is operating or not.

The environment is assumed to behave in a way that if the pump is not operating, it will not start operating unless it was already not operating in the previous state.

The system guarantees two conditions. Firstly, at all times, the pump will either continue to be off or turn on in the next state. 

Secondly, whenever the water level is high or methane is present, the system will ensure that the pump will turn off in the next state, unless neither condition is true.

Initially, there are no specific conditions specified for the system or environment. At all times, the system will adhere to these guarantees, given the environment's behavior.
