

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

**Requirements Description**

The Minepump system controls a pump based on environmental inputs regarding water levels and methane gas presence. The system operates continuously, reacting to the environment at each step.

**Environment Assumptions**
The environment is assumed to satisfy the following constraint at all times:
- If methane will be detected in the next step, then either the water level will not be high in the next step or the pump was off in the previous step.

**System Guarantees**
The system must ensure the following behaviors hold globally:
- If methane is not currently detected and the water level is currently high, the pump must be on in the next step.
- If methane is currently detected, the pump must be off in the next step.
