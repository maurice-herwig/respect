

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system controls a pump based on environmental inputs regarding water levels and methane gas. The environment provides the boolean inputs `highwater` and `methane`, while the system controls the boolean output `pump`.

The environment is assumed to satisfy specific global conditions regarding the relationship between its inputs and the system's output. Whenever `highwater` is true, it must be the case that either the `pump` is currently off or it was off in the previous state. Similarly, whenever `methane` is true, it must be the case that either the `pump` is currently off or it was off in the previous state. Additional assumptions specify that whenever the `pump` is off, logical conditions regarding its current or previous state hold.

The system must satisfy the following guarantees at all times. First, the system must ensure that the `pump` is turned on in the next state. Second, the system must ensure that if `methane` is true, the `pump` is turned off in the next state. These requirements define the safety and liveness behavior expected of the system whenever the environment adheres to its assumptions.
