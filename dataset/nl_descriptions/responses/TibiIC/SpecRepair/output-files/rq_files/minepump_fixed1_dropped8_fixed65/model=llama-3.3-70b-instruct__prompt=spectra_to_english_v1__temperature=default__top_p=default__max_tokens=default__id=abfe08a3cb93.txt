The environment also assumes that if the pump is off and there is high water, it will remain off, considering it was off previously. Furthermore, if the pump is off and methane is expected to be present in the next state, the pump will remain off, provided it was off in the previous state.

The system guarantees two main behaviors. Firstly, it will always ensure that the pump will be turned on at some point in the future. Secondly, if there is methane, the system guarantees that the pump will be turned off in the next state.
