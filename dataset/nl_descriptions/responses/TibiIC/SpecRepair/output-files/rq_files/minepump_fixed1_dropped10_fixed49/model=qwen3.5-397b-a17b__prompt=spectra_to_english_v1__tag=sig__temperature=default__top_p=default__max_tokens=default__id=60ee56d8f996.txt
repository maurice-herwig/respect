

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system controls the boolean output `pump` based on the boolean inputs `highwater` and `methane` provided by the environment.

The specification operates under the assumption that globally, whenever `highwater` is false, the `pump` is false.

The system must satisfy the following guarantees globally:
1. If `methane` is false, then `pump` must be true in the next step.
2. If `methane` is true, then `pump` must be false in the next step.
