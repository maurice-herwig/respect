The TrafficE2 system is a reactive system that interacts with its environment, which controls the presence of a car, emergency situations, and police presence. The system controls the state of a traffic light, specifically whether it is green.

The environment is expected to behave in certain ways. It should not have police presence indefinitely, allowing for periods without police. When the traffic light is not green, the car should not start moving unless there is an emergency or the light turns green, or the car remains stationary. Additionally, when the car is moving and the light was previously green, the car should stop if the police are present or the light turns red.

The system guarantees that it will respond to the presence of a car by eventually turning the traffic light green when a car is present. This response is governed by a state machine that ensures the system remains in a safe state. Initially, the system starts in a state where it can respond to the car's presence. The system then continuously checks for the car's presence and its own state to determine the next course of action. If a car is present and the light is not green, the system transitions to a state where it must turn the light green. Once the light is green, the system returns to its initial state, allowing it to respond to the car's presence again. The system ensures that it infinitely often returns to this initial responsive state.

The traffic light should initially be in a state where it can respond to cars, and it should always maintain a safe state, either by being responsive to cars when they are present or by turning green when a car is waiting. The system's guarantee of turning the light green when a car is present should happen infinitely often, ensuring that cars are not indefinitely ignored.
