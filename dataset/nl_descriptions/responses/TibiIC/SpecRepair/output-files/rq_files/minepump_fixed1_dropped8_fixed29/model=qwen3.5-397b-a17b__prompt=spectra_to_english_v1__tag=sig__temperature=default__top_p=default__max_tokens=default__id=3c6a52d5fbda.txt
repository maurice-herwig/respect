

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump specification describes a reactive system where the environment controls the boolean input variables `highwater` and `methane`, and the system controls the boolean output variable `pump`. The behavior of the system is defined by assumptions placed on the environment and guarantees required from the system.

Regarding the environment, it is assumed that whenever the `highwater` signal is true, either the `pump` is currently false or the `pump` was false in the previous step. This condition must hold at all times during the system operation.

The system must satisfy two main guarantees globally. First, whenever the `highwater` signal is true, the system must set the `pump` to true in the next step. Second, whenever both the `highwater` signal and the `methane` signal are true, the system must set the `pump` to false in the next step. These requirements define the safety and response behavior of the pump controller relative to the water and methane sensor inputs.
