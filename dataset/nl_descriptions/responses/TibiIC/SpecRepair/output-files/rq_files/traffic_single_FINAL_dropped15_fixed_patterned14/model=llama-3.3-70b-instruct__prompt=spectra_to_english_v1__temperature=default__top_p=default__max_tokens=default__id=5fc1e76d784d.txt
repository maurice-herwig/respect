The TrafficE2 system is a reactive system that interacts with its environment, which controls the presence of a car, emergency situations, and police presence. The system controls the state of a traffic light, indicated by the green signal.

The environment is assumed to behave in certain ways: when the traffic light is not green, the car will not move unless there is an emergency or the car is already moving. Additionally, the environment ensures that if the car is about to move, it will do so only if there is an emergency, the car is already moving, or the traffic light is about to turn green.

The system guarantees two main behaviors: the traffic light will turn green often when a car is present, and there will be periods where no car is present. 

Initially, the system is in a state where it is ready to respond to the car's presence. The system's behavior is characterized by the following rules: 
- When the system is waiting for a car and a car is present, it will turn the traffic light green.
- If a car is present and the traffic light is not green, the system will transition to a state where it is waiting for the traffic light to turn green.
- Once the traffic light turns green, the system will return to its initial state, ready to respond to the next car.
- The system will always eventually return to its initial state, ensuring that it can respond to cars in a timely manner.
