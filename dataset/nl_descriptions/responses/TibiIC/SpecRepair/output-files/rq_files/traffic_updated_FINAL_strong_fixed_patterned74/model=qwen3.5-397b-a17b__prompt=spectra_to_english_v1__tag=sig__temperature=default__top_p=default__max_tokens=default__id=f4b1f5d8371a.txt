

Specification name: TrafficE2

Environment variables:
- carA: boolean
- carB: boolean
- emergency: boolean

System variables:
- greenA: boolean
- greenB: boolean

This specification defines a reactive traffic light control system for two lanes. The environment provides inputs indicating the presence of cars in lane A (`carA`) and lane B (`carB`), as well as an `emergency` signal. The system controls the green light outputs for lane A (`greenA`) and lane B (`greenB`).

**Environment Assumptions**
The environment behaves according to the following constraints:
1.  **Emergency Signal:** The condition `emergency=false` occurs infinitely often; the emergency mode is not permanently active.
2.  **Car A Dynamics:**
    *   If `carA` is true and `greenA` is false, `carA` remains true in the next step.
    *   If `carA` is true and `greenA` is true, `carA` becomes false in the next step.
3.  **Car B Dynamics:**
    *   If `carB` is true, `greenB` is false, and `carA` is true, `carB` remains true in the next step.
    *   If `carB` is true and `greenB` is true, `carB` becomes false in the next step.

**System Guarantees**
The system must satisfy the following requirements whenever the environment satisfies its assumptions:
1.  **Mutual Exclusion:** At all times, either `greenA` is false or `greenB` is false. The lights `greenA` and `greenB` are never true simultaneously.
2.  **Emergency Response:** Whenever `emergency` is true, both `greenA` and `greenB` must be false.
3.  **Lane A Response:** Whenever `carA` is true, `greenA` must eventually become true.
4.  **Lane B Response:** Whenever `carB` is true, `greenB` must eventually become true.
