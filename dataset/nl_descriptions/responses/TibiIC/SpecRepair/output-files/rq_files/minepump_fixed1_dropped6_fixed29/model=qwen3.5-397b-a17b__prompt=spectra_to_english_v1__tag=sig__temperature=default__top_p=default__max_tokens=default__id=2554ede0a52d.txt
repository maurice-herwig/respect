

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump specification describes a reactive controller that manages a pump based on environmental sensor inputs. The environment controls the boolean inputs `highwater` and `methane`, while the system controls the boolean output `pump`.

**Environment Assumptions**
The environment must adhere to the following constraint at all times: whenever the `highwater` signal is true, the `pump` must have been false in the immediately preceding step.

**System Guarantees**
The system must satisfy the following requirements at all times:
1. If `methane` is false and `highwater` is true, then the `pump` must be true in the next step.
2. If `methane` is true, then the `pump` must be false in the next step.
