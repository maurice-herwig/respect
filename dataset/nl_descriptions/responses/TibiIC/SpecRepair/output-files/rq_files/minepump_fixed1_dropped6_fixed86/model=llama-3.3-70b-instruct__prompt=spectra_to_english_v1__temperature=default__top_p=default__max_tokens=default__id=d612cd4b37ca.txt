The Minepump system interacts with its environment, which controls the presence of high water and methane. The system controls the operation of a pump. 

The environment is expected to behave in a way that when there is no high water, it will not have had the pump on previously if it is currently not flooded. 

The system must ensure two conditions: 
- If methane is present, then either the pump will be turned on at the next step or there is high water, 
- If there is no methane, then the pump will be turned off at the next step. 

In summary, the environment controls the levels of water and methane, and the system controls the pump. The system's behavior is constrained by the guarantees that it must turn on the pump when methane is present unless there is high water, and turn off the pump when there is no methane. The environment's behavior is constrained by the assumption that it will not have previously turned on the pump when there is no high water.
