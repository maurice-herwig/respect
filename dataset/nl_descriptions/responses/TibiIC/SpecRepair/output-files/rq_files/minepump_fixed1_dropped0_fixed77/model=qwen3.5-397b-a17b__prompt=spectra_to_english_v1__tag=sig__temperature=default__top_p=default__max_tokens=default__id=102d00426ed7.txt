

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system controls a pump based on environmental inputs regarding water levels and methane presence. The environment provides the current status of the water level and methane detection, while the system determines the state of the pump.

**Environment Assumptions**
The environment is assumed to behave according to the following constraint: Whenever the pump is on, if it was also on in the previous step, then the water level must not be high in the next step. This ensures that continuous pumping leads to a reduction in water level.

**System Guarantees**
The system must satisfy the following requirements at all times:
1. If methane is not present and the water level is high, the pump must be turned on in the next step.
2. If methane is present, the pump must be turned off in the next step.

These guarantees ensure that the pump activates to lower high water levels when safe to do so, and immediately deactivates upon methane detection to prevent hazards.
