The Minepump system interacts with its environment, which controls the presence of high water and methane. The system controls the pump. The environment is assumed to behave in a way that when there is no methane, if the pump was not running in the previous state, then there will be no high water in the next state.

The system must guarantee two conditions. Firstly, if methane is present, then the pump must be turned on in the next state. Secondly, if there is no methane, then the pump must be turned off in the next state. These conditions ensure that the pump's operation is directly tied to the presence or absence of methane, providing a basic safety mechanism against the dangers of methane when the pump is not running.
