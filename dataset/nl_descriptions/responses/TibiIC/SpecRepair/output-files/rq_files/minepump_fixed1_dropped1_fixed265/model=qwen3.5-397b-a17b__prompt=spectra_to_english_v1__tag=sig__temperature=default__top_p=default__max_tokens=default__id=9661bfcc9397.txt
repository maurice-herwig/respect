

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

This specification describes the control logic for a mine pump system. The environment provides input signals indicating whether the water level is high and whether methane gas is present. The system controls the output signal that determines whether the pump is active.

**Environment Assumptions**
The environment is assumed to satisfy the following condition regarding the water level: whenever the water level is not high, if the pump is currently on, then the water level must remain not high in the next step.

**System Guarantees**
The system must ensure the following conditions hold at all times:
1. If methane is not present and the water level is high, the pump must be turned on in the next step.
2. If methane is present, the pump must be turned off in the next step.
