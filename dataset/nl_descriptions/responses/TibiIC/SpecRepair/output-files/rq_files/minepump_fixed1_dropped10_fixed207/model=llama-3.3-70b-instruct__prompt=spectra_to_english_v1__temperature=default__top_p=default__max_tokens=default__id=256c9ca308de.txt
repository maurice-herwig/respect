The Minepump system interacts with an environment that controls two inputs: highwater and methane. The system controls one output: pump. 

The environment is assumed to behave in such a way that if the pump is currently off, it will remain off, at least until the system decides to turn it on.

The system must guarantee two conditions. Firstly, if methane is present, the pump must be turned on at the next opportunity. Secondly, if there is no methane, the pump must be turned off at the next opportunity.

Note that the highwater input from the environment does not have any specified requirements or assumptions associated with it in this specification.
