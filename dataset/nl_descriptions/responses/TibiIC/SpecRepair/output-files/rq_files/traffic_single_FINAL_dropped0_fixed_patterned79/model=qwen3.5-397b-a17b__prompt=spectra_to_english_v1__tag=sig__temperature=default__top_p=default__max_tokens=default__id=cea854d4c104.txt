

Specification name: TrafficE2

Environment variables:
- car: boolean
- emergency: boolean
- police: boolean

System variables:
- green: boolean

The system controls the `green` traffic light signal based on inputs from the environment regarding car presence (`car`), emergency status (`emergency`), and police presence (`police`).

**Environment Assumptions**
The environment is assumed to satisfy the following conditions:
1.  **Police Presence:** The police signal will be false infinitely often.
2.  **Car Stability at Red:** If a car is currently present, there is no emergency, and the green light is off, the car must remain present in the next time step.
3.  **Car Movement Constraints (Previous Emergency):** If the emergency signal was false in the previous step, then either the car is currently absent, the car will be absent in the next step, or the green light is currently off.
4.  **Car Movement Constraints (Current Emergency):** If the emergency signal is currently true, then either the car is currently absent, the car will be absent in the next step, or the green light is currently off.

**System Guarantees**
The system must satisfy the following requirements:
1.  **Response to Car:** Whenever a car is present, the green light must eventually turn on. The system internally tracks this request starting from an initial ready state. It must ensure that every request triggered by a car's presence is eventually granted by turning the green light on, returning to the ready state infinitely often.
2.  **Car Absence:** The condition where the car is absent must occur infinitely often.
