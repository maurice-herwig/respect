The TrafficE2 system is a reactive system that interacts with its environment, which controls the presence of a car, emergency situations, and police interventions. The system controls the state of a traffic light, indicated by the green signal.

The environment is assumed to behave in certain ways: it is expected that there will be periods where police are not present, and this will happen infinitely often. Additionally, when the car is not present, it will either remain absent or become present only if there is an emergency or if it was already going to become present. The environment is also assumed to ensure that if a car is not present, it will either remain absent or continue to be absent in the next moment.

The system guarantees that it will respond to the presence of a car by eventually turning the traffic light green. This response is governed by a pattern that describes the system's behavior in terms of its state, which can be either S0 or S1. Initially, the system is in state S0. The system remains in state S0 as long as there is no car present or if a car is present and the light is green. If a car is present and the light is not green, the system transitions to state S1. In state S1, the system will turn the light green, and once it does, it will return to state S0. The system will infinitely often be in state S0, ensuring that it periodically responds to the presence of a car by turning the light green.

The environment-controlled inputs are the presence of a car, emergency situations, and police interventions. The system-controlled output is the state of the traffic light, indicated by the green signal.
