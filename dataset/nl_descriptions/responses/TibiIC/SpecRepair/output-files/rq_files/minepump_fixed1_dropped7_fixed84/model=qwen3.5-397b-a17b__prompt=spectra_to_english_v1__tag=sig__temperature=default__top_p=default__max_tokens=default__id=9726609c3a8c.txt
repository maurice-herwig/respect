

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The system continuously monitors the environment variables to determine the correct state for the system variables. The behavior is constrained by the following assumptions and guarantees.

**Assumptions**
The specification assumes that whenever the methane variable is true, the pump variable is either currently false or was false in the immediately preceding step. This restricts the operating conditions under which the system guarantees must hold.

**Guarantees**
The system must ensure the following behavior at all times regarding the pump variable in the next step based on the current state of the methane variable:
1. If the methane variable is false, the pump variable must be true in the next step.
2. If the methane variable is true, the pump variable must be false in the next step.

There are no specific initial conditions defined; the guarantees apply to all steps in the system execution. The highwater variable is available as an input but does not constrain the specified behavior.
