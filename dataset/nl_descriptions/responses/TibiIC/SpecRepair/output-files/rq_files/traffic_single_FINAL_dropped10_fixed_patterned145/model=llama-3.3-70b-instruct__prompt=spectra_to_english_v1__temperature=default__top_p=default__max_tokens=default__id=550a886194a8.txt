The TrafficE2 system is a reactive system that interacts with its environment, which controls the presence of a car, emergency situations, and police presence. The system controls the state of a traffic light, specifically whether it is green.

The environment is expected to behave in certain ways. Specifically, it is assumed that the police will not be present indefinitely, and there will be times when they are not present. Additionally, the environment is assumed to ensure that a car is not present when the traffic light is not green, unless there is an emergency or the car is already moving. The environment is also expected to ensure that when the traffic light is green, either the police are present, there is no car, or the car will move on the next step.

The system guarantees certain behavior. The traffic light will turn green when a car is present, and this will happen repeatedly over time. Furthermore, the system ensures that there will be times when there is no car present.

Initially, the system starts in a state where it is not responding to the presence of a car. The system then enters a loop where it either remains in this state if there is no car or if a car is present and the traffic light is green, or it transitions to a new state if a car is present and the traffic light is not green. If the system is in this new state, it will remain there until the traffic light turns green, at which point it will return to the initial state. The system will repeatedly return to its initial state over time.
