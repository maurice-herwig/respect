The Minepump system is a reactive system that interacts with its environment, which controls the presence of high water and methane. The system controls the operation of a pump. 

The environment provides two inputs: highwater and methane, which indicate whether the water level is high and whether methane is present, respectively. The system has one output: pump, which indicates whether the pump is operating.

The environment is assumed to behave in such a way that if the pump is not operating, it will not start operating unless it was already operating in the previous state or it is not operating in the current state and was not operating in the previous state.

The system must satisfy two guarantees. Firstly, if methane is present, the pump must start operating in the next state, unless the water level is not high. Secondly, if methane is not present, the pump must not operate in the next state. 

In summary, the system must ensure that the pump operates when methane is present and the water level is high, and stops operating when methane is not present, under the assumption that the environment does not spontaneously start the pump.
