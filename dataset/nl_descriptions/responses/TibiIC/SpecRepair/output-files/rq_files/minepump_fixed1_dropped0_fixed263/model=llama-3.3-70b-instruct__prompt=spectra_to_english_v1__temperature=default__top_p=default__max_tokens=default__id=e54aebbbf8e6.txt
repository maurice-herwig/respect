The Minepump system operates in an environment where water levels and methane presence are monitored. The environment controls the detection of high water levels and methane presence. In response, the system controls the operation of a pump.

The environment is expected to behave in a way that when the water level is high, it will eventually decrease, but only if the pump was not previously running.

The system must ensure two main guarantees. Firstly, if methane is detected, the pump must be turned on at the next opportunity, unless the water level is not high. Secondly, if no methane is detected, the pump must be turned off at the next opportunity.

Initially, there are no specified conditions. However, the system must always adhere to these guarantees, ensuring safe operation based on the environmental conditions of water level and methane presence.
