

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump specification describes a reactive system where the environment controls the boolean inputs `highwater` and `methane`, and the system controls the boolean output `pump`.

The specification includes an assumption regarding the system context. At every point in time, it is assumed that if the pump is off, then either the pump is off or it was off in the previous step.

The system must satisfy two guarantees. First, at every point in time, the system must ensure that the pump is turned on in the next step. Second, at every point in time, the system must ensure that either the pump is turned on in the next step, methane is not present, or the pump is turned off in the next step.
