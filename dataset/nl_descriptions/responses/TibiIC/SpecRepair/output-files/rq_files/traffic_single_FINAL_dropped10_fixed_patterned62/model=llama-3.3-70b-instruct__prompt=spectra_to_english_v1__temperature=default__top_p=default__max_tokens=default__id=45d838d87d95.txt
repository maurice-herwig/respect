The TrafficE2 system is a reactive system that interacts with its environment, which controls the presence of a car, emergency situations, and police presence. The system controls the state of a traffic light, specifically whether it is green.

The environment is assumed to behave in certain ways. It is expected that the police will not be present infinitely often. Additionally, when the traffic light is not green, the car will not start moving unless there is an emergency or the car is already moving. When the traffic light is green, the car will move only if there is no police presence or if the car is already moving and will continue to move.

The system guarantees two main behaviors. Firstly, it will ensure that the traffic light turns green often, and when it does, the car will be present and allowed to move. Secondly, the system guarantees that there will be periods where there is no car present.

Initially, the system starts in a state where it is ready to respond to the car's presence. The system then continuously checks for the car's presence and the traffic light's state. If the car is present and the traffic light is not green, the system will transition to a state where it waits for the traffic light to turn green. Once the traffic light turns green, the system will return to its initial state, allowing the car to move. If the car is not present when the traffic light is green, the system will remain in its initial state. The system will infinitely often return to its initial state, ensuring that it is always ready to respond to the car's presence.
