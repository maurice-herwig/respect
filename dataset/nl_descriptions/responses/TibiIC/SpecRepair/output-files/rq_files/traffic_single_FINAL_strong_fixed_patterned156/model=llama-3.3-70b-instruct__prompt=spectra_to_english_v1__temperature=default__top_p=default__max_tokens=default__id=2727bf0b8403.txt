The TrafficE2 system is a reactive system that interacts with its environment, which controls the presence of a car, emergency situations, and police interventions. The system controls the state of a traffic light, specifically whether it is green or not.

The environment is expected to behave in certain ways. Specifically, it is assumed that there will be periods where police are not present. Additionally, when the traffic light is not green and there is no emergency, if a car is present, it will remain present in the next state. On the other hand, when the traffic light is green and a car is present, the car will move and not be present in the next state.

The system guarantees certain behaviors. Firstly, it ensures that the traffic light will often be green when a car is present, meaning that the system will periodically respond to the presence of a car by turning the traffic light green. Secondly, the system guarantees that there will often be periods where no car is present.

Initially, the system starts in a state where it is not responding to any stimulus. The system then enters a loop where it either remains in this state if there is no car or if a car is present and the traffic light is green, or it transitions to a different state if a car is present and the traffic light is not green. If the system is in this different state, it will remain there until the traffic light turns green, at which point it will transition back to the initial state. The system will infinitely often return to its initial state.
