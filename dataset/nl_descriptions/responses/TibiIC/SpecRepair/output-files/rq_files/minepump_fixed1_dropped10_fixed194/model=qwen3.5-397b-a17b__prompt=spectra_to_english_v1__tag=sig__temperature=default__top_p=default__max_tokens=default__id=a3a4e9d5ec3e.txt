

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system controls the `pump` output based on the `highwater` and `methane` inputs provided by the environment. The behavior is constrained by the following assumptions and guarantees.

**Assumptions**
It is assumed that throughout the operation of the system, whenever the `highwater` input is true, the `pump` output is false.

**Guarantees**
The system must satisfy the following conditions at all times:
1. If the `methane` input is false, the `pump` output must be true in the immediately following state.
2. If the `methane` input is true, the `pump` output must be false in the immediately following state.
