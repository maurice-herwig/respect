The TrafficE2 system is a reactive system that interacts with its environment, which controls the presence of a car, emergency situations, and police presence. The system controls the state of a traffic light, specifically whether it is green.

The environment is expected to behave in certain ways. Firstly, if a car is present, it will either continue to be present or an emergency situation will occur, or the car will leave, until the traffic light turns green. Secondly, if a car is not present, it will either remain absent or not arrive, or the traffic light will not be green.

The system guarantees that it will often respond to the presence of a car by turning the traffic light green. This means that whenever a car is present, the system will eventually turn the traffic light green, and this will happen infinitely often.

Initially, the system is in a state where it is not responding to the car's presence. The system's behavior is defined by a set of rules that determine its next state based on its current state and the presence of a car. If the system is not responding to the car's presence and the car is present but the traffic light is not green, it will transition to a state where it is waiting for the traffic light to turn green. If the system is waiting for the traffic light to turn green and the traffic light does turn green, it will transition back to the state where it is not responding to the car's presence.

The system's safety requirements ensure that it will always be in one of these two states, and that it will transition between them according to the rules defined above. The system's liveness requirement ensures that it will eventually return to the state where it is not responding to the car's presence, which means that the traffic light will turn green infinitely often when a car is present.
