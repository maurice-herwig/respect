

Specification name: TrafficE2

Environment variables:
- car: boolean
- emergency: boolean
- police: boolean

System variables:
- green: boolean

**Requirements Description**

This specification defines the behavior of a traffic light system interacting with vehicles and police presence. The system controls the green light signal based on environment inputs indicating the presence of a car, an emergency, or police.

**Assumptions on the Environment**
The environment is assumed to adhere to the following constraints:
1.  **Police Presence:** The police signal will be false infinitely often; police presence is not permanent.
2.  **Car Behavior at Red Light:** If a car is present, the green light is off, and no police are present, the car remains present in the next moment.
3.  **Car Behavior at Green Light:** If a car is present and the green light is on, the car will not be present in the next moment.

**Guarantees from the System**
The system must satisfy the following requirements:
1.  **Response to Vehicles:** Whenever a car is present, the system must eventually turn the green light on.
2.  **Car Absence Frequency:** The system guarantees that the car signal will be false infinitely often.

**Variable Interface**
The system interacts with the environment through the following variables:
*   **Inputs (Environment):** `car`, `emergency`, and `police` are boolean signals controlled by the environment.
*   **Outputs (System):** `green` is a boolean signal controlled by the system.
