The Minepump system interacts with its environment, which controls the `highwater` and `methane` conditions. The system controls the `pump` output. 

The environment is assumed to behave in such a way that whenever the water is high, the pump is not activated. 

The system must guarantee two conditions: 
- If methane is present, then the pump must be activated at the next step.
- If methane is not present, then the pump must not be activated at the next step.

In other words, the pump's activation is directly tied to the presence or absence of methane, with the system ensuring that the pump's state is updated accordingly in response to changes in the methane condition.
