

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system controls a pump output based on environment inputs indicating water levels and methane presence. The environment controls the boolean inputs `highwater` and `methane`. The system controls the boolean output `pump`.

The environment is assumed to satisfy specific behavioral constraints. Always, if the `pump` output was true in the previous step and remains true in the current step, then the `highwater` input will be false in the next step. Additionally, the environment ensures that whenever `highwater` is false, either `highwater` is false or `methane` is false.

The system must satisfy the following guarantees whenever the environment satisfies its assumptions. Always, if the `highwater` input is true, then either the `pump` output is currently false or the `pump` output must be true in the next step. Furthermore, always, if the `methane` input is true, then either the `highwater` input is true or the `pump` output must be false in the next step.
