

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system manages a pump based on environmental inputs regarding water levels and methane presence. The environment controls the `highwater` and `methane` signals, while the system controls the `pump` signal.

**Environment Assumptions**
The environment is assumed to satisfy the following constraint at all times: If the `highwater` signal was false in the previous step, then either the `highwater` signal will be false in the next step or the `pump` signal is currently false.

**System Guarantees**
The system must satisfy the following requirements at all times:
1. If `methane` is false and `highwater` is true, then the `pump` must be true in the next step.
2. If `methane` is true, then the `pump` must be false in the next step.
