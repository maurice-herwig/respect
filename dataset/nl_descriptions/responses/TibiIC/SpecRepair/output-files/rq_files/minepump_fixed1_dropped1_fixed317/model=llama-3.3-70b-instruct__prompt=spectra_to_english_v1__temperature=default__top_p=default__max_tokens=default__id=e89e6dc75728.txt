The Minepump system is a reactive system that interacts with its environment, which controls the presence of high water and methane. The system controls the pump. 

The environment is assumed to behave in such a way that if methane is present, then either the water level will not be high in the next state or the pump will be off. 

The system must guarantee two conditions. Firstly, if methane is present, then either the pump must be on in the next state or the water level must not be high. Secondly, if methane is not present, then the pump must be off in the next state. 

In this system, the environment-controlled inputs are the presence of high water and methane, while the system-controlled output is the state of the pump.
