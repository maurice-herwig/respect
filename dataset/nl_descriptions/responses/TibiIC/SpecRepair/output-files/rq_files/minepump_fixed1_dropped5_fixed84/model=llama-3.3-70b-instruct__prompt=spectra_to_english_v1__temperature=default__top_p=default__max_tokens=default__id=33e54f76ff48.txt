The Minepump system interacts with its environment, which controls the presence of high water and methane. The system controls the pump. 

The environment is assumed to behave in a way that when there is high water, it will either eventually stop being high water or the pump will be turned off.

The system must satisfy two guarantees. Firstly, if methane is present, then the pump must be turned on at the next opportunity. Secondly, if methane is not present, then the pump must be turned off at the next opportunity.

There are no specified initial conditions for the system. The system's behavior is defined by the relationship between the environment's conditions and the system's next-state actions, specifically regarding the pump's operation in response to methane presence or absence.
