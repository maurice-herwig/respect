

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The environment controls the `highwater` and `methane` inputs, while the system controls the `pump` output.

The specification imposes the following assumption on the behavior:
- Globally, if the pump is off, then either the pump is off or it was off in the previous step.

The system must satisfy the following guarantees globally:
- If `methane` is false at the current step, then `pump` must be true in the next step.
- If `methane` is true at the current step, then `pump` must be false in the next step.
