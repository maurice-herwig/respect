The TrafficE2 system is a reactive system that interacts with its environment, which controls the presence of a car, emergency situations, and police presence. The system controls the state of a traffic light, indicated by the green signal.

The environment is expected to behave in certain ways: it should not have police presence indefinitely, and there should be periods where there is no car. Additionally, the environment should ensure that a car is idle when the traffic light is not green, unless there is an emergency or the car is already moving. When a car is present, the environment should allow it to move when the traffic light is green, and if the car is moving, it should either continue moving or stop when the traffic light turns red.

The system guarantees that the traffic light will turn green whenever a car is present, and this will happen repeatedly. Furthermore, the system ensures that there will be periods where there is no car.

Initially, the system is in a state where it is ready to respond to the presence of a car. The system's behavior is characterized by the following rules: when a car is present and the traffic light is green, the system remains in its current state; when a car is present and the traffic light is not green, the system transitions to a state where it is waiting for the traffic light to turn green; when the traffic light is green, the system returns to its initial state; and when the traffic light is not green, the system remains in its waiting state. The system will repeatedly return to its initial state, ensuring that it responds to the presence of cars.
