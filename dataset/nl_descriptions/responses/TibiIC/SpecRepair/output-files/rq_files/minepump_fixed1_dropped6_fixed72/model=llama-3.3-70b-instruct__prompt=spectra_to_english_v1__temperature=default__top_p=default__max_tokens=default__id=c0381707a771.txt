The Minepump system is designed to operate in an environment where water levels and methane presence are monitored. The environment controls two inputs: `highwater`, indicating whether the water level is high, and `methane`, indicating whether methane is present. The system controls one output: `pump`, which determines whether the pump is active.

The environment is assumed to behave in a way that if the pump was not active in the previous state and is still not active in the current state, then it was also not active in the state before that.

The system guarantees two conditions. Firstly, if methane is present, then either the pump will be active in the next state or the water level is not high. This ensures that the pump will be activated when methane is detected, unless the water level is low. Secondly, if methane is not present, then the pump will not be active in the next state, ensuring that the pump is deactivated when there is no methane.

These guarantees define the system's behavior in response to the environment's inputs, ensuring safe operation of the mine pump.
