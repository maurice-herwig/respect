

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

This specification defines the requirements for a mine pump control system where the environment provides sensor readings and the system controls the pump actuator.

**Environment Assumptions**
The environment behavior is restricted by the following conditions:
1. At all times, if the pump is off, then either the pump is currently off or it was off in the previous step.
2. At all times, if methane is present, then either the pump is currently off or it was off in the previous step.

**System Guarantees**
The system must ensure the following behaviors hold globally:
1. At every step, the pump must be on in the next state.
2. At every step, either methane is absent or the pump must be off in the next state.
