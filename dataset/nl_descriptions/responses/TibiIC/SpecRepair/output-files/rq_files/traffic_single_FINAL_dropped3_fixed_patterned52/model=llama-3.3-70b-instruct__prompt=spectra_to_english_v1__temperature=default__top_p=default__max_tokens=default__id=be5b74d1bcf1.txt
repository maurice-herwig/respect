The TrafficE2 system is a reactive system that interacts with its environment, which controls the presence of a car, an emergency situation, and police intervention. The system controls the state of a traffic light, specifically whether it is green.

The environment is assumed to behave in certain ways. It is expected that police will not be present infinitely often. Additionally, when the traffic light is not green, a car will not start moving unless the light turns green or the car remains stationary. The environment is also assumed to ensure that if a car is not present, it will either remain absent or the traffic light will not be green when the car appears.

The system guarantees certain behavior. The traffic light will turn green whenever a car is present, although this may not happen immediately. Furthermore, the system ensures that there will be periods when no car is present.

The system's behavior regarding the traffic light can be described as follows. Initially, the system is in a state where it is not responding to the presence of a car. The system remains in this state as long as no car is present or a car is present and the light is green. If a car appears and the light is not green, the system transitions to a state where it is waiting for the light to turn green. Once the light turns green, the system returns to its initial state. The system will infinitely often be in its initial state, ensuring that it periodically responds to the presence of cars.
