

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump specification defines a reactive system where the environment controls the boolean inputs `highwater` and `methane`, and the system controls the boolean output `pump`. The behavior is governed by the following assumptions and guarantees:

**Assumptions**
The specification includes an assumption regarding the system's history: globally, whenever the pump is off, it must hold that either the pump is currently off or it was off in the previous step.

**Guarantees**
The system must satisfy the following requirements at every step of the interaction:
1.  **Next-State Definition:** The system must always define the state of the pump for the next step, ensuring it is either off or on.
2.  **Safety Condition:** If both the `highwater` and `methane` inputs are true, the system must ensure that the pump is off in the next step. Otherwise, there are no restrictions on the pump's next state imposed by this condition.
