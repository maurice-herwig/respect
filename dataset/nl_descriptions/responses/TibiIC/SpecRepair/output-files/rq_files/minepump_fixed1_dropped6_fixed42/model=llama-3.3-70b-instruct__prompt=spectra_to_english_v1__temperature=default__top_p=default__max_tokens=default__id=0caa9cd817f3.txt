The Minepump system interacts with its environment, which controls the presence of high water and methane. The system controls the pump. 

The environment is assumed to behave in a way that if the pump is off and was off in the previous state, then it was off in the previous state.

The system must satisfy two guarantees. Firstly, if methane is present, then either the pump must be turned on at the next state or there must be no high water. Secondly, if there is no methane, then the pump must be turned off at the next state.

In this system, the environment-controlled inputs are the presence of high water and methane, while the system-controlled output is the state of the pump.
