The Minepump system interacts with an environment that provides two inputs: highwater and methane, which indicate the presence of high water and methane, respectively. The system controls one output: pump, which represents the state of a pump.

The environment is assumed to behave in such a way that whenever methane is present, the pump was not active in the previous state.

The system must satisfy two guarantees. Firstly, if methane is present, then either the pump must be active in the next state or there must not be high water. Secondly, if methane is not present, then the pump must not be active in the next state.

In summary, the system must control the pump based on the presence of methane and high water, while the environment provides the necessary input signals. The system's behavior is constrained by the assumptions on the environment's behavior, ensuring safe operation of the pump.
