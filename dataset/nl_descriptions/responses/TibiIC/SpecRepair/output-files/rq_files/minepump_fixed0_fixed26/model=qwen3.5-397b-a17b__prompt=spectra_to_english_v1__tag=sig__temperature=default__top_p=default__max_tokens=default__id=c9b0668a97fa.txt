

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump specification describes a reactive system where the environment provides sensor inputs regarding water and gas levels, and the system controls a pump output.

**Environment Assumptions**
The environment behavior is restricted by the following assumptions:
1. If the pump was active in the previous step and remains active in the current step, then the highwater signal must be inactive in the next step.
2. If the pump was inactive in the previous step, then currently either the highwater signal is inactive or the methane signal is inactive.

**System Guarantees**
The system must satisfy the following requirements:
1. Whenever the highwater signal is active, the pump must be either inactive or active in the next step.
2. Whenever the methane signal is active, the pump must be inactive in the next step.
