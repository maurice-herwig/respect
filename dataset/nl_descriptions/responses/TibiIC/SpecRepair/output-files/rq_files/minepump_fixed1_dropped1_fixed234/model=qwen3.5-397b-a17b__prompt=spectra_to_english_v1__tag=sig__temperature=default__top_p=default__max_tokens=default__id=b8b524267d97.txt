

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The system operates under the following assumption regarding the environment behavior: always, if the water level signal `highwater` is true, then either the water level will not be high in the next step (`highwater` becomes false), or the `pump` is currently off.

The system must satisfy the following guarantees:
1. Always, if there is no methane (`methane` is false) and the water level is high (`highwater` is true), then the `pump` must be turned on (true) in the next step.
2. Always, if methane is present (`methane` is true), then the `pump` must be turned off (false) in the next step.
