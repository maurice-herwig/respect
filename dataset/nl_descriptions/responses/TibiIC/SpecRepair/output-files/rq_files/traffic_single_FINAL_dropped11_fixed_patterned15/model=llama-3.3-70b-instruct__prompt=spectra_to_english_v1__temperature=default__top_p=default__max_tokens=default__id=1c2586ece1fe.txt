The TrafficE2 system is a reactive system that interacts with its environment, which controls the presence of a car, emergency situations, and police presence. The system controls the state of a traffic light, specifically whether it is green.

The environment is expected to behave in certain ways. It should not have police present indefinitely, allowing for periods where police are not present. When a car is not present, it should remain absent, become present, or the traffic light should be green, unless there is an emergency. Additionally, if a car was previously present, it should either still be present, or the traffic light should not be green, unless police are present.

The system guarantees that it will often respond to the presence of a car by eventually turning the traffic light green. This means that whenever a car is present, the system will ensure that the traffic light turns green, but it may go through a sequence of states to achieve this. Initially, the system starts in a state where it is not responding to the car's presence. The system then follows specific rules to update its state: if a car is present and the light is not green, it moves to a state where it is trying to respond; if the light becomes green while in this state, it returns to its initial state. The system ensures that it periodically returns to its initial state, indicating that it has responded to the car's presence.
