The TrafficE2 system is a reactive system that interacts with its environment, which controls the presence of a car, emergency situations, and police presence. The system controls the state of a traffic light, specifically whether it is green.

The environment is assumed to behave in certain ways. Specifically, when the car is not present, it will either remain absent or become present only if there is an emergency. Additionally, when the car is present and the light is not green, the car will move only if the light turns green or if the car was already moving.

The system guarantees that it will often respond to the presence of a car by turning the light green. This means that whenever a car is present, the system will eventually turn the light green, unless the car is no longer present.

Initially, the system is in a state where it is not responding to the car's presence. The system remains in this state as long as there is no car present or if a car is present and the light is green. If a car is present and the light is not green, the system transitions to a state where it is waiting for the car to be served. In this waiting state, the system will turn the light green, allowing the car to pass. Once the light is green, the system returns to its initial state, ready to respond to the next car. The system will infinitely often return to its initial state, ensuring that it regularly responds to the presence of cars.
