The TrafficE2 system is a reactive system that interacts with its environment, which controls the presence of a car, emergency situations, and police interventions. The system controls the traffic light, which can be either green or not.

The environment is expected to behave in certain ways. Specifically, it is assumed that police interventions do not occur frequently, and there are periods where police are not present. Additionally, when the traffic light is not green, the car should not move unless there is an emergency. When the traffic light is green, the car should move, but if the police intervene or an emergency occurs, the car should stop. If there is no emergency, the car should stop when the police are present or when the traffic light is not green.

The system guarantees that the traffic light will turn green when a car is present, and this will happen repeatedly. The system also guarantees that there will be periods where there is no car.

Initially, the system is in a state where it is waiting for a car to arrive. The system then responds to the presence of a car by turning the traffic light green, but only if the car is present. If the car is present and the traffic light is not green, the system will transition to a state where it is waiting for the traffic light to turn green. Once the traffic light is green, the system will return to its initial state. The system will always eventually return to its initial state, ensuring that the traffic light turns green repeatedly when a car is present.
