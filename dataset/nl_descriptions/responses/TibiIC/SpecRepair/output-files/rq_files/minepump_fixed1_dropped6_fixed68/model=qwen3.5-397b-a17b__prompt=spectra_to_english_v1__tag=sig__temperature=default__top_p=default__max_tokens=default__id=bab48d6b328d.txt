

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system manages a pump based on environmental conditions regarding water levels and methane gas presence. The environment provides boolean inputs `highwater` and `methane`, while the system controls the boolean output `pump`.

The specification imposes the following assumption on the environment behavior: whenever the `highwater` signal is false, the `pump` must have been false in the immediately preceding step.

The system must satisfy the following guarantees regarding the state of the `pump` in the next step:
1. If `methane` is true, the system must set `pump` to false in the next step.
2. If `methane` is false and `highwater` is true, the system must set `pump` to true in the next step.

These conditions hold globally throughout the system operation.
