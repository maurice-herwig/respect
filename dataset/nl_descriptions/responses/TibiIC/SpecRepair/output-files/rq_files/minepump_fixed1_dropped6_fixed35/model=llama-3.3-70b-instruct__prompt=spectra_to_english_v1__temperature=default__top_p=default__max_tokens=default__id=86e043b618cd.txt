The Minepump system interacts with its environment, which controls two inputs: highwater and methane, both of which are boolean values indicating the presence of high water and methane, respectively. The system controls one output: pump, a boolean value indicating whether the pump is active.

The environment is assumed to behave in such a way that if there is no methane, then the pump was not active in the previous state.

The system must satisfy two guarantees. Firstly, if methane is present, then either the pump must be active in the next state or there must be no high water. Secondly, if there is no methane, then the pump must be inactive in the next state.

In summary, the system must ensure that the pump is controlled based on the presence of methane and high water, while the environment ensures that the pump's previous state is consistent with the absence of methane.
