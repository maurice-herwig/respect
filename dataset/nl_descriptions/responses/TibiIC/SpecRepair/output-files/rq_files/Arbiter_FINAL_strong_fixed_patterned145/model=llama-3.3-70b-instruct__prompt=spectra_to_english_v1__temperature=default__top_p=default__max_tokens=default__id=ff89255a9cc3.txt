The Arbiter system interacts with its environment through four boolean variables: `a`, `r1`, and `r2` are controlled by the environment, while `g1` and `g2` are controlled by the system.

The environment is assumed to always set `a` to true whenever `r1` is true.

The system guarantees the following behavior:

- Whenever `r1` is true, the system will set `g1` to true.
- Whenever `r2` is true and either `r1` is false or `g2` is true, the system will set `g2` to true.
- If `a` is false, then the system will ensure that `a` remains false as long as both `g1` and `g2` are false.
- At all times, if `r1` is true, then either `g1` or `g2` (or both) must be false.

The system's behavior is further constrained by a pattern that defines how it responds to certain stimuli. Initially, the system is in a state where it is not responding to a stimulus. The system remains in this state as long as the stimulus is not present or is present and the system is responding to it. If the stimulus is present and the system is not responding to it, the system transitions to a state where it is waiting for a response. In this waiting state, the system will respond to the stimulus and transition back to the initial state, or it will remain in the waiting state if the stimulus is still not responded to. The system will infinitely often be in the initial state.
