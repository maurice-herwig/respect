The Minepump system is a reactive system that interacts with its environment. The environment controls two inputs: highwater and methane, which indicate whether the water level is high and whether methane is present, respectively. The system controls one output: pump, which indicates whether the pump is active or not.

The environment is assumed to behave in such a way that if the pump is active in the current and previous states, then the water level will not be high in the next state.

The system guarantees two safety conditions. Firstly, if the water level is high and there is no methane, the pump will be active in the next state. Secondly, if methane is present, the pump will be inactive in the next state.

Note that the initial state of the system is not specified, and there are no liveness requirements or explicit next-state/update rules beyond the guarantees mentioned above. The system's behavior is defined solely by the specified guarantees and assumption.
