

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump specification describes a reactive system where the environment controls the boolean inputs `highwater` and `methane`, and the system controls the boolean output `pump`.

The environment is assumed to satisfy the following constraint at all times: whenever `methane` is true, either `highwater` will be false in the next step or `pump` is currently false.

The system must satisfy the following guarantees at all times:
1. Whenever `methane` is false and `highwater` is true, the system must ensure `pump` is true in the next step.
2. Whenever `methane` is true, the system must ensure `pump` is false in the next step.
