

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump specification describes a reactive system where the environment provides sensor readings regarding water and gas levels, and the system controls the state of a pump. The variables `highwater` and `methane` are environment-controlled inputs, while `pump` is a system-controlled output.

**Environment Assumptions**
The environment is assumed to behave according to the following constraints:
1. Whenever the `highwater` input is true, the `pump` output must be false either in the current state or in the immediately preceding state.
2. Whenever the `methane` input is true, the `pump` output must be false either in the current state or in the immediately preceding state.

**System Guarantees**
The system must satisfy the following requirements regarding the `pump` output:
1. At every step of the interaction, the `pump` must be true in the subsequent state.
2. At every step of the interaction, if the `methane` input is true, the `pump` must be false in the subsequent state.
