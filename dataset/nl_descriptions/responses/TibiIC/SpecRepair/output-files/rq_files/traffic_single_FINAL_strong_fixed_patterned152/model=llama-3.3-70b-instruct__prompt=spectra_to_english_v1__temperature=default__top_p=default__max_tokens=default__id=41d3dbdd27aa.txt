The TrafficE2 system is a reactive system that interacts with its environment, which controls the presence of a car, emergency situations, and police presence. The system controls the state of a traffic light, specifically whether it is green.

The environment is expected to behave in certain ways. Specifically, it is assumed that police will not be present indefinitely, and there will be times when the police are not present. Additionally, when the traffic light is red, if a car is present, it will remain present until the light turns green. If the light is green and a car is present, but there is no emergency, the car will move and no longer be present. Even if an emergency occurs while the car is moving and the light is green, the car will still move and no longer be present.

The system guarantees certain behavior. The traffic light will turn green whenever a car is present, and this will happen repeatedly over time. Furthermore, there will be times when no car is present.

Initially, the system starts in a state where it is not responding to the presence of a car. The system's behavior can be described by a set of rules that define how it responds to the presence of a car and the state of the traffic light. If a car is not present or is present and the light is green, the system remains in this initial state. If a car is present and the light is not green, the system moves to a different state, where it waits for the light to turn green. Once the light turns green, the system returns to its initial state, and this cycle repeats over time. The system ensures that it periodically returns to its initial state, where it is ready to respond to the presence of a car.
