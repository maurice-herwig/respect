

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump specification defines a reactive system where the environment controls the `highwater` and `methane` inputs, and the system controls the `pump` output. The behavior is constrained by the following assumptions and guarantees:

**Assumptions**
There is one assumption regarding the system's output history. At all times, if the `pump` variable is false, then either the `pump` variable is false in the current step or it was false in the previous step.

**Guarantees**
The system must satisfy two guarantees globally:
1. At all times, in the next step, either the `highwater` variable will be false or the `pump` variable will be true.
2. At all times, either the `methane` variable is true, or the `methane` variable is false, or the `pump` variable will be false in the next step.
