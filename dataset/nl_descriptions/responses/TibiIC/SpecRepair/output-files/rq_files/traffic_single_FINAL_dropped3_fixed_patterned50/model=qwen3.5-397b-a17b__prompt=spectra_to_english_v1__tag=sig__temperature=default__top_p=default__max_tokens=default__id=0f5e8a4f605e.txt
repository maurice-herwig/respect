

Specification name: TrafficE2

Environment variables:
- car: boolean
- emergency: boolean
- police: boolean

System variables:
- green: boolean

The system controls a traffic light signal based on environment inputs regarding car presence, emergency status, and police activity.

**Environment Assumptions**
The environment is assumed to adhere to the following constraints. The police signal must eventually become false infinitely often. Regarding vehicle dynamics, if a car is present and the traffic light is not green, the car must remain present in the next time step. Additionally, if there is no police activity, and a car is present while the light is green, the car must become absent in the next time step.

**System Guarantees**
The system must satisfy the following requirements. The system must ensure a response property such that whenever a car is present, the traffic light eventually turns green. Additionally, it is guaranteed that the car signal eventually becomes false infinitely often.

**Initial Conditions**
The internal logic monitoring the response between car presence and the green light initializes in an idle state.
