

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system controls a pump based on environmental inputs regarding water levels and methane presence. The environment provides the `highwater` and `methane` signals, while the system determines the state of the `pump`.

**Environment Assumptions**
The environment is assumed to satisfy the following constraint: whenever methane is present, the pump must either be currently off or must have been off in the immediately preceding step.

**System Guarantees**
The system must ensure the following behaviors hold at all times:
1. If methane is present, the pump must be off in the next step.
2. If the water level is high and methane is not present, the pump must be on in the next step.
