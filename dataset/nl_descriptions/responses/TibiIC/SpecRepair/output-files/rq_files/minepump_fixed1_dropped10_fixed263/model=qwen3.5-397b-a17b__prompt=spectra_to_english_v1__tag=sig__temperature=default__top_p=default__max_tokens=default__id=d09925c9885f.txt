

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system controls the `pump` output based on environmental sensor inputs. The environment provides the boolean signals `highwater` and `methane`, while the system determines the boolean state of `pump`.

The specification operates under the assumption that globally, whenever the `highwater` signal was false in the previous step, the `pump` is false in the current step.

The system guarantees specific relationships between the `methane` level and the subsequent state of the `pump`. Always, if `methane` is false, the `pump` must be true in the next step. Conversely, always, if `methane` is true, the `pump` must be false in the next step. This ensures the pump state in the next step is determined by the current presence or absence of methane.
