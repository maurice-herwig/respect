

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system controls the `pump` output based on the environment-controlled `highwater` and `methane` inputs. The requirements are divided into assumptions on the operating context and guarantees that the system must satisfy.

**Assumptions**
The specification assumes that the following condition holds at all times: whenever `highwater` is false, `pump` is false.

**Guarantees**
The system must ensure the following conditions hold at all times:
1. If `methane` is true, then `pump` must be true in the next step.
2. If `methane` is false and `highwater` is true, then `pump` must be true in the next step.
