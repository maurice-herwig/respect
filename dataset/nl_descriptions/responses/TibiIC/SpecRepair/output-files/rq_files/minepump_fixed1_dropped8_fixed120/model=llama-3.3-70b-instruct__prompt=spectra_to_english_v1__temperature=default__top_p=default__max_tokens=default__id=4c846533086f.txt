The Minepump system operates in an environment where two conditions are monitored: high water levels and the presence of methane. The system controls a pump. 

The environment provides input on whether there is high water and whether methane is present. The system's output is the state of the pump, which can be either on or off.

It is assumed that the environment will not turn the pump on if it was previously off, unless the system itself turns it on.

The system must guarantee two conditions. Firstly, at any point, the pump must either remain off or be turned on in the next state. 

Secondly, if methane is detected, the system must ensure that the pump is turned off in the next state, unless no methane is present, in which case the pump's state can be determined by other conditions.

Note that the presence of high water is an environmental condition, but there are no specific guarantees or assumptions related to it in this specification.
