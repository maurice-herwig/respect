

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system controls the `pump` output based on the `highwater` and `methane` inputs provided by the environment. The behavior of the system and the constraints on the environment are defined as follows:

**Environment Assumptions**
The environment is restricted by the following condition: At all times, if `highwater` is true and `methane` becomes true in the next step, then `pump` must have been false in the previous step.

**System Guarantees**
The system must satisfy the following requirements at all times:
1. Whenever `methane` is false and `highwater` is true, the system must set `pump` to true in the next step.
2. Whenever `methane` is true, the system must set `pump` to false in the next step.
