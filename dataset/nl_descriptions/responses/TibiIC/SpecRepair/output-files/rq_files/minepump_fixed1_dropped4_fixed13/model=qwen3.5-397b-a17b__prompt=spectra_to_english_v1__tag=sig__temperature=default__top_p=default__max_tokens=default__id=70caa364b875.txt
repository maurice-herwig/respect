

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system controls a pump based on environmental water and methane levels. The environment provides the `highwater` and `methane` inputs, while the system determines the `pump` output.

The specification includes the following assumption regarding the system's operation:
- It is assumed that whenever `highwater` is false, the `pump` is false.

The system must satisfy the following guarantees at every step of the interaction:
- Whenever `methane` is false and `highwater` is true, the system must set `pump` to true in the next step.
- Whenever `methane` is true, the system must set `pump` to false in the next step.
