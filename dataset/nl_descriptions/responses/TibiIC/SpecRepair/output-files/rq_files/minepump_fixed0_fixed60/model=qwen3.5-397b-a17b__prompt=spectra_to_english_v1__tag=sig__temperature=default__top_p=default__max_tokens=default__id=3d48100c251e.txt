

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system controls a water pump based on environmental conditions in a mine. The environment provides input signals regarding water levels and gas presence, while the system determines the state of the pump.

**Environment Assumptions**
The system relies on the following assumptions regarding the behavior of the environment:
1. If the pump has been active in both the previous step and the current step, the high water condition must be absent in the next step.
2. Whenever the pump is active, the environment ensures that high water and methane are not both detected simultaneously.
3. If methane was detected in the previous step, the environment ensures that currently high water and methane are not both detected simultaneously.

**System Guarantees**
The system must satisfy the following requirements:
1. Whenever high water is detected, the system must activate the pump in the next step.
2. Whenever methane is detected, the system must deactivate the pump in the next step.
