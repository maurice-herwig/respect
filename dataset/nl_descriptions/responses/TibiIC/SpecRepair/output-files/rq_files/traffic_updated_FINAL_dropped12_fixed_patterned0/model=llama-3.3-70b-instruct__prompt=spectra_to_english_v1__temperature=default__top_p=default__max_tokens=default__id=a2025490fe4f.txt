The TrafficE2 system controls traffic lights in response to cars and emergency situations. The environment controls the presence of cars A and B, as well as emergency situations. The system controls the green lights for roads A and B.

The environment is assumed to not have emergencies often, meaning that it is always eventually the case that there is no emergency. Additionally, when the system's lights are red, the environment is assumed to keep car A idle unless there is an emergency or car A is already moving. The environment is also assumed to keep car B idle when there is an emergency, unless the system's light for road B is green.

When car A is present, the system guarantees that the light for road A will eventually turn green. When car B is present, the system guarantees that either the light for road A or the light for road B will eventually turn green. The system also guarantees that when there is no emergency, the light for road B will be red. Furthermore, the system guarantees that when there is an emergency, both lights will be red.

The environment is assumed to make car A move when the light for road A is green, unless car A is already not moving. Similarly, the environment is assumed to make car B move when the light for road B is green, unless there is an emergency or car B is already not moving.

Initially, the system is in a state where it can respond to the presence of cars. The system's response to the presence of cars is such that when a car is present, the corresponding light will eventually turn green, and when the light is green, the car will move. The system ensures that it will always eventually return to a state where it can respond to the presence of cars.
