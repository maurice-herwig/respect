

Specification name: TrafficE2

Environment variables:
- car: boolean
- emergency: boolean
- police: boolean

System variables:
- green: boolean

**Environment Assumptions**
The specification assumes the following behaviors regarding the environment inputs:
1.  **Police Presence:** It is assumed that there are infinitely many moments in time where no police are present.
2.  **Car Persistence:** If a car is present and there is no emergency, the car must remain present in the next time step.
3.  **Car Movement:** It is assumed that whenever the light is green, if a car is present and no police are present, the car must leave in the next time step.

**System Guarantees**
The system must satisfy the following requirements:
1.  **Car Response:** Whenever a car is present, the traffic light must eventually turn green. This requirement applies continuously throughout operation.
2.  **Car Frequency:** The system guarantees that there are infinitely many moments in time where no car is present.

**Initial Conditions**
At the start of operation, the system initializes its internal monitoring state to indicate that there are no pending car requests requiring a green light response.
