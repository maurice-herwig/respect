The TrafficE2 system is a reactive system that interacts with its environment, which controls the presence of a car, emergency situations, and police interventions. The system controls the state of a traffic light, indicated by the green signal.

The environment is expected to behave in certain ways: it should not have police interventions indefinitely, and there should be periods where there is no car present. Additionally, the environment should ensure that if a car is present, it will not start moving when the light is red, unless there is an emergency or the car is already moving. When the light is green, the car should either be accompanied by police, not present, or not move in the next moment.

The system guarantees two main behaviors: the traffic light will turn green when a car is present, and this will happen infinitely often. Furthermore, the system ensures that whenever a car is present, the traffic light will eventually turn green, and this response will happen repeatedly.

Initially, the system is in a state where it is ready to respond to the presence of a car. The system's safety requirements dictate that if a car is present and the light is not green, the system will transition to a state where it is waiting for the light to turn green. Once the light turns green, the system will return to its initial state, ready to respond to the next car. If the light remains green, the system will stay in the waiting state. The system will always eventually return to its initial state, ensuring that it can respond to cars repeatedly.
