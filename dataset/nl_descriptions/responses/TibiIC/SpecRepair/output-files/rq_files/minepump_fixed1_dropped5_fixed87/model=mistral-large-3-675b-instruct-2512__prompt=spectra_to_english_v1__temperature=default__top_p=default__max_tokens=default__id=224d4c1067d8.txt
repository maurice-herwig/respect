**Requirements Description for the Minepump System**

The minepump system interacts with its environment through two inputs—**highwater** and **methane**—both of which are controlled by the environment. The system controls a single output, the **pump**, which can be turned on or off.

The environment imposes the following assumption: *if the pump is off, then at the next time step, either the highwater condition must not occur, or the pump must remain off.* In other words, the environment cannot falsely trigger a highwater condition if the pump is off and remains off.

The system must guarantee two key behaviors:
1. *If methane is detected (true) at any point, then in the next time step, the pump must be turned on.* This ensures that the pump activates promptly in response to methane presence.
2. *If methane is absent (false), then in the next time step, the pump must be turned off.* This ensures the pump deactivates when methane is no longer a concern.

The system does not specify initial conditions, only these ongoing reactive behaviors.
