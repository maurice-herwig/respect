

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

**Requirements Description**

The Minepump system manages a pump based on environmental conditions. The environment provides input signals indicating the water level (`highwater`) and the presence of methane (`methane`). The system controls the output signal for the pump (`pump`).

**Assumptions on the Environment**
The specification assumes that the environment behaves according to the following safety constraint: Globally, if the pump is off, then either the highwater level will be off in the next step or the pump is off.

**Guarantees from the System**
The system must satisfy the following safety requirements regarding the pump's behavior in response to methane levels:
1. Globally, if methane is not detected, the pump must be on in the next step.
2. Globally, if methane is detected, the pump must be off in the next step.
