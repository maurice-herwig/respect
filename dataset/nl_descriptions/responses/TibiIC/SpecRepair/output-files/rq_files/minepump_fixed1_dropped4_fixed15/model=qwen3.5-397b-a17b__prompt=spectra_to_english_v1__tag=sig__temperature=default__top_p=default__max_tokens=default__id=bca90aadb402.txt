

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump specification describes a reactive system that controls a pump based on environmental signals regarding water and methane levels.

**Environment Assumptions**
The specification assumes the environment behaves according to the following constraints:
- Whenever the `highwater` signal is true, the `pump` output is false.
- Whenever the `methane` signal is true, the `pump` output is false.

**System Guarantees**
The system must satisfy the following requirements at all times:
- The `methane` signal must always be false.
- At every moment, at least one of the following conditions must hold:
  - The `methane` signal is true.
  - The `pump` output will be true in the next state.
  - The `highwater` signal is false.
