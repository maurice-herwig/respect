

Specification name: TrafficE2

Environment variables:
- car: boolean
- emergency: boolean
- police: boolean

System variables:
- green: boolean

**Requirements Description**

This specification defines the behavior of a traffic control system interacting with an environment that provides inputs regarding car presence, emergency status, and police presence. The system controls the green traffic light signal.

**Environment Assumptions**
The environment is constrained by the following assumptions:
1.  **Police Presence:** Police must be absent infinitely often.
2.  **Car Persistence:** If a car was present in the previous step, then either an emergency is currently active, the car is currently absent, or the car must remain present in the next step.
3.  **Car Movement:** If police are absent and a car is currently present, the car must be absent in the next step.

**System Guarantees**
The system must satisfy the following requirements:
1.  **Initial Condition:** The system initializes its internal response tracking state to a ready state (S0).
2.  **Car Response:** The system guarantees a response relationship between car presence and the green light. Whenever a car is present, the green light must eventually turn on. The system must return to the ready state infinitely often, ensuring that it remains capable of responding to car presence indefinitely.
3.  **Car Absence:** The system guarantees that the car is absent infinitely often.
