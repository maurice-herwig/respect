

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system controls the boolean output variable `pump` based on the boolean input variables `highwater` and `methane`, which are controlled by the environment. The behavior of the system and the environment is constrained by the following assumptions and guarantees.

**Environment Assumptions**
The environment is restricted by the following requirement: at all times, if `methane` is true, then `pump` must be false. This limits the conditions under which the environment may set `methane` to true relative to the state of the system.

**System Guarantees**
The system must satisfy the following requirements at all times:
1.  `methane` must be false.
2.  Either `methane` is true, or `pump` will be true in the next state, or `highwater` is false. Equivalently, whenever `methane` is false and `highwater` is true, the system must set `pump` to true in the next state.

There are no specified initial conditions or liveness requirements requiring events to occur infinitely often; the specification consists entirely of safety constraints and next-state relationships.
