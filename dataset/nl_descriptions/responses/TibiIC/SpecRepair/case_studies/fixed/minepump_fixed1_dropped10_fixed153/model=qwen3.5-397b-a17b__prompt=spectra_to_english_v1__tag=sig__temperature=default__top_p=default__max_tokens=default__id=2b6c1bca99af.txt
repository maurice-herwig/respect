

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The system controls the `pump` output based on the `methane` input provided by the environment. The environment is assumed to ensure that at all times, if `methane` is true, then `pump` is false. The system must satisfy two safety guarantees regarding the next state of the pump. First, at all times, if `methane` is false, then `pump` must be true in the next step. Second, at all times, if `methane` is true, then `pump` must be false in the next step.
