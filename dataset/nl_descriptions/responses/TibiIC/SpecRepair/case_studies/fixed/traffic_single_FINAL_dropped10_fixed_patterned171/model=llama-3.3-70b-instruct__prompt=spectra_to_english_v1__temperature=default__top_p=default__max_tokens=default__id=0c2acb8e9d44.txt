The TrafficE2 system is a reactive system that interacts with its environment, which controls the presence of a car, emergency situations, and police interventions. The system controls the state of a traffic light, specifically whether it is green.

The environment is expected to behave in certain ways. It is assumed that there will be periods where police are not present. Additionally, when the traffic light is not green, the car should not start moving unless there is an emergency or the car is already moving. If the police are present or will be present, or if the car is not moving, then the car should not start moving when the traffic light is green. The same applies if an emergency is about to occur. Furthermore, if there is no emergency, the car should not move when the traffic light is green unless the police are present or the car is not moving.

The system guarantees that the traffic light will turn green whenever a car is present, and this will happen infinitely often. It also guarantees that there will be periods where no car is present.

Initially, the system is in a state where it is ready to respond to the presence of a car. The system's behavior is constrained by safety requirements that dictate how it responds to the presence of a car and the state of the traffic light. Specifically, if a car is present and the traffic light is not green, the system will transition to a state where it is waiting for the traffic light to turn green. Once the traffic light turns green, the system will return to its initial state. The system will always eventually return to its initial state, ensuring that it is always ready to respond to the presence of a car.
