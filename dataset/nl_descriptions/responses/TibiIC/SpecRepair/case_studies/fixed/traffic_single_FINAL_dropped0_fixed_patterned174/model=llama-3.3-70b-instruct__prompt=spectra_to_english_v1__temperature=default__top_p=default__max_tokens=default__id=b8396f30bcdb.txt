The TrafficE2 system is a reactive system that interacts with its environment, which controls the presence of a car, emergency situations, and police presence. The system controls the state of a traffic light, specifically whether it is green.

The environment is expected to behave in certain ways. It is assumed that the police will not be present indefinitely, and there will be times when they are not present. Additionally, when the traffic light is not green, a car will not start moving unless there is an emergency or the light turns green. If a car is already present when the light is not green, it will either stay or leave when the light turns green or if there is no car.

The system must guarantee two main behaviors. Firstly, it must ensure that the traffic light turns green whenever a car is present, infinitely often. This means that the system will periodically turn the light green to allow cars to pass. Secondly, the system must ensure that there will be times when there are no cars present.

Initially, the system starts in a state where it is not responding to the presence of a car. The system then continuously checks for the presence of a car and updates its state accordingly. If a car is present and the light is not green, the system moves to a state where it is waiting for the light to turn green. Once the light turns green, the system returns to its initial state, allowing the car to pass. If the light turns green when a car is not present, the system remains in its initial state. The system ensures that it periodically returns to its initial state, allowing cars to pass infinitely often.
