

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system controls a pump based on environmental inputs. The environment provides the boolean signals `highwater` and `methane`, while the system controls the boolean output `pump`.

The specification includes an assumption regarding the operation of the `pump`: it is assumed that the `pump` is never on for two consecutive steps. At any point in time, either the `pump` is currently off or it was off in the previous step.

The system must satisfy the following guarantees regarding the next state of the `pump`:
1. Whenever `methane` is false and `highwater` is true, the `pump` must be on in the next step.
2. Whenever `methane` is true, the `pump` must be off in the next step.

These requirements hold globally throughout the system's operation.
