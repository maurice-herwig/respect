

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The system interacts with the environment through the variables listed above. Variables designated as environment variables are controlled by the environment, while variables designated as system variables are controlled by the system. The behavior of the system is defined by assumptions placed on the environment and guarantees that the system must satisfy.

The specification imposes one assumption on the environment. The environment is assumed to ensure that the `pump` variable remains false at all times.

The system must satisfy two guarantees. First, the system must ensure that the `methane` variable is always false. Second, at every step of the interaction, at least one of the following conditions must hold: `methane` is true, the `pump` variable will be true in the next step, or `highwater` is false. This second guarantee establishes a relationship between the current state of `methane` and `highwater` and the next state of `pump`.
