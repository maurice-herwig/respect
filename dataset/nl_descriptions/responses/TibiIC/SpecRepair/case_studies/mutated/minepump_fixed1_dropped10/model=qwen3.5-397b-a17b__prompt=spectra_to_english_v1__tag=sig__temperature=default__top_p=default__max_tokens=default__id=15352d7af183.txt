

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The system interacts with an environment that provides the boolean inputs `highwater` and `methane`. The system controls the boolean output `pump`.

The specification includes an assumption that the `pump` variable is always false.

The system must satisfy two safety guarantees regarding the relationship between the `methane` input and the next state of the `pump` output. At all times, if `methane` is false, then `pump` must be true in the next state. Additionally, at all times, if `methane` is true, then `pump` must be false in the next state. There are no specified initial conditions for the variables.
