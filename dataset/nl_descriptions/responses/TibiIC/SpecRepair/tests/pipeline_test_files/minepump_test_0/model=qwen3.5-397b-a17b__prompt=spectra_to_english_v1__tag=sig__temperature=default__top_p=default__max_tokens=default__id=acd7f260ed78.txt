

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump specification describes a control system that manages a pump based on environmental water and methane levels. The environment provides inputs indicating whether the water level is high (`highwater`) and whether methane is present (`methane`). The system controls the output signal for the pump (`pump`).

**Initial Conditions**
At the start of operation, the environment indicates that both `highwater` and `methane` are false. The system initializes with the `pump` turned off.

**Environment Assumptions**
The environment behavior is restricted by the following rules:
1. If the `pump` was on in the previous step and remains on in the current step, the environment ensures that `highwater` becomes false in the next step.
2. Whenever the `pump` is off, either `highwater` is false or `methane` is false (or both).

**System Guarantees**
The system must satisfy the following requirements whenever the environment adheres to its assumptions:
1. Whenever `highwater` is true, the `pump` must be on either in the current state or in the next state.
2. Whenever `methane` is true, the `pump` must be off in the next state.
