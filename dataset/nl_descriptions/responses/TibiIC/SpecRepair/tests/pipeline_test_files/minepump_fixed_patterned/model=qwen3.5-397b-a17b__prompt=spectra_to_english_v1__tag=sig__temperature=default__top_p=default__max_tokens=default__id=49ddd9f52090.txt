

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system manages a pump based on environmental inputs regarding water levels and methane presence. The environment controls the `highwater` and `methane` inputs, while the system controls the `pump` output.

**Initial Conditions**
At the start of operation, the environment indicates that `highwater` is false and `methane` is false. The system initializes with the `pump` set to false.

**Environment Assumptions**
The environment is assumed to adhere to the following constraints:
1. If the `pump` was true in the previous step and is true in the current step, then `highwater` must be false in the next step.
2. The condition where `highwater` is false or `methane` is false must occur infinitely often. The environment cannot maintain both `highwater` and `methane` as true indefinitely.

**System Guarantees**
The system must satisfy the following requirements:
1. Whenever `highwater` is true, the `pump` must be true in the next step.
2. Whenever `methane` is true, the system must eventually reach a state where the `pump` is false in the following step.
