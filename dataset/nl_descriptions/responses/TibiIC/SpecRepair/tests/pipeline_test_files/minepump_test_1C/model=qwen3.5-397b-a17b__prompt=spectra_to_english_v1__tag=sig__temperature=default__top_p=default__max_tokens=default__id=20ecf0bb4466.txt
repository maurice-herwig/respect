

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

**Requirements Description**

**Initial Conditions**
At the start of operation, the environment variables `highwater` and `methane` are both false. The system variable `pump` is initially false.

**Environment Assumptions**
The environment adheres to the following constraints:
1. Whenever `pump` was true in the previous step and `pump` is true in the current step, the environment ensures that `highwater` will be false in the next step.
2. Always, if `pump` is false and `highwater` is false, then either `highwater` is false or `methane` is false.

**System Guarantees**
The system must satisfy the following requirements:
1. Always, if `highwater` is true, then `pump` is false, `pump` is true, or `pump` will be true in the next step.
2. Always, if `methane` is true, then `pump` will be false in the next step.
