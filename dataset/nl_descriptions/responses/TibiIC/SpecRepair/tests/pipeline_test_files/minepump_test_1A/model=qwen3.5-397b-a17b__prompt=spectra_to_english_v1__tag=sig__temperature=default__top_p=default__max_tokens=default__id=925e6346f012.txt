

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system controls a pump based on environmental signals indicating water levels and methane presence. The environment controls the `highwater` and `methane` inputs, while the system controls the `pump` output.

**Initial Conditions**
At the start of operation, the environment ensures that both `highwater` and `methane` are false. The system ensures that the `pump` is initially false.

**Environment Assumptions**
The environment behaves according to the following constraints:
- If the `pump` was true in the previous step and remains true in the current step, the environment must ensure that `highwater` becomes false in the next step.

**System Guarantees**
The system must satisfy the following requirements whenever the environment satisfies its assumptions:
- Whenever `highwater` is true, the system ensures that either `highwater` is true or the `pump` is set to true in the next step.
- Whenever `methane` is true, the system ensures that the `pump` is set to false in the next step.
