

Specification name: Test

Environment variables:
- a: boolean

System variables:
- b: boolean

The system interacts with an environment through the boolean variable `a`, which is an input controlled by the environment, and the boolean variable `b`, which is an output controlled by the system. The environment is assumed to ensure that `a` is true infinitely often during execution. The system must guarantee that at every moment in time, if `a` is true, then `b` is also true.
