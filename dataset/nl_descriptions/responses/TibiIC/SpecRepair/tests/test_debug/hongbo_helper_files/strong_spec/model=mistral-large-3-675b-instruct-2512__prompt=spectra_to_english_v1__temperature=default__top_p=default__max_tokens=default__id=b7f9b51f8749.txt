### **Requirements Description for the Reactive System**

This specification describes a system that interacts with its environment through two boolean signals:

- **Environment-controlled input (`a`):** The environment decides the value of `a` at all times.
- **System-controlled output (`b`):** The system controls the value of `b` in response to `a`.

#### **Assumptions on the Environment**
The environment must ensure that its input `a` is **true infinitely often**—that is, no matter how the system behaves, `a` must become true repeatedly without bound over time.

#### **Guarantees Required from the System**
Whenever the environment satisfies its assumptions, the system must ensure:
- **Safety requirement:** Whenever `a` is true, `b` must also be true. This relationship must hold at **every moment** during the interaction.

No additional initial conditions, liveness guarantees, or next-state rules are specified. The system must only satisfy the above safety requirement under the given environment assumption.
