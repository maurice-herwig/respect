

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system regulates a pump based on environmental sensors. The environment controls the boolean inputs `highwater` and `methane`, while the system controls the boolean output `pump`.

Regarding the environment, it is assumed that `highwater` and `methane` never occur simultaneously. Additionally, if the `pump` remains active for two consecutive steps (being true in both the previous and current states), the environment ensures that `highwater` will be false in the subsequent step.

The system must satisfy specific behavioral guarantees. Whenever `highwater` is true, the system must set `pump` to true in the next step. Conversely, whenever `methane` is true, the system must set `pump` to false in the next step.
