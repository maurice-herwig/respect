**Minepump System Requirements**

The Minepump system monitors and controls a pump to manage water levels in an environment where methane may be present. The environment provides two inputs: a *highwater* signal indicating whether water has reached a dangerous level, and a *methane* signal indicating whether methane is detected. The system controls a single output: the *pump*, which determines whether the pump is active.

The environment must satisfy the following constraints:
- If the pump was active in the previous state and remains active, the highwater signal must not be present in the next state.
- The environment cannot simultaneously report high water levels and methane; at least one of these conditions must be false at all times.

The system must guarantee the following behavior:
- Whenever the highwater signal is active, the pump must be turned on in the next state.
- Whenever methane is detected, the pump must be turned off in the next state.
