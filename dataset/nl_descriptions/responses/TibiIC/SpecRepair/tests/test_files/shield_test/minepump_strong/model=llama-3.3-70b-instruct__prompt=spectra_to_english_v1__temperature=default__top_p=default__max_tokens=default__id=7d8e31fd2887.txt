The Minepump system is a reactive system that interacts with its environment, which controls the presence of high water and methane. The system controls the operation of a pump. 

Initially, the environment is assumed to be in a safe state, with no high water and no methane present. In this initial state, the pump is required to be off.

The system is required to behave in the following manner: if high water is present, the pump must be turned on at the next opportunity. Conversely, if methane is detected, the pump must be turned off at the next opportunity.

The environment is assumed to behave in a way that if the pump was previously on and is still on, then at the next opportunity, the high water condition must be resolved. Additionally, the environment is assumed to never have both high water and methane present simultaneously.

These requirements ensure the safe operation of the pump in response to the environmental conditions, preventing it from operating when methane is present and ensuring it operates to resolve high water conditions.
