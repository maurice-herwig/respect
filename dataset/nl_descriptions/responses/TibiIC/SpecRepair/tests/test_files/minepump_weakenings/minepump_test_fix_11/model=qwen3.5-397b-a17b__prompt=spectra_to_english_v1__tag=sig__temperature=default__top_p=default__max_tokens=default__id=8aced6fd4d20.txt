

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system controls a pump based on environmental inputs regarding water levels and methane presence. The environment controls the boolean inputs `highwater` and `methane`, while the system controls the boolean output `pump`.

Initially, the system starts with `highwater`, `methane`, and `pump` all set to false.

The environment is assumed to behave according to specific constraints. If the `pump` is true in the current step and was also true in the previous step, the environment must ensure that `highwater` becomes false in the next step. Additionally, whenever the `pump` is true, it must not be the case that both `highwater` and `methane` are true simultaneously; at least one of these variables must be false.

The system must satisfy specific guarantees regarding the pump operation. Whenever `highwater` is true, the system must set the `pump` to true in the next step. Furthermore, whenever `methane` is true, the system must ensure that either `methane` is true or the `pump` is set to false in the next step.
