

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump specification describes a reactive system where the environment controls the boolean inputs `highwater` and `methane`, and the system controls the boolean output `pump`.

Initially, the environment ensures that `highwater` is false and `methane` is false. The system initializes with `pump` set to false.

The environment is assumed to adhere to the following constraints. Globally, if `pump` was true in the previous step and remains true in the current step, the environment must ensure `highwater` is false in the next step. Additionally, whenever `pump` is true, it must be the case that either `highwater` is false or `methane` is false.

The system must satisfy the following guarantees. Globally, whenever `highwater` is true, the system ensures that either `pump` is currently false or `pump` will be true in the next step. Furthermore, whenever `methane` is true, the system must ensure `pump` is false in the next step.
