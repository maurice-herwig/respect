

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

**Initial Conditions**
At the start of operation, the environment sets both `highwater` and `methane` to false. The system sets `pump` to false.

**Environment Assumptions**
The environment must adhere to the following constraints:
1.  If the `pump` was true in the previous step and remains true in the current step, the environment must ensure that `highwater` becomes false in the next step.
2.  Whenever the `pump` is true, it must be the case that either `highwater` is false or `methane` is false.

**System Guarantees**
The system must satisfy the following requirements:
1.  Whenever `highwater` is true, either `highwater` remains true in the next step or the system sets `pump` to true in the next step.
2.  Whenever `methane` is true, the system must set `pump` to false in the next step.
