

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system controls a pump based on environmental inputs regarding water levels and methane gas. At the start of operation, the highwater level is false, the methane level is false, and the pump is off.

The environment is assumed to behave according to specific constraints. Whenever the pump was on in the previous step and remains on in the current step, the environment must ensure that highwater becomes false in the next step. Additionally, whenever the pump is on, it must be the case that either highwater is false or methane is false.

The system must satisfy specific guarantees regarding the pump's operation. Whenever highwater is true, either methane is true or the system must turn the pump on in the next step. Furthermore, whenever methane is true, the system must ensure the pump is off in the next step.
