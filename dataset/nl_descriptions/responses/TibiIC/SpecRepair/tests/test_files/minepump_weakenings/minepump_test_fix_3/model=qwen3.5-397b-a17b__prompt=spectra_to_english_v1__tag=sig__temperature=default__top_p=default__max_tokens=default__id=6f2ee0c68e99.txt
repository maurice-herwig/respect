

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The system controls a pump based on environmental inputs regarding water levels and methane gas. Initially, the environment reports no high water level and no methane, and the system keeps the pump off.

Regarding the environment behavior, it is assumed that at all times, if methane is false, then either highwater is false or methane is false. Additionally, if the pump was active in the previous step and remains active in the current step, the environment must ensure that the high water level becomes false in the next step.

Regarding the system guarantees, whenever the high water level is true, either methane must be currently true or the pump must be turned on in the next step. Furthermore, whenever methane is true, the pump must be turned off in the next step.
