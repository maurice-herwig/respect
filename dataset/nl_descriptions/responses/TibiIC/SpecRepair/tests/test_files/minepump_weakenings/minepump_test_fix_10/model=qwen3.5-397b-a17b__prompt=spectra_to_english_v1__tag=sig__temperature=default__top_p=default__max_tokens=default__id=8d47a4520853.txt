

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump specification describes a reactive system where the environment controls the boolean inputs `highwater` and `methane`, and the system controls the boolean output `pump`.

**Initial Conditions**
At the beginning of operation, the environment ensures that both `highwater` and `methane` are false. The system ensures that the `pump` is initially false.

**Environment Assumptions**
The environment is assumed to adhere to the following constraints:
1. Whenever the `pump` was true in the previous step and is true in the current step, the environment guarantees that `highwater` will be false in the next step.
2. Whenever `methane` is false, the environment ensures that either `highwater` is false or `methane` is false.

**System Guarantees**
The system must satisfy the following requirements:
1. Whenever `highwater` is true, the system must set `pump` to true in the next step.
2. Whenever `methane` is true, the system must satisfy the condition that either `methane` is true or `pump` is set to false in the next step.
