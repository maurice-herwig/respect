

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

**Requirements Description**

**Initial Conditions**
At the start of operation, the environment variables `highwater` and `methane` are both false. The system variable `pump` is also initially false.

**Environment Assumptions**
The environment behavior is constrained by the following rules:
1. At all times, if `methane` is false, then either `highwater` is false or `methane` is false.
2. At all times, if the `pump` was true in the previous step and remains true in the current step, the environment must ensure that `highwater` becomes false in the next step.

**System Guarantees**
The system must satisfy the following requirements whenever the environment satisfies its assumptions:
1. At all times, if `highwater` is true, then either `methane` is true or the system must set `pump` to true in the next step.
2. At all times, if `methane` is true, the system must set `pump` to false in the next step.
