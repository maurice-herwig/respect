

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

Requirements Description

Initial Conditions
At the start of operation, the environment indicates that highwater is false and methane is false. The system initializes with pump set to false.

Environment Assumptions
The environment adheres to the following constraints during operation:
1. If pump was true in the previous step and is true in the current step, the environment ensures that highwater becomes false in the next step.
2. At all times, it is not the case that highwater, methane, and pump are all true simultaneously.

System Guarantees
The system must satisfy the following requirements:
1. If highwater is true and pump is true in the current step, the system must ensure pump remains true in the next step.
2. If methane is true in the current step, the system must ensure pump becomes false in the next step.
