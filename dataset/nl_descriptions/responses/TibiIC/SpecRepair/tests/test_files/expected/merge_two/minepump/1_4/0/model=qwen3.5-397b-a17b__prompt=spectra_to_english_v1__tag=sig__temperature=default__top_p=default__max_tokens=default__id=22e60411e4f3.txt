

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system controls a pump based on environmental water and methane levels. At the initial state, there is no high water (highwater is false) and no methane (methane is false), and the pump is off (pump is false).

The environment is assumed to adhere to the following constraints:
1. If the pump was on in the previous step and remains on in the current step, then the high water level must become false in the next step.
2. At all times, at least one of the following must be false: highwater, methane, or pump.
3. Infinitely often, either highwater is false or methane is false.

The system must satisfy the following guarantees:
1. Whenever highwater is true and methane is false, the pump must be true in the next step.
2. Whenever methane is true, the pump must be false in the next step.
