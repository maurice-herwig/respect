

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system manages a pump based on environmental inputs indicating water levels and methane gas presence. The environment controls the boolean inputs `highwater` and `methane`, while the system controls the boolean output `pump`.

**Initial Conditions**
At the start of operation, the environment signals `highwater` and `methane` are both false. The system initializes with the `pump` set to false.

**Environment Assumptions**
The specification assumes the following behavior regarding the environment and operational context:
1. If the `pump` is true in the previous state and remains true in the current state, then `highwater` must become false in the next state.
2. At any time, it is assumed that at least one of the following holds: `highwater` is false, `methane` is false, or the `pump` is false.
3. Infinitely often, either `highwater` is false or `methane` is false. This ensures that the condition where both signals are true does not persist indefinitely.

**System Guarantees**
The system must satisfy the following requirements:
1. Whenever `highwater` is true, the system must ensure that either the `pump` becomes true in the next state, or `methane` is true and the `pump` is currently false.
2. Whenever `methane` is true, the system must ensure that the `pump` is false in the next state.
