

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system manages a pump based on environmental conditions. The environment controls the `highwater` and `methane` inputs, while the system controls the `pump` output.

**Initial Conditions**
At the start of operation, the environment ensures that `highwater` is false and `methane` is false. The system initializes with `pump` set to false.

**Environment Assumptions**
The environment adheres to the following constraints:
1. If the `pump` is on in the current step and was also on in the previous step, then `highwater` must be false in the next step.
2. Whenever `pump` is true, either `highwater` is false or `methane` is false (or both).
3. Infinitely often, either `highwater` is false or `methane` is false.

**System Guarantees**
The system must satisfy the following behaviors:
1. If `highwater` is true and `pump` is true in the current step, then `pump` must be true in the next step.
2. If `methane` is true in the current step, then `pump` must be false in the next step.
