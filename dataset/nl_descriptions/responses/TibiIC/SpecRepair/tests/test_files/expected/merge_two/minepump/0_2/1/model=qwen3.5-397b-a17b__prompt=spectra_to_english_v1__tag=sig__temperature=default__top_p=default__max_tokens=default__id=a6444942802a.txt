

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system manages a pump based on environmental inputs regarding water levels and methane presence. The environment controls the `highwater` and `methane` signals, while the system controls the `pump` output.

**Initial Conditions**
At the start of operation, the environment indicates that `highwater` is false and `methane` is false. The system initializes with the `pump` set to false.

**System Guarantees**
The system must satisfy the following requirements at every step of operation:
1. If `highwater` is true, the system must set `pump` to true in the next step.
2. If `methane` is true, the `pump` must be false either in the current step or in the next step.

**Environment Assumptions**
The environment is constrained by the following assumptions:
1. If the `pump` is true in the current step and was also true in the previous step, then `highwater` must be false in the next step.
2. At any point in time, it is never the case that `highwater`, `methane`, and `pump` are all true simultaneously.
