

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system manages a pump based on environmental water and methane levels. The environment controls the boolean inputs `highwater` and `methane`, while the system controls the boolean output `pump`.

**Initial Conditions**
At the beginning of operation, the `highwater` and `methane` inputs are both false, and the `pump` output is false.

**System Guarantees**
The system must satisfy the following requirements whenever the environment adheres to its assumptions:
1. Whenever `highwater` is true, the `pump` must be true in the next step.
2. Whenever `methane` is true and `highwater` is false, the `pump` must be false in the next step.

**Environment Assumptions**
The environment behavior is restricted by the following constraints:
1. If the `pump` was true in the previous step and remains true in the current step, then `highwater` must be false in the next step.
2. The `pump` is never true when both `highwater` and `methane` are true simultaneously.
3. Infinitely often, at least one of `highwater` or `methane` is false.
