

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The system controls a pump based on environmental inputs regarding water levels and methane presence. The variables `highwater` and `methane` are inputs controlled by the environment, while `pump` is an output controlled by the system.

**Initial Conditions**
At the start of operation, `highwater` is false, `methane` is false, and `pump` is false.

**Environment Assumptions**
The environment must satisfy the following constraints:
1. If the `pump` is true in the previous step and remains true in the current step, then `highwater` must be false in the next step.
2. It must never occur that `highwater`, `methane`, and `pump` are all true simultaneously.

**System Guarantees**
The system must satisfy the following requirements:
1. Whenever `highwater` is true, the system must set `pump` to true in the next step.
2. Whenever `methane` is true, the system must ensure that either `pump` is false in the next step, or `pump` is currently false and `highwater` is currently true.
