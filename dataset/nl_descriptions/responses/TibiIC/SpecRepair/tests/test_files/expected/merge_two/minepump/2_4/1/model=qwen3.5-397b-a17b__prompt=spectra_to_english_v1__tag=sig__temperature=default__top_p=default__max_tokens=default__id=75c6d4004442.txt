

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump system controls a pump based on environmental inputs regarding water levels and methane presence. The environment provides the boolean inputs `highwater` and `methane`, while the system controls the boolean output `pump`.

**Initial Conditions**
At the start of operation, the environment must set both `highwater` and `methane` to false. Simultaneously, the system must initialize the `pump` to false.

**System Guarantees**
The system must adhere to the following behavior requirements:
1.  Whenever `highwater` is true and `methane` is false, the system must set `pump` to true in the next step.
2.  Whenever `methane` is true, the system must set `pump` to false in the next step.

**Environment Assumptions**
The environment is constrained by the following assumptions:
1.  If the `pump` was true in the previous step and remains true in the current step, the environment must ensure that `highwater` becomes false in the next step.
2.  At every moment in time, at least one of the following conditions must hold: `highwater` is false, `methane` is false, or `pump` is false.
3.  Infinitely often, either `highwater` is false or `methane` is false.
