

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

The Minepump specification describes a reactive system that controls a pump based on water levels and methane presence. The environment provides inputs regarding water and methane status, while the system controls the pump output.

**Initial Conditions**
At the beginning of operation, the environment signals that highwater is false and methane is false. The system initializes with the pump set to false.

**Environment Assumptions**
The environment is constrained by the following behaviors:
1. If the pump is on in the current step and was also on in the previous step, the environment must ensure highwater becomes false in the next step.
2. At any point in time, it is never the case that highwater, methane, and pump are all true simultaneously.
3. Infinitely often, either highwater is false or methane is false.

**System Guarantees**
The system must satisfy the following requirements:
1. Whenever highwater is true, the system must set the pump to true in the next step.
2. Whenever methane is true, the system must ensure that the pump is either currently false or becomes false in the next step.
