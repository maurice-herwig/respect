

Specification name: Minepump

Environment variables:
- highwater: boolean
- methane: boolean

System variables:
- pump: boolean

**Requirements Description**

This specification defines the behavior of a mine pump controller. The environment provides input signals indicating water levels and methane presence, while the system controls the pump activation.

**Initial Conditions**
At the start of operation, the environment indicates that both `highwater` and `methane` are false. The system must initialize with the `pump` set to false.

**Environment Assumptions**
The environment adheres to the following constraints regarding sensor behavior and physical responses:
1. If the `pump` was true in the previous step and remains true in the current step, the environment ensures that `highwater` becomes false in the next step.
2. At any point in time, it is never the case that `highwater`, `methane`, and the `pump` are all true simultaneously. At least one of these three variables must be false.
3. Infinitely often, either `highwater` is false or `methane` is false; they cannot both remain true forever.

**System Guarantees**
The system must satisfy the following control requirements:
1. Whenever `highwater` is true and the `pump` is currently true, the system must keep the `pump` true in the next step.
2. Whenever `methane` is true, the system must ensure the `pump` is false in the next step.
