The system interacts with an environment that sends requests through a set of boolean inputs, `request`, where each input corresponds to a specific entity (up to `N-1` entities). The system responds to these requests by granting access through a corresponding set of boolean outputs, `grant`. 

The environment is assumed to behave in such a way that if an entity is waiting (i.e., its request is set but the corresponding grant is not), then the environment will maintain the request in the next step. Additionally, the environment will eventually release each entity, meaning that it will not hold onto a request indefinitely.

The system guarantees that if an entity is currently being granted access, then the grant will continue in the next step. Furthermore, the system ensures that every waiting entity will eventually be granted access. When an entity (other than the first one) is granted access after not having it, the system ensures that the first entity is not waiting.

A crucial safety requirement of the system is that it will never grant access to more than one entity at a time, ensuring mutual exclusion among all entities.

The system maintains symmetry across entities 1 through `N-1` for both the `request` and `grant` arrays, implying that the system's behavior is symmetric with respect to these entities.
