The Elevator system is a reactive system that interacts with its environment, which controls the current floor. The system controls the elevator's motion, which can be moving forward, backward, or stopped. 

The environment-controlled input is the current floor, which can be one of the following: LOWER, MIDDLE, UPPER, or NONE. The system-controlled output is the elevator's motion, which can be in one of the following states: FWD (moving forward), BWD (moving backward), or STOP (stopped).

The assumption about the environment is that whenever the elevator is stopped, the current floor is not NONE.

The system guarantees the following behavior: 
- Initially, the elevator is stopped.
- The elevator will always eventually move forward.
- The elevator will change direction to move forward when it reaches the LOWER floor.
- The elevator will change direction to move backward when it reaches the UPPER floor.

In summary, the Elevator system is designed to move between floors, changing direction at the LOWER and UPPER floors, while ensuring it is initially stopped and will always eventually move forward, under the assumption that the environment will not report NONE as the current floor when the elevator is stopped.
