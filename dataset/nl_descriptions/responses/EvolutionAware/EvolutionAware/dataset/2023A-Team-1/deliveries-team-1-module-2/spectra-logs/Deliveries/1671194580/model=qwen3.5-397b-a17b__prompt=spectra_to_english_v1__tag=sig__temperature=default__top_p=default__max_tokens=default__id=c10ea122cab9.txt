

The Deliveries specification defines a reactive system responsible for managing robot positions within a bounded two-dimensional grid. The grid dimensions are constrained such that X coordinates range from 0 to 5 and Y coordinates range from 0 to 5. The system interacts with an environment that provides information about delivery tasks and infrastructure status.

The environment controls the input variables representing the locations of deliveries and the elevator. Specifically, the environment provides the X and Y coordinates for two delivery points and the current X and Y coordinates of the elevator. The system controls the output variables representing the positions of two robots. For each robot, the system determines the X and Y coordinates within the defined grid boundaries.

Specification name: Deliveries

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)
- Coord: Int(0..DY)

Environment variables:
- deliveriesX: DimX [2]
- deliveriesY: DimY [2]
- elevatorX: DimX
- elevatorY: DimY

System variables:
- robotX0: DimX
- robotY0: DimY
- robotX1: DimX
- robotY1: DimY
