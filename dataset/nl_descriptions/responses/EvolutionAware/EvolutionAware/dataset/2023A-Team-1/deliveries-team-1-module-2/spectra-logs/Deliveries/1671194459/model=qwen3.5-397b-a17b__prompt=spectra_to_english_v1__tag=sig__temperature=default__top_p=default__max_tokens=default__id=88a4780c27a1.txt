

Specification name: Deliveries

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)
- Coord: Int(0..DY)

Environment variables:
- none

System variables:
- robotX0: DimX
- robotY0: DimY
- robotX1: DimX
- robotY1: DimY

The Deliveries specification defines constants DX and DY, each assigned the value 5. It establishes three types: DimX representing integers from 0 to DX, DimY representing integers from 0 to DY, and Coord representing integers from 0 to DY. The system controls four variables. Variables robotX0 and robotX1 are of type DimX, while variables robotY0 and robotY1 are of type DimY. These variables represent the coordinate positions for two robots within the defined dimensions.
