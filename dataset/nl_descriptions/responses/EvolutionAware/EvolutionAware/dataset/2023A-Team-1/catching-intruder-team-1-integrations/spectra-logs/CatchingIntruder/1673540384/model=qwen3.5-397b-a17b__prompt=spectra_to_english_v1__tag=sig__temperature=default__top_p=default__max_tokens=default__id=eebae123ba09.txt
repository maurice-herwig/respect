

Specification name: CatchingIntruder

Named domains:
- Dim: Int(0..D)

Environment variables:
- intruderX: Dim
- intruderY: Dim

System variables:
- robotX0: Dim
- robotY0: Dim
- robotX1: Dim
- robotY1: Dim

**System Description**

The system controls the positions of two robots, Robot 0 and Robot 1, on a two-dimensional grid. The environment controls the position of an intruder on the same grid. All coordinates are integers within the domain Dim.

**Safety Requirements**

The system must satisfy the following guarantees at all times:

1.  **Static Obstacle Avoidance**: Both Robot 0 and Robot 1 must avoid a specific static obstacle region. Neither robot is permitted to occupy a position where the Y-coordinate is 1 while the X-coordinate is between 2 and 5 inclusive.

2.  **Inter-Robot Collision Avoidance**: Robot 0 and Robot 1 must never occupy the same location simultaneously. Furthermore, the robots must not swap positions in a single time step (i.e., Robot 0 moving to Robot 1's current position while Robot 1 moves to Robot 0's current position).

3.  **Intruder Collision Avoidance**: Each robot must never occupy the same location as the intruder. Additionally, neither robot is permitted to swap positions with the intruder in a single time step.
