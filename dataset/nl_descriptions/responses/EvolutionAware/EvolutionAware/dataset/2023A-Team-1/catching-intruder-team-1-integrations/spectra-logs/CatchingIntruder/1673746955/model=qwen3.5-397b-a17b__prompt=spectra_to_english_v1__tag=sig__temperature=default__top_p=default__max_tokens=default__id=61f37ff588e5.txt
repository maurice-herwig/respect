

Specification name: CatchingIntruder

Named domains:
- Dim: Int(0..D)

Environment variables:
- intruderX: Dim
- intruderY: Dim

System variables:
- robotX0: Dim
- robotY0: Dim
- robotX1: Dim
- robotY1: Dim

The system manages the positions of two robots within a grid where all coordinates are integers ranging from 0 to 7. The environment controls the position of an intruder using the variables `intruderX` and `intruderY`. The system controls the positions of Robot 0 and Robot 1 using the variables `robotX0`, `robotY0`, `robotX1`, and `robotY1`. The system guarantees that initially, Robot 0 is positioned at coordinates (0, 0) and Robot 1 is positioned at coordinates (5, 0).
