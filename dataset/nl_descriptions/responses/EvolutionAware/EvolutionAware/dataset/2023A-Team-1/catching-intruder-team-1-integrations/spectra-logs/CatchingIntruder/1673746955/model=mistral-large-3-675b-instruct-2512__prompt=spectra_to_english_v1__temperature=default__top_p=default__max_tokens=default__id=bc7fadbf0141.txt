**System Description: Catching Intruder**

This system models the behavior of two robots attempting to intercept an intruder within a bounded 7×7 grid (where coordinates range from 0 to 6). The environment controls the intruder's position, provided as integer coordinates (*intruderX*, *intruderY*) within the grid. The system controls the two robots, each with their own position: Robot 0, defined by coordinates (*robotX0*, *robotY0*), and Robot 1, defined by coordinates (*robotX1*, *robotY1*).

At the start of operation, Robot 0 must be positioned at (0, 0), and Robot 1 must be positioned at (5, 0). The system must ensure this initial placement is correct. There are no assumptions placed on the environment's behavior, and no further guarantees (such as movement rules or interception requirements) are specified beyond the initial conditions. The row at *y = 1* is implicitly treated as a static obstacle, though its effect on behavior is not defined in this specification.
