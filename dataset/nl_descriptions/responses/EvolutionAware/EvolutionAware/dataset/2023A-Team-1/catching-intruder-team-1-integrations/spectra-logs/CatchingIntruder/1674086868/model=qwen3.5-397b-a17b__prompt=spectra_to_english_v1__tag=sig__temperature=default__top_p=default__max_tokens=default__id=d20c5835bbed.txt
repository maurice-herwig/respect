

Specification name: CatchingIntruder

Named domains:
- Dim: Int(0..D)

Environment variables:
- intruderX: Dim
- intruderY: Dim

System variables:
- robotX0: Dim
- robotY0: Dim
- robotX1: Dim
- robotY1: Dim

The CatchingIntruder specification defines a reactive system that operates on a two-dimensional grid. The grid coordinates are bounded by the type Dim, which represents integers ranging from 0 to 7. The environment controls the position of an intruder, providing the horizontal and vertical coordinates via the inputs intruderX and intruderY. The system controls the positions of two robots. The coordinates for the first robot are output via robotX0 and robotY0, while the coordinates for the second robot are output via robotX1 and robotY1. All position variables are constrained to remain within the valid Dim domain.
