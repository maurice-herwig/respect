**Requirements Description for "Catching Intruder" Reactive System**

This system models a scenario where two robots attempt to catch an intruder within a discrete 7×7 grid (dimensions 0 to 6). The environment controls the intruder's position, specified by `(intruderX, intruderY)`, while the system controls the initial positions of the two robots, `(robotX0, robotY0)` and `(robotX1, robotY1)`, as well as a counter tracking the number of turns (`turns`), which ranges from 0 to 4.

**Initial Condition**
At the start of operation, the turn counter must be set to `0`.

**System Guarantees**
The system must ensure that the turn counter repeatedly reaches `3` infinitely often during execution. This implies that the counter cycles through its range in a manner that guarantees this value is revisited an unbounded number of times over time.

*(Note: The commented guarantee `intruderStuckIncreasesTurns`—though not active in the specification—suggests a possible behavioral rule where, if the intruder remains in the same position between consecutive states, the turn counter is incremented by 1 in the next state. This rule is not enforced as part of the current requirements.)*
