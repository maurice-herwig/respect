

Specification name: CatchingIntruder

Named domains:
- Dim: Int(0..D)
- Turns: Int(0..4)

Environment variables:
- intruderX: Dim
- intruderY: Dim

System variables:
- robotX0: Dim
- robotY0: Dim
- robotX1: Dim
- robotY1: Dim
- turns: Turns

**Requirements Description**

The system controls the positions of two robots and a turn counter, while the environment controls the position of an intruder. The robot positions are defined by coordinates robotX0, robotY0, robotX1, and robotY1. The intruder position is defined by coordinates intruderX and intruderY. All coordinate variables must hold integer values between 0 and 7. The turns variable must hold integer values between 0 and 4.

At the start of execution, the system must initialize the turns variable to 0. During operation, the system must ensure that the turns variable equals 3 infinitely often.
