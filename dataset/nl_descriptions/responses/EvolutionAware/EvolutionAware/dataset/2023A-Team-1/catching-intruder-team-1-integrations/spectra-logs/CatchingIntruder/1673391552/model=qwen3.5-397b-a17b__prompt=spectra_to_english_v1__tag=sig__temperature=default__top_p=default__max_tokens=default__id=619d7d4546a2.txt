

Specification name: CatchingIntruder

Named domains:
- Dim: Int(0..D)

Environment variables:
- intruderX: Dim
- intruderY: Dim

System variables:
- robotX0: Dim
- robotY0: Dim
- robotX1: Dim
- robotY1: Dim

The system operates on a grid where all coordinates are integers ranging from 0 to D, with D defined as 7. The environment provides the current horizontal and vertical position of an intruder. The system controls the horizontal and vertical positions of two distinct robots, designated as robot 0 and robot 1.
