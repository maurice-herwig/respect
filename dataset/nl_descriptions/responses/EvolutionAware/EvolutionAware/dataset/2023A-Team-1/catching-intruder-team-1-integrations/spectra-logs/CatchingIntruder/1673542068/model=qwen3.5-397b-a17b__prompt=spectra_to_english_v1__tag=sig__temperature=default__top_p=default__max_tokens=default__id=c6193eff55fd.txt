

Specification name: CatchingIntruder

Named domains:
- Dim: Int(0..D)

Environment variables:
- intruderX: Dim
- intruderY: Dim

System variables:
- robotX0: Dim
- robotY0: Dim
- robotX1: Dim
- robotY1: Dim

The system controls the positions of two robots, Robot 0 and Robot 1, within a grid where coordinates range from 0 to 7. The environment controls the position of an intruder within the same grid. The following safety requirements must hold at all times:

1. **Static Obstacle Avoidance:** There is a static obstacle region at Y coordinate 1. Neither Robot 0 nor Robot 1 is permitted to occupy any location where the Y coordinate is 1 and the X coordinate is 2, 3, 4, or 5.

2. **Robot Mutual Avoidance:** Robot 0 and Robot 1 must never occupy the same location simultaneously. Additionally, they must not swap locations in a single step (i.e., Robot 0 cannot move to Robot 1's current position at the same time Robot 1 moves to Robot 0's current position).

3. **Intruder Avoidance:** Each robot must never occupy the same location as the intruder simultaneously. Furthermore, neither robot may swap locations with the intruder in a single step.
