

Specification name: CatchingIntruder

Named domains:
- Dim: Int(0..D)

Environment variables:
- intruderX: Dim
- intruderY: Dim

System variables:
- robotX0: Dim
- robotY0: Dim
- robotX1: Dim
- robotY1: Dim

The system controls the positions of two robots, Robot 0 and Robot 1, within a grid environment where coordinates are integers from 0 to 7. The environment controls the position of an intruder. The system must satisfy the following safety guarantees at all times:

1.  **Static Obstacle Avoidance:** There is a static obstacle located at Y-coordinate 1 spanning X-coordinates 2 through 5. Both Robot 0 and Robot 1 must never occupy a position where the Y-coordinate is 1 while the X-coordinate is between 2 and 5 inclusive.
2.  **Inter-Robot Collision Avoidance:** Robot 0 and Robot 1 must never occupy the same grid position simultaneously.
3.  **Intruder Collision Avoidance:** Neither Robot 0 nor Robot 1 must ever occupy the same grid position as the intruder.
