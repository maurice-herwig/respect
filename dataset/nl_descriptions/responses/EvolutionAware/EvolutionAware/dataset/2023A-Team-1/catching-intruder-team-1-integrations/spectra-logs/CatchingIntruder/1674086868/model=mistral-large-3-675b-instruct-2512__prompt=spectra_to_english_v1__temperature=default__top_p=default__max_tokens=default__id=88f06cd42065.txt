**Requirements Description for the *CatchingIntruder* System**

This specification describes a reactive system in which two robots attempt to track an intruder within a bounded 7×7 grid (where both dimensions range from 0 to 6, inclusive).

**Environment and System Variables:**
- The environment controls the intruder’s position, represented by the coordinates *intruderX* and *intruderY*, each of which is an integer between 0 and 6.
- The system controls the positions of two robots, each defined by their coordinates:
  - Robot 0: *robotX0* and *robotY0*
  - Robot 1: *robotX1* and *robotY1*

**System Behavior:**
The system must ensure that the robots operate within the defined grid (0 to 6 for both coordinates) at all times. Beyond this, no additional guarantees or assumptions are specified for this partial description. The system’s behavior is currently only constrained by the initial validity of the robots’ positions.
