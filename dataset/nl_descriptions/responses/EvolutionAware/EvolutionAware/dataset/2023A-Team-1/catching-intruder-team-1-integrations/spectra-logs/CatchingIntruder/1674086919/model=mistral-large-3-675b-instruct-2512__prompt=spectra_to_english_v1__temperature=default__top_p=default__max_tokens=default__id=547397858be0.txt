The system models the behavior of two robots tracking an intruder on a 7×7 discrete grid (where coordinates range from 0 to 6). The system controls the positions of the two robots, represented by their coordinates `(robotX0, robotY0)` for the first robot and `(robotX1, robotY1)` for the second. The environment controls the intruder's position, given by `(intruderX, intruderY)`, and the number of elapsed turns, which cycles through values 0, 1, 2, and 3.

The system's requirements are as follows:

- Initially (at turn 0), both robots must start at the same position—specifically, at coordinate (0, 0).

The systems guarantees that:
- The robots always remain within the valid grid bounds `(0..6, 0..6)` during operation.
- The robots never collide with each other—that is, their positions are always distinct.
- From any valid starting state, the system ensures that within a bounded number of turns, one of the two robots will eventually reach the current position of the intruder. This means the intruder will be "caught" by either robot after some finite time.
