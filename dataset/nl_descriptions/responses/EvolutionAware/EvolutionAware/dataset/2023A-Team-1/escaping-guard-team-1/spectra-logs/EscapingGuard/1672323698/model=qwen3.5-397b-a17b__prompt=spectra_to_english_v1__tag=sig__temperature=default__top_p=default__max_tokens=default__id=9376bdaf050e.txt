

Specification name: EscapingGuard

Named domains:
- Dim: Int(0..D)

Environment variables:
- none

System variables:
- robotX: Dim
- robotY: Dim

**Requirements Description**

The system controls the position of a robot on a two-dimensional grid using the coordinates `robotX` and `robotY`. Both coordinates are integers ranging from 0 to 7.

Initially, the robot must start at the position where `robotX` is 7 and `robotY` is 0.

At every step of operation, the robot's movement is restricted such that the value of `robotX` and the value of `robotY` may each change by at most 1 unit from their previous values.

Additionally, the robot must never occupy a position where `robotX` is 2 and `robotY` is simultaneously 2, 3, 4, or 5.
