

Specification name: EscapingGuard

Named domains:
- Dim: Int(0..D)

Environment variables:
- none

System variables:
- robotX: Dim
- robotY: Dim

**Requirements Description**

The system controls the position of a robot on a two-dimensional grid. The coordinates are represented by the system variables `robotX` and `robotY`, both of which take integer values from 0 to 7 (where the constant D is 7).

The system maintains an internal cycle counter named `turn` that initializes to 1 and cycles repeatedly through the values 1, 2, and 3.

The system must ensure the following safety properties regarding the robot's movement and position:

1.  **Movement Constraint:** In every step, the change in the robot's position must be at most 1 unit in either the X or Y direction. Specifically, the absolute difference between the current value and the next value for both `robotX` and `robotY` must be less than or equal to 1.

2.  **Periodic Stopping:** Whenever the `turn` counter equals 3, the robot must remain stationary in the next step. That is, both `robotX` and `robotY` must retain their current values when `turn` is 3.

3.  **Obstacle Avoidance:** The robot must never occupy a forbidden region. Specifically, the robot must never be located at an X coordinate of 2 while simultaneously having a Y coordinate of 2, 3, 4, or 5.
