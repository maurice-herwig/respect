

Specification name: EscapingGuard

Named domains:
- Dim: Int(0..D)

Environment variables:
- none

System variables:
- robotX: Dim
- robotY: Dim

**Requirements Description**

The system controls a robot navigating a two-dimensional grid. The robot's position is defined by the coordinates `robotX` and `robotY`, where both values are integers ranging from 0 to 7.

**Initial Condition**
At the start of operation, the robot must be located at position `robotX = 7` and `robotY = 0`.

**Safety Requirements**
1.  **Legal Movement:** At every step, the robot's movement must be constrained. The value of each coordinate in the next state must differ from its current value by at most 1. This allows the robot to move to an adjacent grid cell or remain in its current cell.
2.  **Obstacle Avoidance:** The robot must never occupy a forbidden region. Specifically, it is prohibited for the robot to be at a position where `robotX` equals 2 while `robotY` is any value in the set {2, 3, 4, 5}.

**Liveness Requirements**
The robot must visit each of the following three target locations infinitely often throughout its operation:
1.  `robotX = 0`, `robotY = 0`
2.  `robotX = 7`, `robotY = 0`
3.  `robotX = 7`, `robotY = 7`
