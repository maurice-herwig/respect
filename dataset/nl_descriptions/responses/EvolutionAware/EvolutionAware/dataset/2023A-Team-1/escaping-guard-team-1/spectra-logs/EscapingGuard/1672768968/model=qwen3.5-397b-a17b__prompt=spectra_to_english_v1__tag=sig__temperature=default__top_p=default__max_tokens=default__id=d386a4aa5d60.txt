

Specification name: EscapingGuard

Named domains:
- Dim: Int(0..D)

Environment variables:
- none

System variables:
- robotX: Dim
- robotY: Dim

The system controls a robot moving on a two-dimensional grid. The robot's position is defined by the coordinates `robotX` and `robotY`, both of which are integers ranging from 0 to 7.

Initially, the robot starts at the position where `robotX` is 7 and `robotY` is 0.

At every step of the operation, the robot must move legally. The value of `robotX` in the next state must differ from its current value by at most 1, and the value of `robotY` in the next state must differ from its current value by at most 1.

The robot must avoid static obstacles at all times. Specifically, the robot must never occupy a position where `robotX` is 2 and `robotY` is simultaneously 2, 3, 4, or 5.

The robot must reach three specific target locations infinitely often during operation. These target locations are (0, 0), (7, 7), and (0, 7).
