### **Requirements for the EscapingGuard System**

The **EscapingGuard** system controls the position of a robot in a two-dimensional grid. The grid has dimensions from `0` to `7` (inclusive) along both axes.

#### **System-Controlled Outputs**
The system manages two outputs representing the robot's position:
- A horizontal coordinate (`robotX`), which must always be an integer between `0` and `7`.
- A vertical coordinate (`robotY`), which must always be an integer between `0` and `7`.

#### **Initial Condition**
When the system starts, the robot must be at position `(7, 0)`, meaning:
- `robotX` is initially set to `7`.
- `robotY` is initially set to `0`.

No further assumptions about the environment or additional guarantees are imposed in this specification. The system must ensure that the robot's initial position meets these constraints.
