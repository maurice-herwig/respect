

Specification name: EscapingGuard

Named domains:
- Dim: Int(0..D)

Environment variables:
- none

System variables:
- robotX: Dim
- robotY: Dim

The system controls the horizontal and vertical coordinates of a robot using the output variables robotX and robotY. Both coordinates are integers within the range 0 to 7.

Initially, the robot must start at the location where robotX is 7 and robotY is 0.

At every step of the system operation, the robot's movement is constrained. The value of robotX in the next state must differ from its current value by no more than 1. Similarly, the value of robotY in the next state must differ from its current value by no more than 1. This ensures that the robot either remains stationary or moves by exactly one unit along either axis at each step.
