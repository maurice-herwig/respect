

Specification name: EscapingGuard

Named domains:
- Dim: Int(0..D)

Environment variables:
- none

System variables:
- robotX: Dim
- robotY: Dim

The system controls the position of a robot using two coordinates, `robotX` and `robotY`. Both variables are system-controlled outputs that take values from the domain `Dim`, which consists of integers from 0 to 7 inclusive.

**Initial Conditions**
At the start of operation, the robot must be located at the position where `robotX` is 7 and `robotY` is 0.

**Safety Requirements**
The system must ensure that the robot moves legally at all times. For every transition from the current state to the next state, the value of `robotX` must change by no more than 1 unit, and the value of `robotY` must change by no more than 1 unit. Specifically, for both coordinates, the difference between the current value and the next value must be less than or equal to 1 in either direction. This constraint holds continuously throughout the system's execution.

**Guarantees**
The system guarantees the initial location and the legal movement constraints described above. There are no assumptions restricting environment behavior.
