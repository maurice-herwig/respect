

Specification name: EscapingGuard

Named domains:
- Dim: Int(0..D)

Environment variables:
- none

System variables:
- robotX: Dim
- robotY: Dim

**Requirements Description**

The system controls two output variables, `robotX` and `robotY`, which represent coordinates within the dimension range `Dim` (integers from 0 to 7). There are no environment-controlled inputs. The system must satisfy the following guarantee regarding its initial state: at the start of execution, `robotX` must be equal to 7 and `robotY` must be equal to 0.
