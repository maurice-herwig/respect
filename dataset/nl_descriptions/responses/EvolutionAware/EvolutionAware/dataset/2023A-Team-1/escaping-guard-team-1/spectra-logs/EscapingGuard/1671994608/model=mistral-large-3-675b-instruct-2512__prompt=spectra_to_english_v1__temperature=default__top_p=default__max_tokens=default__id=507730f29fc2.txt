### **Requirements Description: EscapingGuard System**

The **Escorting Guard** system describes a reactive interaction between an environment and a robotic agent moving in a grid of size **7×7** (indices ranging from 0 to 6 in each dimension). The system controls the robot's position, defined by two outputs: `robotX` (horizontal position) and `robotY` (vertical position), both of which are integers within the grid bounds.

**System Guarantees:**
1. **Movement Constraints:**
   - The robot can move at most one unit per step in either the horizontal (`robotX`) or vertical (`robotY`) direction. This means its position in each dimension may stay the same or change by ±1 in a single step.

2. **Obstacle Avoidance:**
   - The robot must never be at position `(2, y)` where `y` is 2, 3, 4, or 5. This corresponds to avoiding the vertical line of obstacles at `x = 2` in these specific rows.

The system must ensure these guarantees hold at all times during operation. There are no explicitly stated assumptions about the environment nor any initial conditions, liveness requirements, or next-state rules beyond the movement and obstacle avoidance guarantees.
