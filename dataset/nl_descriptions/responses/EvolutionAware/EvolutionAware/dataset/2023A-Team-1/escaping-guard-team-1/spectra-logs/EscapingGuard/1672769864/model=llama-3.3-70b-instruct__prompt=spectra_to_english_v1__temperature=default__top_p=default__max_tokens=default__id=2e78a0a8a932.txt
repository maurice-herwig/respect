The system is a robot that moves within a grid of size 8x8. The robot's position is defined by its x and y coordinates, `robotX` and `robotY`, which are controlled by the system. The environment does not have any explicitly defined inputs.

The system is expected to satisfy the following requirements:

Initially, the robot must start at the location (7, 0).

At all times, the robot's movement must be legal, meaning that its x and y coordinates can only change by at most 1 unit in either direction.

The robot must avoid colliding with static obstacles. Specifically, it must never be at the x-coordinate `staticObstaclesX` (which is 2) when its y-coordinate is 2, 3, 4, or 5.

The system must ensure that the robot reaches each of three targets infinitely often. The targets are located at coordinates (0, 0), (7, 7), and (0, 7). 

There are no explicit assumptions about the environment's behavior, so the system must be able to satisfy these requirements regardless of any external factors.
