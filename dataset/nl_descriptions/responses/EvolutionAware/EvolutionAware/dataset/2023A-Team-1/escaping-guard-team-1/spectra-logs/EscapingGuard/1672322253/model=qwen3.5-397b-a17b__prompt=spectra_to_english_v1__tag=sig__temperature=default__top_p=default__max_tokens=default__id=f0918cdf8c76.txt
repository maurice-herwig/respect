

Specification name: EscapingGuard

Named domains:
- Dim: Int(0..D)

Environment variables:
- none

System variables:
- robotX: Dim
- robotY: Dim

The system controls the variables robotX and robotY. Both variables are constrained to the domain Dim, which consists of integer values from 0 to 7 inclusive. The system is responsible for determining the values of these variables during operation.
