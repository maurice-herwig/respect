The system controls the position of a robot within a defined two-dimensional grid. The grid spans from 0 to 6 in both the x and y directions (inclusive). The robot's position is represented by two system-controlled variables: **robotX** and **robotY**, each holding integer values that must remain within this range.

At all times, the robot must stay within the bounds of the grid—that is, its x-coordinate (robotX) and y-coordinate (robotY) must never go below 0 or exceed 6. There are no assumptions on the environment in this specification, and no additional requirements (such as movement rules or liveness conditions) are imposed beyond this initial safety constraint.
