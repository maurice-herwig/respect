

Specification name: EscapingGuard

Named domains:
- Dim: Int(0..D)

Environment variables:
- none

System variables:
- robotX: Dim
- robotY: Dim

The system controls the position of a robot on a two-dimensional grid using the coordinates `robotX` and `robotY`. Both coordinates are integers within the range 0 to 7 (inclusive), corresponding to the domain `Dim`. There are no environment inputs; the system determines the values of both coordinates.

The system must satisfy the following safety guarantees at all times:

1. Movement Constraint: Between any consecutive states, the value of `robotX` and the value of `robotY` must each change by no more than 1.
2. Obstacle Avoidance: The robot must never occupy a position where `robotX` is 2 while `robotY` is simultaneously 2, 3, 4, or 5.
