

Specification name: EscapingGuard

Named domains:
- Dim: Int(0..D)

Environment variables:
- none

System variables:
- robotX: Dim
- robotY: Dim

The system controls two variables, `robotX` and `robotY`, which represent coordinates within the integer domain `Dim`. The system operates autonomously without environment inputs or assumptions restricting environment behavior. The specification imposes a safety guarantee on the movement of these coordinates. At every step of the execution, the difference between the current value and the next value for both `robotX` and `robotY` must be strictly less than 1 in both positive and negative directions. Since the variables are integers, this constraint requires that the values of `robotX` and `robotY` remain constant throughout the system's operation; they cannot change from one state to the next. There are no specific initial conditions imposed on the variables other than they must belong to the defined domain.
