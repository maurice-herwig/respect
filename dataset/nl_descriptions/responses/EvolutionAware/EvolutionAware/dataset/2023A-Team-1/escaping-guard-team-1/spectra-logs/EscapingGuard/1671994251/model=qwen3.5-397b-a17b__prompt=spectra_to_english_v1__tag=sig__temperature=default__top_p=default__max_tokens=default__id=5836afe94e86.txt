

Specification name: EscapingGuard

Named domains:
- Dim: Int(0..D)

Environment variables:
- none

System variables:
- robotX: Dim
- robotY: Dim

The system controls the robot's position using two coordinates, `robotX` and `robotY`. Both variables are integers ranging from 0 to 7, inclusive. The system must guarantee that throughout operation, the robot's movement is restricted in every step. Specifically, the value of `robotX` in the next state must differ from its current value by at most 1. Likewise, the value of `robotY` in the next state must differ from its current value by at most 1. This ensures that each coordinate either remains the same, increases by 1, or decreases by 1 at every transition. This safety requirement must hold continuously during system execution.
