

Specification name: EscapingGuard

Named domains:
- Dim: Int(0..D)

Environment variables:
- none

System variables:
- robotX: Dim
- robotY: Dim

The system controls two variables, `robotX` and `robotY`, which represent coordinates within the integer range 0 to 7. The system must ensure that at the initial state of execution, `robotX` is equal to 7 and `robotY` is equal to 0.
