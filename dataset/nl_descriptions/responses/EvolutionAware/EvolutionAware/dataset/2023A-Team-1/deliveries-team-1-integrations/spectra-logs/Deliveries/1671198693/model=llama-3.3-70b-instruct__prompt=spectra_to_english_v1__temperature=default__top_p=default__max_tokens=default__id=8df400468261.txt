The system, Deliveries, describes the interaction between a robotic delivery system and its environment, specifically an elevator. The environment controls the elevator's vertical position, represented by `elevatorY`, which can range from 0 to `DY` (5). The system controls the positions of two robots, `robotX0`, `robotY0`, `robotX1`, and `robotY1`, which represent the horizontal and vertical coordinates of the robots within a grid of size `DX` (5) by `DY` (5).

The environment is assumed to move the elevator vertically in a way that its position either stays the same or changes by one unit at a time.

Initially, both robots are positioned at a vertical coordinate of 5. The system guarantees that the robots move horizontally and vertically in a way that their positions either stay the same or change by one unit at a time.

Furthermore, the system ensures that when the first robot is at the leftmost position (horizontal coordinate 0), its vertical position matches the elevator's vertical position. This implies that the robot moves between floors only when it is aligned with the elevator. 

At all times, the robots' movements are constrained to change their positions by at most one unit in either the horizontal or vertical direction, ensuring a gradual and controlled movement within the defined grid.
