

Specification name: Deliveries

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)
- Coord: Int(0..DY)

Environment variables:
- elevatorY: DimY

System variables:
- robotX0: DimX
- robotY0: DimY
- robotX1: DimX
- robotY1: DimY

**Requirements Description**

This specification defines the behavior of a delivery system involving two robots and an elevator operating within a grid coordinate space. The horizontal coordinates (X) and vertical coordinates (Y) range from 0 to 5.

**Initial Conditions**
At the start of operation, the vertical position of both robot 0 (`robotY0`) and robot 1 (`robotY1`) is initialized to 5. The initial horizontal positions are unspecified.

**Environment Assumptions**
The environment controls the vertical position of the elevator (`elevatorY`). The elevator is assumed to move smoothly; specifically, its vertical position may change by at most one unit per step (it may increase by 1, decrease by 1, or remain the same).

**System Guarantees**
The system controls the horizontal and vertical positions of both robots (`robotX0`, `robotY0`, `robotX1`, `robotY1`). The system must satisfy the following requirements:

1.  **Movement Constraints:** In every step, the position of each robot along both the X and Y axes may change by at most one unit. For each coordinate, the next value must be either the current value plus one, the current value minus one, or the current value unchanged.
2.  **Vertical Movement Restriction:** A robot is permitted to change its vertical position only when its horizontal position is 0. If a robot's horizontal position (`robotX0` or `robotX1`) is not 0, its vertical position (`robotY0` or `robotY1`) must remain unchanged in the next step.
