

Specification name: Deliveries

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)
- Coord: Int(0..DY)

Environment variables:
- elevatorY: DimY

System variables:
- robotX0: DimX
- robotY0: DimY
- robotX1: DimX
- robotY1: DimY

**Requirements Description**

The system controls the positions of two robots, Robot 0 and Robot 1, within a grid defined by the dimensions DimX and DimY. The environment controls the vertical position of an elevator.

**Initial Conditions**
At the start of operation, the vertical position of Robot 0 (`robotY0`) and the vertical position of Robot 1 (`robotY1`) are both initialized to 5.

**System Guarantees**
The system must ensure that both robots move smoothly across the grid. At each step, the horizontal position (`robotX0`, `robotX1`) and vertical position (`robotY0`, `robotY1`) of each robot may increase by 1, decrease by 1, or remain unchanged.

Additionally, Robot 0 is subject to a specific movement constraint regarding its vertical position. Robot 0 may only change its vertical position (`robotY0`) when its horizontal position (`robotX0`) is 0. If `robotX0` is not 0, `robotY0` must remain constant in the next step.

**Environment Assumptions**
The environment is assumed to operate the elevator smoothly. The elevator's vertical position (`elevatorY`) may change by at most 1 unit, or remain unchanged, at each step.
