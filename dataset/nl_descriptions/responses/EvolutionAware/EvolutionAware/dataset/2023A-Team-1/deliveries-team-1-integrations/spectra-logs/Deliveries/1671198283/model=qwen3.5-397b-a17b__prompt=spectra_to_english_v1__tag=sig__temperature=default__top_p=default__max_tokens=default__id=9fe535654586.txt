

Specification name: Deliveries

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)
- Coord: Int(0..DY)

Environment variables:
- none

System variables:
- robotX0: DimX
- robotY0: DimY
- robotX1: DimX
- robotY1: DimY

**Requirements Description**

The system controls the positions of two robots, Robot 0 and Robot 1, on a two-dimensional grid. The horizontal positions (`robotX0` and `robotX1`) and vertical positions (`robotY0` and `robotY1`) are integers bounded between 0 and 5.

**Initial Conditions**
At the start of operation, the vertical positions of both robots must be initialized to 5. Specifically, `robotY0` must equal 5 and `robotY1` must equal 5.

**Safety Requirements**
Throughout operation, the movement of both robots is constrained at every step. For each coordinate variable (`robotX0`, `robotY0`, `robotX1`, and `robotY1`), the value in the next state must differ from the current value by at most 1 unit. Specifically, the next value for any coordinate must be either equal to the current value, one greater than the current value, or one less than the current value. This ensures that both robots move at most one unit horizontally or vertically per step, or remain stationary.
