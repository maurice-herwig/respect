The system consists of two robots operating within a defined area of dimensions 5x5. The environment provides the delivery locations, represented by `deliveriesX` and `deliveriesY`, which are arrays of two elements each, specifying the x and y coordinates of the delivery points. The system controls the positions of the two robots, `robotX0`, `robotY0`, `robotX1`, and `robotY1`, which are the x and y coordinates of the robots.

The environment is assumed to ensure that the delivery points are never on the ground floor, meaning the y-coordinates of the delivery points are always greater than 5.

The system guarantees that each robot will deliver packages to their respective assigned delivery points. Specifically, robot 0 will deliver packages to the location specified by `deliveriesX[0]` and `deliveriesY[0]`, and robot 1 will deliver packages to the location specified by `deliveriesX[1]` and `deliveriesY[1]`. This delivery is considered to occur when the robot's position matches the delivery point's coordinates.

Additionally, the system guarantees that each robot will periodically return to the right corner of the ground floor, which is the location (5, 5).

The system also maintains two counters, `packagesDeliveredByRobot0` and `packagesDeliveredByRobot1`, which track the number of packages delivered by each robot. These counters are incremented when a robot delivers a package, and reset when the robot returns to the right corner of the ground floor. The counters have a maximum value of 3 and do not overflow.
