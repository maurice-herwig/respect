

Specification name: Deliveries

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)
- Coord: Int(0..DY)

Environment variables:
- elevatorY: DimY
- deliveriesX: DimX [2]
- deliveriesY: DimY [2]

System variables:
- robotX0: DimX
- robotY0: DimY
- robotX1: DimX
- robotY1: DimY

**Requirements Description**

This specification defines the behavior of a system controlling two robots, Robot 0 and Robot 1, operating within a grid environment. The system manages the horizontal (X) and vertical (Y) coordinates of both robots. The environment provides the vertical position of an elevator and delivery location data. The horizontal position of the elevator is fixed at 0.

**Initial Conditions**
Upon system initialization, the vertical coordinate of Robot 0 (`robotY0`) and the vertical coordinate of Robot 1 (`robotY1`) must both be set to 5.

**Environment Assumptions**
The environment is assumed to operate the elevator such that its vertical position (`elevatorY`) changes by at most one unit between consecutive steps.

**System Guarantees**
The system must ensure the following behaviors regarding robot movement and elevator usage:

1.  **Movement Constraints:** Both robots must move smoothly. Between any two consecutive steps, the horizontal and vertical coordinates of each robot may change by no more than one unit.
2.  **Elevator Usage:** A robot is permitted to change its vertical coordinate only if it is currently located at horizontal position 0 and its vertical position matches the current vertical position of the elevator. Furthermore, if a robot changes its vertical coordinate, its horizontal position must remain 0 in the subsequent step. Vertical movement is thus restricted to the elevator shaft at horizontal position 0.
