

Specification name: Deliveries

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)
- Coord: Int(0..DY)

Environment variables:
- elevatorY: DimY
- deliveriesX: DimX [2]
- deliveriesY: DimY [2]

System variables:
- robotX0: DimX
- robotY0: DimY
- robotX1: DimX
- robotY1: DimY

The system controls the coordinates of two robots, Robot 0 and Robot 1, operating within a grid where X and Y coordinates range from 0 to 5. The environment provides the current elevator position and two sets of delivery coordinates via arrays. Specifically, the environment inputs `deliveriesX` and `deliveriesY` each contain two values representing the target X and Y locations for the respective robots.

There are no assumptions restricting the behavior of the environment.

The system must satisfy the following guarantees:

**Safety Requirements:**
The system ensures that Robot 0 is always positioned at the X coordinate 5 and the Y coordinate 5. Similarly, the system ensures that Robot 1 is always positioned at the X coordinate 5 and the Y coordinate 5.

**Liveness Requirements:**
Infinitely often, Robot 0 must be located at the coordinates specified by the first elements of the environment's delivery arrays (`deliveriesX[0]` and `deliveriesY[0]`). Likewise, infinitely often, Robot 1 must be located at the coordinates specified by the second elements of the delivery arrays (`deliveriesX[1]` and `deliveriesY[1]`).
