

Specification name: Deliveries

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)
- Coord: Int(0..DY)

Environment variables:
- elevatorY: DimY
- deliveriesX: DimX [2]
- deliveriesY: DimY [2]

System variables:
- robotX0: DimX
- robotY0: DimY
- robotX1: DimX
- robotY1: DimY

**Requirements Description**

The system manages the positions of two robots within a grid environment defined by the dimensions DimX and DimY. The environment provides target delivery locations for the robots via the input arrays `deliveriesX` and `deliveriesY`, each containing two coordinates. The system controls the X and Y coordinates for Robot 0 (`robotX0`, `robotY0`) and Robot 1 (`robotX1`, `robotY1`).

The system must satisfy the following liveness guarantees:

1.  **Robot 0 Delivery:** Infinitely often, the position of Robot 0 must match the first delivery location provided by the environment. Specifically, `robotX0` must equal `deliveriesX[0]` and `robotY0` must equal `deliveriesY[0]`.
2.  **Robot 1 Delivery:** Infinitely often, the position of Robot 1 must match the second delivery location provided by the environment. Specifically, `robotX1` must equal `deliveriesX[1]` and `robotY1` must equal `deliveriesY[1]`.

These requirements ensure that both robots repeatedly reach their respective assigned delivery coordinates over the course of system operation.
