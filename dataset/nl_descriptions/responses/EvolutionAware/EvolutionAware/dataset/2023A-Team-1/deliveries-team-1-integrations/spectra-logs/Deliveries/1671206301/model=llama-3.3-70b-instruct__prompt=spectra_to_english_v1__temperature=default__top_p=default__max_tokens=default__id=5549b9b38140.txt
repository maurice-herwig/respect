The system controls two robots, with initial positions robotX0, robotY0, robotX1, and robotY1. The environment provides the locations of two deliveries, specified by deliveriesX[0], deliveriesY[0], deliveriesX[1], and deliveriesY[1], as well as an elevator position, elevatorY, which is not used in the system's behavior.

The environment is assumed to never place deliveries at position 5 on the x-axis, ensuring that deliveriesX[0] and deliveriesX[1] are always less than 5.

The system guarantees that each robot will deliver its assigned package by eventually moving to the delivery location. Specifically, robot 0 must move to the location specified by deliveriesX[0] and deliveriesY[0], and robot 1 must move to the location specified by deliveriesX[1] and deliveriesY[1]. Both robots are also required to periodically return to the right corner of the ground floor, at position (5, 5).

The system tracks the number of packages delivered by each robot using counters packagesDeliveredByRobot0 and packagesDeliveredByRobot1. These counters increment whenever a robot delivers a package (i.e., reaches the delivery location) and reset whenever the robot returns to the right corner of the ground floor. The counters will keep their current value if they reach their maximum value of 4.

At all times, the system ensures that the number of packages delivered by each robot remains less than 4.
