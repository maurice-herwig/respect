The system consists of two robots operating within a 5x5 grid, with coordinates ranging from 0 to 5 in both the x and y dimensions. The environment controls the x and y coordinates of two delivery packages, as well as a mock elevator y-coordinate. The system controls the x and y coordinates of the two robots.

The environment is assumed to never place delivery packages at the right corner of the ground floor, i.e., at coordinates (5, 5).

The system guarantees that each robot will deliver its assigned package by eventually moving to the package's location. Specifically, robot 0 will deliver the package at coordinates (deliveriesX[0], deliveriesY[0]), and robot 1 will deliver the package at coordinates (deliveriesX[1], deliveriesY[1]). 

Additionally, the system ensures that each robot will periodically return to the right corner of the ground floor, i.e., coordinates (5, 5).

The system also maintains two counters, one for each robot, to track the number of packages delivered. The counters increment when a robot delivers a package and reset when the robot returns to the right corner of the ground floor. If a counter reaches its maximum value of 4, it will remain at that value.

The system guarantees that the number of packages delivered by each robot will always be less than 4.
