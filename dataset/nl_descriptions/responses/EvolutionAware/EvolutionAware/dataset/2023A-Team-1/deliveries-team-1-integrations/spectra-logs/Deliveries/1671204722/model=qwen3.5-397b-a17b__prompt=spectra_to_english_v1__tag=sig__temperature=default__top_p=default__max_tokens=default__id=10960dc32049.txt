

Specification name: Deliveries

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)
- Coord: Int(0..DY)

Environment variables:
- elevatorY: DimY
- deliveriesX: DimX [2]
- deliveriesY: DimY [2]

System variables:
- robotX0: DimX
- robotY0: DimY
- robotX1: DimX
- robotY1: DimY

The system controls the horizontal and vertical positions of two robots, Robot 0 and Robot 1, within a grid where the maximum coordinate value for both dimensions is 5. The environment provides target delivery locations for both robots through arrays. The system must satisfy the following liveness requirements:

1. Robot 0 must infinitely often reach the position specified by the first elements of the delivery coordinate arrays provided by the environment.
2. Robot 1 must infinitely often reach the position specified by the second elements of the delivery coordinate arrays provided by the environment.
3. Robot 0 must infinitely often reach the specific coordinate (5, 5).
4. Robot 1 must infinitely often reach the specific coordinate (5, 5).
