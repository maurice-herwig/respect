The system consists of two robots operating within a 5x5 grid, with coordinates ranging from 0 to 5 in both the x and y dimensions. The environment provides the x and y coordinates of two delivery locations, represented by `deliveriesX` and `deliveriesY`. The system controls the x and y coordinates of the two robots, denoted as `robotX0`, `robotY0`, `robotX1`, and `robotY1`.

The environment is assumed to ensure that the delivery locations are never on the ground floor, i.e., their y-coordinates are always greater than 5.

The system guarantees the following behavior:

- Robot 0 will deliver a package whenever it reaches the location specified by `deliveriesX[0]` and `deliveriesY[0]`, and similarly, Robot 1 will deliver a package when it reaches the location specified by `deliveriesX[1]` and `deliveriesY[1]`.
- Both robots will always eventually be at the right corner of the ground floor, i.e., at coordinates (5, 5).
- The system maintains two counters, `packagesDeliveredByRobot0` and `packagesDeliveredByRobot1`, to track the number of packages delivered by each robot. These counters are incremented whenever a robot delivers a package and reset when the robot returns to the right corner of the ground floor.
- The system ensures that each robot delivers fewer than 4 packages.

In summary, the system controls two robots that operate within a grid, delivering packages at locations specified by the environment while ensuring that the robots periodically return to a designated location and do not exceed a certain number of deliveries.
