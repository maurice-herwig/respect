

Specification name: Deliveries

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)
- Coord: Int(0..DY)

Environment variables:
- elevatorY: DimY

System variables:
- robotX0: DimX
- robotY0: DimY
- robotX1: DimX
- robotY1: DimY

The system controls the horizontal and vertical positions of two robots, Robot 0 and Robot 1, while the environment controls the vertical position of an elevator. The system outputs are the coordinates `robotX0`, `robotY0`, `robotX1`, and `robotY1`. The environment input is the elevator coordinate `elevatorY`. All coordinates are integers within the specified domains DimX and DimY.

Initially, the vertical positions of both robots (`robotY0` and `robotY1`) must be set to 5.

The environment is assumed to operate the elevator such that its vertical position (`elevatorY`) changes by at most one unit per step. Specifically, in any step, the elevator's next vertical position must be equal to its current position, one greater than its current position, or one less than its current position.

The system must satisfy the following guarantees:
1.  **Robot Movement:** In every step, the horizontal and vertical positions of both robots must change by at most one unit. For each robot coordinate, the next value must be equal to the current value, one greater than the current value, or one less than the current value.
2.  **Elevator Alignment:** Whenever Robot 0 is at horizontal position 0 (`robotX0 = 0`), its vertical position (`robotY0`) must match the elevator's vertical position (`elevatorY`).
