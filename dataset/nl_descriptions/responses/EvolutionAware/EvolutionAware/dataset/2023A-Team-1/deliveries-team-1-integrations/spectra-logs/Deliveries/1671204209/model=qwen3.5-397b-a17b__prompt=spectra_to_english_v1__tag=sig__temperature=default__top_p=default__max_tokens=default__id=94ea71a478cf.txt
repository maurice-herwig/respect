

Specification name: Deliveries

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)
- Coord: Int(0..DY)

Environment variables:
- elevatorY: DimY
- deliveriesX: DimX [2]
- deliveriesY: DimY [2]

System variables:
- robotX0: DimX
- robotY0: DimY
- robotX1: DimX
- robotY1: DimY

The system controls the coordinates of two robots operating on a two-dimensional grid where both X and Y axes range from 0 to 5. The environment provides target delivery coordinates for two packages.

The system must satisfy the following liveness requirements:
1. Robot 0 must infinitely often reach the location specified by the environment at index 0 of the delivery arrays. Specifically, the system variables `robotX0` and `robotY0` must simultaneously equal `deliveriesX[0]` and `deliveriesY[0]` infinitely often.
2. Robot 1 must infinitely often reach the location specified by the environment at index 1 of the delivery arrays. Specifically, the system variables `robotX1` and `robotY1` must simultaneously equal `deliveriesX[1]` and `deliveriesY[1]` infinitely often.
