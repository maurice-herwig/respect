The system consists of two robots operating within a defined grid of dimensions 5x5. The environment controls the locations of two packages to be delivered, represented by `deliveriesX` and `deliveriesY`, as well as a mock variable `elevatorY` for simulation purposes. The system controls the positions of the two robots, `robotX0`, `robotY0`, `robotX1`, and `robotY1`.

The environment is assumed to ensure that the packages are not located at the right corner of the ground floor, as specified by the condition that `deliveriesX[0]` and `deliveriesX[1]` are not equal to 5.

The system guarantees the following behavior:

- Robot 0 will deliver its assigned package whenever it reaches the package's location, as indicated by `robotX0` equaling `deliveriesX[0]` and `robotY0` equaling `deliveriesY[0]`.
- Robot 1 will deliver its assigned package whenever it reaches the package's location, as indicated by `robotX1` equaling `deliveriesX[1]` and `robotY1` equaling `deliveriesY[1]`.
- Robot 0 will always eventually be at the right corner of the ground floor, where `robotX0` equals 5 and `robotY0` equals 5.
- Robot 1 will always eventually be at the right corner of the ground floor, where `robotX1` equals 5 and `robotY1` equals 5.

Two counters, `packagesDeliveredByRobot0` and `packagesDeliveredByRobot1`, keep track of the number of packages delivered by each robot. These counters increment whenever a robot delivers a package (i.e., when a robot's position matches the package's location) and reset when the robot returns to the right corner of the ground floor. If the counter reaches its maximum value of 4, it will remain at that value (overflow: keep).

The system ensures that the number of packages delivered by each robot never exceeds 3, as specified by the condition that `packagesDeliveredByRobot0` and `packagesDeliveredByRobot1` are always less than 4.
