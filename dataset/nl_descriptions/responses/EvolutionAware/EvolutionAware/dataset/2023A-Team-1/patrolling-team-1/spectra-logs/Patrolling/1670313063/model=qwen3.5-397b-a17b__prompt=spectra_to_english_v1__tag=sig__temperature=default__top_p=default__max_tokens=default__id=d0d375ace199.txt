

Specification name: Patrolling

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)

Environment variables:
- goalsX: DimX[num_targets]
- goalsY: DimY[num_targets]

System variables:
- robotX: DimX
- robotY: DimY

**System Overview**
The system controls a robot navigating a two-dimensional grid. The grid coordinates for both X and Y axes range from 0 to 4. The environment provides the locations of three target goals. Additionally, there are five fixed static obstacles located at the following coordinates: (1,1), (3,3), (2,1), (0,3), and (3,4).

**Environment Assumptions**
The environment is assumed to adhere to the following constraints regarding the goal locations:
1.  **Static Goals:** The coordinates for all goal locations remain constant throughout operation; they do not change between states.
2.  **Valid Placement:** No goal location coincides with the location of any static obstacle.

**System Guarantees**
The system must ensure the following behaviors regarding the robot's movement and objectives:
1.  **Movement Constraints:** In each transition, the robot's position may change by at most one unit in the X direction and at most one unit in the Y direction. The robot may move to an adjacent cell horizontally or vertically, or remain in its current cell.
2.  **Obstacle Avoidance:** The robot must never occupy a cell containing a static obstacle.
3.  **Goal Visitation:** The robot must visit every specified goal location infinitely often. For each of the three goals, the robot's coordinates must coincide with the goal's coordinates repeatedly throughout the system's infinite operation.
