

Specification name: Patrolling

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)

Environment variables:
- goalsX: DimX[num_targets]
- goalsY: DimY[num_targets]

System variables:
- robotX: DimX
- robotY: DimY

**Requirements Description**

The system controls the movement of a robot on a two-dimensional grid. The environment provides the fixed locations of multiple targets. The system must ensure the robot visits every target location repeatedly while adhering to specific movement constraints.

**Environment Assumptions**
The environment defines the X and Y coordinates for each target. These target locations are static; once set, the coordinates for every target remain constant and do not change between system steps.

**System Guarantees**
1.  **Movement Constraints:** In every step, the robot's position must change gradually. Specifically, the robot's X coordinate and Y coordinate may each increase by one, decrease by one, or remain unchanged. The robot cannot move more than one unit in either direction per step.
2.  **Patrolling Requirement:** The robot must visit the location of every target infinitely often. For each target, the robot's position must eventually coincide with that target's coordinates, and this event must recur indefinitely throughout the system's operation.
