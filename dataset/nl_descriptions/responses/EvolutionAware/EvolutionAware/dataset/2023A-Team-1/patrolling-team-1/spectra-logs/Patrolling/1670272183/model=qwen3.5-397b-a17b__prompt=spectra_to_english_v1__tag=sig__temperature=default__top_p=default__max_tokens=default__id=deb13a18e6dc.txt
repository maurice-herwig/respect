

Specification name: Patrolling

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)

Environment variables:
- goalsX: DimX[num_targets]
- goalsY: DimY[num_targets]

System variables:
- robotX: DimX
- robotY: DimY

**Requirements Description**

This specification defines a reactive system for a robot patrolling a grid environment. The grid spans coordinates from 0 to 4 in both the X and Y dimensions (where DX = 4 and DY = 4). The system controls the robot's current position, while the environment provides the fixed locations of target goals.

**Environment Assumptions**
The environment provides the coordinates for three target goals via the input arrays `goalsX` and `goalsY`. It is assumed that the location of each goal remains constant throughout operation; the values in `goalsX` and `goalsY` do not change between states. Additionally, the environment ensures that no goal is placed on top of any of the five predefined static obstacles. The static obstacles are permanently located at the following (X, Y) coordinates: (1, 1), (3, 3), (2, 1), (0, 3), and (3, 4).

**System Guarantees**
The system must control the output variables `robotX` and `robotY` to satisfy the following requirements:

1.  **Movement Constraint:** In every step, the robot's position may change by at most one unit in the X direction and at most one unit in the Y direction. Specifically, the next value of `robotX` must be equal to the current value, the current value plus one, or the current value minus one. The same constraint applies to `robotY`.
2.  **Obstacle Avoidance:** The robot must never occupy the same position as any of the five static obstacles. At all times, the pair (`robotX`, `robotY`) must differ from the coordinates of every static obstacle.
3.  **Goal Visitation:** The robot must visit the location of each of the three goals infinitely often. For every goal index, the system guarantees that the robot will eventually reach the position specified by `goalsX` and `goalsY` for that index, and this behavior must repeat indefinitely.
