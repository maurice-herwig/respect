

Specification name: Patrolling

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)

Environment variables:
- goalsX: DimX[num_targets]
- goalsY: DimY[num_targets]

System variables:
- robotX: DimX
- robotY: DimY

The system controls a robot operating on a two-dimensional grid where both X and Y coordinates range from 0 to 4. The system determines the robot's current position using the variables `robotX` and `robotY`. The environment provides the locations of three distinct targets using the arrays `goalsX` and `goalsY`, where each index from 0 to 2 corresponds to the X and Y coordinates of a specific target.

The environment is assumed to maintain stationary target locations. The coordinates for all three targets must remain constant throughout the operation; they do not change from one step to the next.

The system must satisfy the following guarantees regarding the robot's behavior:

1.  **Movement Constraint:** At every step, the robot's position may change by at most one unit in either the X or Y direction. The robot may move to an adjacent coordinate horizontally or vertically, or it may remain in its current position.
2.  **Patrolling Requirement:** The robot must visit the location of each of the three targets infinitely often. Specifically, the robot must reach the coordinates of target 0, target 1, and target 2 repeatedly over time.
