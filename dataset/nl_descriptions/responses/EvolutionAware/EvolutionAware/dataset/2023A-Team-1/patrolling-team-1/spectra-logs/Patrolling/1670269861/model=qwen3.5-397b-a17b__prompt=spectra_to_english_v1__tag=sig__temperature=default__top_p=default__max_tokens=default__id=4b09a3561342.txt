

Specification name: Patrolling

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)

Environment variables:
- goalsX: DimX[num_targets]
- goalsY: DimY[num_targets]

System variables:
- robotX: DimX
- robotY: DimY

**Requirements Description**

The system controls a robot navigating a two-dimensional grid where both X and Y coordinates range from 0 to 4. The system determines the robot's position (`robotX`, `robotY`), while the environment provides the locations of three targets (`goalsX`, `goalsY`). There are five static obstacles located at fixed coordinates within the grid.

**Environment Assumptions**
The environment must adhere to the following constraints regarding the target locations:
1.  **Static Targets:** The coordinates of all three targets remain constant throughout operation; they do not change position over time.
2.  **Valid Placement:** No target location coincides with the location of any static obstacle.

**System Guarantees**
The system must ensure the robot behaves according to the following requirements:
1.  **Movement Constraint:** At each step, the robot's X and Y coordinates may change by at most 1 unit. Specifically, each coordinate may increase by 1, decrease by 1, or remain unchanged in any single transition.
2.  **Obstacle Avoidance:** The robot must never occupy the same location as any of the five static obstacles.
3.  **Patrolling Requirement:** The robot must visit every target location infinitely often.
