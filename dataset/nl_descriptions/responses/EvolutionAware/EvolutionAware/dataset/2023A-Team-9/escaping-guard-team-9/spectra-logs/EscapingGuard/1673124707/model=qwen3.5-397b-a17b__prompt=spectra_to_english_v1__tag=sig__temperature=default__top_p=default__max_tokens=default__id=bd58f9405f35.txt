

Specification name: EscapingGuard

Named domains:
- Dim: Int(0..D)
- guardDim: Int(0..6)

Environment variables:
- guardX: guardDim
- guardY: guardDim

System variables:
- robotX: Dim
- robotY: Dim

The system controls the position of a robot on a grid, while the environment controls the position of a guard. The robot's coordinates, `robotX` and `robotY`, are system-controlled outputs defined over the domain `Dim`, which represents integers from 0 to 7. The guard's coordinates, `guardX` and `guardY`, are environment-controlled inputs defined over the domain `guardDim`, which represents integers from 0 to 6. The specification defines several constant coordinates for targets and obstacles within the grid. The system must satisfy the following guarantee regarding the initial state: at the start of execution, the robot's X coordinate must be 7 and the robot's Y coordinate must be 0.
