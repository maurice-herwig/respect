

Specification name: EscapingGuard

Named domains:
- Dim: Int(0..D)
- guardDim: Int(0..6)

Environment variables:
- guardX: guardDim
- guardY: guardDim

System variables:
- robotX: Dim
- robotY: Dim

**Requirements Description**

The system controls the movement of a robot on a two-dimensional grid, while the environment provides the position of a guard. The robot's position is defined by the coordinates `robotX` and `robotY`, and the guard's position is defined by `guardX` and `guardY`.

**Initial Conditions**
At the start of system operation, the robot is positioned at `robotX` = 7 and `robotY` = 0.

**Safety Requirements**
The robot must remain within the grid boundaries defined by the domain 0 to 7 for both coordinates. At every step, the robot's movement is constrained such that each coordinate (`robotX` and `robotY`) may only change by at most one unit. Specifically, the value of each coordinate in the next state must be equal to, one greater than, or one less than its current value.

**Liveness Requirements**
The robot must visit each of the following three target locations infinitely often during operation:
1. Target T1, located at `robotX` = 0 and `robotY` = 0.
2. Target T2, located at `robotX` = 7 and `robotY` = 7.
3. Target T3, located at `robotX` = 0 and `robotY` = 7.
