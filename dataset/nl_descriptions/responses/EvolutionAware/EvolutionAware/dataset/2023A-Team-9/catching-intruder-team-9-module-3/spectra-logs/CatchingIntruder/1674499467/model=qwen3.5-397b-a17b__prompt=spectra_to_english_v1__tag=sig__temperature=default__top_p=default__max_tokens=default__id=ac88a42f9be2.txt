

Specification name: CatchingIntruder

Named domains:
- Dim: Int(0..D)

Environment variables:
- intruderX: Dim
- intruderY: Dim

System variables:
- robotX0: Dim
- robotY0: Dim
- robotX1: Dim
- robotY1: Dim

The system manages the positions of two robots, Robot 0 and Robot 1, operating on a grid defined by the domain `Dim`, which consists of integers from 0 to 7. The environment provides the current horizontal and vertical coordinates of an intruder via the variables `intruderX` and `intruderY`. The system controls the horizontal and vertical coordinates for Robot 0 using `robotX0` and `robotY0`, and for Robot 1 using `robotX1` and `robotY1`.

The specification defines assumptions regarding the spatial relationship between the intruder and the robots. It is assumed that the intruder never occupies the same position as Robot 0. Similarly, it is assumed that the intruder never occupies the same position as Robot 1. These conditions must hold at all times during the operation of the system.
