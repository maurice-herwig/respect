

Specification name: CatchingIntruder

Named domains:
- Dim: Int(0..D)

Environment variables:
- intruderX: Dim
- intruderY: Dim

System variables:
- robotX0: Dim
- robotY0: Dim
- robotX1: Dim
- robotY1: Dim

The system operates on a two-dimensional grid where both horizontal and vertical coordinates range from 0 to 7. The environment controls the intruder's position via the variables `intruderX` and `intruderY`. The system controls the positions of two robots, Robot 0 and Robot 1, via the variables `robotX0`, `robotY0`, `robotX1`, and `robotY1`.

The specification imposes the following assumptions on the environment and the interaction between the environment and the system:

**Safety Assumptions**
1.  **Collision Avoidance:** The intruder must never occupy the same cell as Robot 0. Similarly, the intruder must never occupy the same cell as Robot 1.
2.  **Static Obstacles:** Certain cells on the grid are permanently occupied and considered unclear. These obstacles are located at coordinates (2, 1), (3, 1), (4, 1), and (5, 1). A cell is considered clear only if it does not contain Robot 0, does not contain Robot 1, and is not one of these static obstacle locations.

**Mobility Assumption**
At every moment, the intruder must have at least one valid move available. A valid move consists of transitioning to an adjacent cell (up, down, left, or right) that remains within the grid bounds (0 to 7) and is clear. This assumption requires that the combined positions of the robots and the intruder never result in the intruder being completely surrounded by robots, static obstacles, or grid boundaries.
