

Specification name: CatchingIntruder

Named domains:
- Dim: Int(0..D)

Environment variables:
- intruderX: Dim
- intruderY: Dim

System variables:
- robotX0: Dim
- robotY0: Dim
- robotX1: Dim
- robotY1: Dim

The system models the interaction between an intruder and two robots operating on a two-dimensional grid. The grid coordinates for both the intruder and the robots range from 0 to 7 in both the X and Y dimensions.

The environment controls the intruder's position, while the system controls the positions of Robot 0 and Robot 1. The following assumptions restrict the behavior of the environment regarding the intruder's movement and position relative to the system and static obstacles:

1.  **Collision Avoidance:** The intruder never occupies the same grid cell as Robot 0 or Robot 1 at any time.
2.  **Static Obstacles:** The grid cells at coordinates (2,1), (3,1), (4,1), and (5,1) are designated as forbidden zones.
3.  **Movement Availability:** It is assumed that the intruder is never trapped. At every moment, there exists at least one adjacent cell (directly above, below, to the left, or to the right) that is valid for movement. A cell is considered valid if it is within the grid boundaries (0 to 7) and is clear. A clear cell is defined as one that is not occupied by Robot 0, not occupied by Robot 1, and is not one of the forbidden static obstacle coordinates.
