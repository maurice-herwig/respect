**Requirements Description: Catching Intruder System**

This system models an interaction between a hostile environment and a pair of robotic agents tasked with tracking an intruder within a 7×7 discrete grid (where coordinates range from 0 to 6).

The environment controls the position of the intruder, represented by the coordinates *(intruderX, intruderY)*. The system controls the positions of two robots, defined by *(robotX0, robotY0)* for the first robot and *(robotX1, robotY1)* for the second.

**Assumptions on the Environment:**
The environment must ensure that the intruder never occupies the same position as either robot. Specifically, the intruder’s position must *never* coincide with *(robotX0, robotY0)* or *(robotX1, robotY1)* at any point in time.

No further constraints are imposed on how the environment moves the intruder.

The system’s guarantees (if any) are not specified in this excerpt. The description is limited to the stated environment assumptions and variable declarations.
