

Specification name: CatchingIntruder

Named domains:
- Dim: Int(0..D)
- four: Int(0..4)

Environment variables:
- intruderX: Dim
- intruderY: Dim
- dontMove: four

System variables:
- robotX0: Dim
- robotY0: Dim
- robotX1: Dim
- robotY1: Dim

The system controls the X and Y coordinates for two robots, designated robot 0 and robot 1. The environment controls the X and Y coordinates of an intruder and a variable named dontMove. All coordinate variables are integers between 0 and 7, while the dontMove variable is an integer between 0 and 4.

The environment is assumed to adhere to the following constraints:
- Initially, the intruder's Y coordinate is 7.
- Initially, the dontMove variable is 0.
- At all times, the intruder is never located at any of the following coordinates: (2, 1), (3, 1), (4, 1), or (5, 1).
