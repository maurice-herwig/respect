

Specification name: CatchingIntruder

Named domains:
- Dim: Int(0..D)

Environment variables:
- intruderX: Dim
- intruderY: Dim

System variables:
- robotX0: Dim
- robotY0: Dim
- robotX1: Dim
- robotY1: Dim

The CatchingIntruder specification describes a reactive system where the system controls the positions of two robots within a grid, while the environment controls the position of an intruder. All position coordinates are defined over the domain Dim, which consists of integers from 0 to 7.

The environment provides the intruder's horizontal and vertical coordinates through the inputs intruderX and intruderY. The system controls the horizontal and vertical coordinates for the first robot (robotX0, robotY0) and the second robot (robotX1, robotY1).

The specification includes an assumption regarding the initial state of the environment: at the start of execution, the intruder's vertical coordinate (intruderY) must be equal to 7.
