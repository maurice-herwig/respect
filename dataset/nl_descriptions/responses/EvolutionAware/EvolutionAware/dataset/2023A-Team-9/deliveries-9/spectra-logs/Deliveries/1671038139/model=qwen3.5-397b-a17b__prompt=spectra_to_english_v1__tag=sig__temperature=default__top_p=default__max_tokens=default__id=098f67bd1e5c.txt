

Specification name: Deliveries

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)
- Coord: Int(0..DY)

Environment variables:
- lamp0X: DimX
- lamp0Y: DimY
- lamp1X: DimX
- lamp1Y: DimY
- elevator: DimY

System variables:
- robotX0: DimX
- robotY0: DimY
- robotX1: DimX
- robotY1: DimY

**Requirements Description**

This specification defines a reactive system for delivery operations within a grid space where both X and Y coordinates range from 0 to 5. The system interacts with an environment that provides sensor data regarding lamp positions and an elevator position. The system controls the positions of two robots.

**Environment Assumptions**
The environment is assumed to adhere to the following constraints regarding the elevator variable:
1.  **Movement Safety:** At every step of the operation, the elevator position must change by at most one unit. Specifically, the next value of the elevator must be either the current value, the current value plus one, or the current value minus one.
2.  **Liveness Requirements:** Throughout the ongoing operation, the elevator must visit position 0 infinitely often. Additionally, the elevator must visit position 5 infinitely often.

**System Behavior**
The system controls the X and Y coordinates for two robots (robot0 and robot1). The specific movement logic, initial positions, and goals for the robots are not constrained by this specification segment; however, the system must maintain valid coordinate values within the defined domains (0 to 5) for all robot position variables.
