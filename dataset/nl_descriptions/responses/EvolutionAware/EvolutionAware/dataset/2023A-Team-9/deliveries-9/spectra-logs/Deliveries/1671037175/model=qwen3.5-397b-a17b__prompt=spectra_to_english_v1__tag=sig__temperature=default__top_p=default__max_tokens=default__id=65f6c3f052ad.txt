

Specification name: Deliveries

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)
- Coord: Int(0..DY)

Environment variables:
- none

System variables:
- robotX0: DimX
- robotY0: DimY
- robotX1: DimX
- robotY1: DimY

The Deliveries specification defines a system responsible for managing the positions of two robots. The system controls four output variables that represent the coordinates of these robots. The variables `robotX0` and `robotY0` denote the X and Y coordinates for the first robot, while `robotX1` and `robotY1` denote the X and Y coordinates for the second robot. All coordinate values are integers constrained within the range of 0 to 5 inclusive, as defined by the system dimensions.
