

Specification name: Deliveries

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)
- Coord: Int(0..DY)

Environment variables:
- lamp0X: DimX
- lamp0Y: DimY
- lamp1X: DimX
- lamp1Y: DimY
- elevator: DimY

System variables:
- robotX0: DimX
- robotY0: DimY
- robotX1: DimX
- robotY1: DimY

**Requirements Description**

The system manages the movement of two robots within a grid where coordinates range from 0 to 5 on both axes. The system interacts with an environment that controls an elevator and various lamp positions.

**Environment Assumptions**
The environment controls the `elevator` variable. The elevator position is constrained such that between any two consecutive states, the value changes by at most one unit; it may remain stationary, increase by one, or decrease by one. Additionally, the elevator must visit position 0 infinitely often and must visit position 5 infinitely often.

**System Guarantees**
The system controls the `robotX0`, `robotY0`, `robotX1`, and `robotY1` variables. The system must satisfy the following requirements:
1.  **Robot 0 Horizontal Movement:** Robot 0's X coordinate (`robotX0`) must change by at most one unit between consecutive states.
2.  **Robot 1 Horizontal Movement:** Robot 1's X coordinate (`robotX1`) must change by at most one unit between consecutive states.
3.  **Robot 0 Vertical Synchronization:** Whenever Robot 0's X coordinate is 0, its Y coordinate in the next state must equal the current position of the elevator.
