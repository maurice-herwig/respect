

Specification name: Deliveries

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)
- Coord: Int(0..DY)

Environment variables:
- lamp0X: DimX
- lamp0Y: DimY
- lamp1X: DimX
- lamp1Y: DimY
- elevator: DimY

System variables:
- robotX0: DimX
- robotY0: DimY
- robotX1: DimX
- robotY1: DimY

The Deliveries specification describes a reactive system operating within a grid where spatial dimensions range from 0 to 5. The system controls the positions of two robots, while the environment controls the positions of two lamps and an elevator.

**Environment Assumptions**
The environment is assumed to manage the elevator according to the following constraints:
1.  **Movement Safety:** The elevator position changes by at most one unit at each step. The value may increase by one, decrease by one, or remain unchanged.
2.  **Liveness:** The elevator must reach position 0 infinitely often.
3.  **Liveness:** The elevator must reach position 5 (the maximum dimension value) infinitely often.

The environment also provides the coordinates for lamp0 and lamp1, though no specific behavioral constraints are imposed on these variables in this specification.

**System Guarantees**
The system must control the robots to satisfy the following safety requirements:
1.  **Robot 0 Movement:** Both the X and Y coordinates of Robot 0 must change by at most one unit at each step. At any step, each coordinate may increase by one, decrease by one, or remain unchanged.
2.  **Robot 1 Movement:** Both the X and Y coordinates of Robot 1 must change by at most one unit at each step. At any step, each coordinate may increase by one, decrease by one, or remain unchanged.
