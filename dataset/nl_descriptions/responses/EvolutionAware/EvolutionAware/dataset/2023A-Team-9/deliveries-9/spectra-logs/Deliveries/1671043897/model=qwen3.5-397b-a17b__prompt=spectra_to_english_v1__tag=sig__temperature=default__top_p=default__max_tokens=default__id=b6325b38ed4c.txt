

Specification name: Deliveries

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)
- Coord: Int(0..DY)

Environment variables:
- lamp0X: DimX
- lamp0Y: DimY
- lamp1X: DimX
- lamp1Y: DimY
- elevator: DimY

System variables:
- robotX0: DimX
- robotY0: DimY
- robotX1: DimX
- robotY1: DimY

**Requirements Description**

This specification defines the behavior of a delivery system involving two robots and an elevator operating within a grid bounded by dimensions DX and DY (both defined as 5). The environment controls the positions of two lamps and the vertical position of the elevator. The system controls the horizontal and vertical coordinates of two robots.

**Environment Assumptions**
The environment must adhere to the following constraints regarding the elevator:
1.  **Movement Step Size:** The elevator's position must change by at most one unit per step. Specifically, in any transition, the next position must be equal to the current position, one unit greater, or one unit less.
2.  **Liveness:** The elevator must visit position 0 infinitely often and must visit position DY infinitely often.

**System Guarantees**
The system must satisfy the following requirements regarding the robots:
1.  **Robot 0 Horizontal Movement:** Robot 0's X-coordinate (`robotX0`) must change by at most one unit per step. The next value must be equal to the current value, one unit greater, or one unit less.
2.  **Robot 1 Horizontal Movement:** Robot 1's X-coordinate (`robotX1`) must change by at most one unit per step. The next value must be equal to the current value, one unit greater, or one unit less.
3.  **Robot 0 Vertical Synchronization:** Whenever Robot 0's X-coordinate is 0, Robot 0's Y-coordinate in the next state must exactly match the elevator's position in the next state.
