The system consists of two robots, each with coordinates (X, Y) in a 7x7 grid. The environment does not control any inputs in this specification. The system-controlled outputs are the positions of the two robots, represented by (robotX0, robotY0) and (robotX1, robotY1).

Initially, robot 0 is at position (0, 0) and robot 1 is at position (7, 0). At all times, the two robots must not be at the same position.

Each robot can move either horizontally or vertically by one unit, or it can stay at its current position. This movement is restricted such that a robot can only move in one direction (either X or Y) at a time, while keeping the other direction constant, or it can stay at its current position without moving.

A counter, reachedBottomLeftCorner, is used to track whether robot 0 has reached the bottom left corner of the grid (position (0, 7)). If robot 0 has not reached this position, then robot 1 must stay at its current position whenever the counter is 0.

Additionally, there are specific positions that the robots must avoid: (2, 1), (3, 1), (4, 1), and (5, 1). Neither robot 0 nor robot 1 can be at any of these positions at any time.
