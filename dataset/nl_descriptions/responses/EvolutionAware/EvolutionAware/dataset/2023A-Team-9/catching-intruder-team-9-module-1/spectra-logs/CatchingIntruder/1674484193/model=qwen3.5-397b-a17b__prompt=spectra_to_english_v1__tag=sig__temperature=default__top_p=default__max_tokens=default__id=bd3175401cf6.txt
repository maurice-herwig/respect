

Specification name: CatchingIntruder

Named domains:
- Dim: Int(0..D)

Environment variables:
- none

System variables:
- robotX0: Dim
- robotY0: Dim
- robotX1: Dim
- robotY1: Dim

The system controls the positions of two robots, Robot 0 and Robot 1, on a two-dimensional grid. The coordinates for both robots are defined by the domain `Dim`, which consists of integers from 0 to 7. All position variables are system-controlled outputs.

Initially, Robot 0 is positioned at X coordinate 0 and Y coordinate 0. Robot 1 is positioned at X coordinate 7 and Y coordinate 0.

At every step of the system operation, the movement of each robot is constrained to ensure safe transitions between grid positions. For Robot 0, the system must ensure that either the X coordinate changes by no more than 1 (increasing by 1, decreasing by 1, or remaining unchanged) while the Y coordinate remains unchanged, or the Y coordinate changes by no more than 1 while the X coordinate remains unchanged, or both coordinates remain unchanged. The same movement constraints apply to Robot 1. These rules prevent either robot from moving diagonally or changing any single coordinate by more than 1 unit in a single step.
