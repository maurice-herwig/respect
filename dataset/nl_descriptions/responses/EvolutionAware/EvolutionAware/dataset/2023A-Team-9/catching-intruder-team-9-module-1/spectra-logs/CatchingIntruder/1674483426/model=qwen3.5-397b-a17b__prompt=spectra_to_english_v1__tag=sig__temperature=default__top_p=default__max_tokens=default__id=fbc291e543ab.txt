

Specification name: CatchingIntruder

Named domains:
- Dim: Int(0..D)

Environment variables:
- none

System variables:
- robotX0: Dim
- robotY0: Dim
- robotX1: Dim
- robotY1: Dim

The system controls the grid coordinates of two robots. The variables robotX0 and robotY0 represent the horizontal and vertical positions of Robot 0, while robotX1 and robotY1 represent the positions of Robot 1. All position coordinates are integers within the range 0 to 7.

Upon initialization, Robot 0 must be positioned at coordinates (0, 0). Robot 1 must be positioned at coordinates (7, 0).
