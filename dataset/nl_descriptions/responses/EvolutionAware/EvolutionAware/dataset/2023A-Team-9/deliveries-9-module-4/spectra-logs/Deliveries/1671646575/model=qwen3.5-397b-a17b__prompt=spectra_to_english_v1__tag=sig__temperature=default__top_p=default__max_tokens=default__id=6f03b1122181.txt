

Specification name: Deliveries

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)
- Coord: Int(0..DY)

Environment variables:
- lamp0X: DimX
- lamp0Y: DimY
- lamp1X: DimX
- lamp1Y: DimY

System variables:
- robotX0: DimX
- robotY0: DimY
- robotX1: DimX
- robotY1: DimY

The system controls the positions of two robots within a grid, while the environment controls the positions of two lamps. The grid dimensions are defined by constants DX and DY.

An internal counter, `package1Cnt`, maintains a value between 0 and 2. This counter is initialized to 0. It increments whenever Robot 0's position (`robotX0`, `robotY0`) matches Lamp 0's position (`lamp0X`, `lamp0Y`).

The system operates under the assumption that whenever the counter `package1Cnt` reaches the value 2, Robot 0 is located at the coordinates (DX, DY).
