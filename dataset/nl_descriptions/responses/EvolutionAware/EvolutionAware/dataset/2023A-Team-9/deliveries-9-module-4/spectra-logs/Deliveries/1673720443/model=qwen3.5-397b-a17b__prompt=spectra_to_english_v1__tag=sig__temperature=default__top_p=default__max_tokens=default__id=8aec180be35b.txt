

Specification name: Deliveries

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)
- Coord: Int(0..DY)

Environment variables:
- elevator: DimY

System variables:
- robotX0: DimX
- robotY0: DimY
- robotX1: DimX
- robotY1: DimY
- elevatorAndGround0: boolean
- elevatorAndGround1: boolean

The system controls the horizontal and vertical positions of two robots along with two boolean status flags, while the environment controls the vertical position of an elevator.

Initially, both boolean status flags, `elevatorAndGround0` and `elevatorAndGround1`, are set to false.

During operation, the system must satisfy the following conditions regarding the vertical positions of the robots:
1. If Robot 0's vertical position in the next state is 5 and its current vertical position is strictly less than 5, then the system must set `elevatorAndGround0` to true in the next state.
2. If Robot 1's vertical position in the next state is 5 and its current vertical position is strictly less than 5, then the system must set `elevatorAndGround1` to true in the next state.

These conditions must hold at all times throughout the system's execution.
