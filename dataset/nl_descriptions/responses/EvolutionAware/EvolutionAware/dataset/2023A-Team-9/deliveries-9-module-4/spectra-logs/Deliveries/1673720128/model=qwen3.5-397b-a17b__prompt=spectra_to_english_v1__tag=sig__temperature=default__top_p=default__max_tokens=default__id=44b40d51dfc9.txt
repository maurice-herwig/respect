

Specification name: Deliveries

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)
- Coord: Int(0..DY)

Environment variables:
- none

System variables:
- robotX0: DimX
- robotY0: DimY
- robotX1: DimX
- robotY1: DimY
- elevatorAndGround0: boolean
- elevatorAndGround1: boolean

The system controls the coordinates and status indicators for two robots. The variables `robotX0`, `robotY0`, `robotX1`, and `robotY1` represent the horizontal and vertical positions of robot 0 and robot 1, respectively, within their defined integer ranges. The boolean variables `elevatorAndGround0` and `elevatorAndGround1` represent status flags associated with each robot.

Initially, both status flags `elevatorAndGround0` and `elevatorAndGround1` are false.

The system must maintain the following behavioral guarantees regarding vertical movement and status flags:
1. Whenever the vertical position `robotY0` transitions to the value 5 from a previous value strictly less than 5, the status flag `elevatorAndGround0` must be true in the resulting state.
2. Whenever the vertical position `robotY1` transitions to the value 5 from a previous value strictly less than 5, the status flag `elevatorAndGround1` must be true in the resulting state.
