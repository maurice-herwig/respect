

Specification name: Deliveries

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)
- Coord: Int(0..DY)

Environment variables:
- none

System variables:
- robotX0: DimX
- robotY0: DimY
- robotX1: DimX
- robotY1: DimY
- elevatorAndGround0: boolean
- elevatorAndGround1: boolean

The Deliveries system operates autonomously without environment inputs, controlling all state variables directly. The system manages the coordinates of two robots. The horizontal positions, `robotX0` and `robotX1`, are integers ranging from 0 to 5. The vertical positions, `robotY0` and `robotY1`, are integers ranging from 0 to 5. Additionally, the system controls two boolean status flags, `elevatorAndGround0` and `elevatorAndGround1`. At the start of operation, the system must initialize both `elevatorAndGround0` and `elevatorAndGround1` to false.
