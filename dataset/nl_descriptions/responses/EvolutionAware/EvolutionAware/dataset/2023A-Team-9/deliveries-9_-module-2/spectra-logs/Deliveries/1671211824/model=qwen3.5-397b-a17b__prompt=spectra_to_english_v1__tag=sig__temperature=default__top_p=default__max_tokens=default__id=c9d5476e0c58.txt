

Specification name: Deliveries

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)
- Coord: Int(0..DY)

Environment variables:
- lamp0X: DimX
- lamp0Y: DimY
- lamp1X: DimX
- lamp1Y: DimY

System variables:
- robotX0: DimX
- robotY0: DimY
- robotX1: DimX
- robotY1: DimY

The system operates within a two-dimensional grid where the X and Y coordinates range from 0 to 5. The system controls the positions of two robots, designated as Robot 0 and Robot 1. The environment controls the positions of two lamps, designated as Lamp 0 and Lamp 1.

The environment must satisfy the following assumptions regarding lamp movement:

1.  **Lamp 0 Stationarity:** Whenever Robot 0 is not at the same location as Lamp 0, Lamp 0 must not move. Specifically, if the coordinates (`robotX0`, `robotY0`) do not match the coordinates (`lamp0X`, `lamp0Y`), then the values of `lamp0X` and `lamp0Y` in the next state must remain equal to their current values.
2.  **Lamp 1 Stationarity:** Whenever Robot 1 is not at the same location as Lamp 1, Lamp 1 must not move. Specifically, if the coordinates (`robotX1`, `robotY1`) do not match the coordinates (`lamp1X`, `lamp1Y`), then the values of `lamp1X` and `lamp1Y` in the next state must remain equal to their current values.

These constraints ensure that each lamp remains stationary until its corresponding robot reaches its location.
