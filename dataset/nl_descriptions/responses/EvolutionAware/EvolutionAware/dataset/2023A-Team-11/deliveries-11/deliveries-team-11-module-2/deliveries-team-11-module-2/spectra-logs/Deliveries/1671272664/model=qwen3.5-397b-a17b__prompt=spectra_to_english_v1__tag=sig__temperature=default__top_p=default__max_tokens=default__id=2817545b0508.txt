

Specification name: Deliveries

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)
- Coord: Int(0..DY)

Environment variables:
- p0X: DimX
- p0Y: DimY
- p1X: DimX
- p1Y: DimY

System variables:
- robotX0: DimX
- robotY0: DimY
- robotX1: DimX
- robotY1: DimY

This specification describes a delivery system operating on a 5x5 grid, where DX and DY are both defined as 5. The system controls the horizontal and vertical coordinates of two robots, Robot 0 (`robotX0`, `robotY0`) and Robot 1 (`robotX1`, `robotY1`). The environment controls the horizontal and vertical coordinates of two corresponding packages, Package 0 (`p0X`, `p0Y`) and Package 1 (`p1X`, `p1Y`). All coordinates are integers ranging from 0 to 5.

Robot 0 is considered to be at Package 0 when `robotX0` equals `p0X` and `robotY0` equals `p0Y`. Similarly, Robot 1 is considered to be at Package 1 when `robotX1` equals `p1X` and `robotY1` equals `p1Y`.

The environment must adhere to the following assumptions regarding package behavior:
1. The Y-coordinates of both packages (`p0Y` and `p1Y`) are never 0.
2. If Robot 0 is not at Package 0, the position of Package 0 remains stationary; both `p0X` and `p0Y` must remain unchanged in the next step.
3. If Robot 1 is not at Package 1, the position of Package 1 remains stationary; both `p1X` and `p1Y` must remain unchanged in the next step.
4. If Robot 0 is at Package 0, the Y-coordinate of Package 0 (`p0Y`) must change in the next step.
5. If Robot 1 is at Package 1, the Y-coordinate of Package 1 (`p1Y`) must change in the next step.
