

Specification name: Deliveries

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)
- Coord: Int(0..DY)

Environment variables:
- p0X: DimX
- p0Y: DimY
- p1X: DimX
- p1Y: DimY

System variables:
- robotX0: DimX
- robotY0: DimY
- robotX1: DimX
- robotY1: DimY

The system controls two robots, Robot 0 and Robot 1, operating within a grid defined by the dimensions DimX and DimY. The environment provides the target coordinates for two packages, Package 0 and Package 1. The system must manage the robots to interact with these packages according to the following requirements.

**Environment Assumptions**
The environment behaves according to these constraints:
1.  The Y-coordinates of both Package 0 (`p0Y`) and Package 1 (`p1Y`) are never 0.
2.  If Robot 0 is not at the same location as Package 0 (where `robotX0` equals `p0X` and `robotY0` equals `p0Y`), the coordinates of Package 0 (`p0X` and `p0Y`) remain unchanged in the next step.
3.  If Robot 1 is not at the same location as Package 1 (where `robotX1` equals `p1X` and `robotY1` equals `p1Y`), the coordinates of Package 1 (`p1X` and `p1Y`) remain unchanged in the next step.
4.  If Robot 0 reaches the same location as Package 0, the Y-coordinate of Package 0 (`p0Y`) must change in the next step.
5.  If Robot 1 reaches the same location as Package 1, the Y-coordinate of Package 1 (`p1Y`) must change in the next step.

**System Guarantees**
The system must ensure the following behaviors:
1.  Robot 0 must reach the location of Package 0 infinitely often.
2.  Robot 1 must reach the location of Package 1 infinitely often.
