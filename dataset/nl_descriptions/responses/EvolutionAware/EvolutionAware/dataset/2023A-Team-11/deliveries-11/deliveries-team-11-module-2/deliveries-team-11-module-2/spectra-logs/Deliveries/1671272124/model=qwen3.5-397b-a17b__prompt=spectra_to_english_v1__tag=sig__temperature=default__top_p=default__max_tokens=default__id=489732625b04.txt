

Specification name: Deliveries

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)
- Coord: Int(0..DY)

Environment variables:
- p0X: DimX
- p0Y: DimY
- p1X: DimX
- p1Y: DimY

System variables:
- robotX0: DimX
- robotY0: DimY
- robotX1: DimX
- robotY1: DimY

The system controls the coordinates of two robots operating on a grid defined by the dimensions DX and DY. The environment provides the coordinates for two packages within the same grid space. 

**Environment Assumptions**
The environment must satisfy the constraint that neither package is ever located at Y-coordinate 0. Specifically, the Y-coordinate for Package 0 (`p0Y`) and the Y-coordinate for Package 1 (`p1Y`) must always be non-zero.

**System State Definitions**
The specification defines logical conditions to determine when a robot is located at the same position as its corresponding package. Robot 0 is considered to be at Package 0 when its X-coordinate (`robotX0`) matches `p0X` and its Y-coordinate (`robotY0`) matches `p0Y`. Similarly, Robot 1 is considered to be at Package 1 when its X-coordinate (`robotX1`) matches `p1X` and its Y-coordinate (`robotY1`) matches `p1Y`.
