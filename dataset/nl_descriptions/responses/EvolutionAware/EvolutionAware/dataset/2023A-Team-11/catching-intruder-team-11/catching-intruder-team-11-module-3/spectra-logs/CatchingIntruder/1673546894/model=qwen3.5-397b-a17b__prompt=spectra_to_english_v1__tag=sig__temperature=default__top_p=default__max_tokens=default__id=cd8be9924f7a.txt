

Specification name: CatchingIntruder

Named domains:
- Dim: Int(0..D)

Environment variables:
- intruderX: Dim
- intruderY: Dim
- StaysCounter: Dim

System variables:
- robotX0: Dim
- robotY0: Dim
- robotX1: Dim
- robotY1: Dim

The CatchingIntruder specification describes a reactive system operating on a grid where all coordinates are integers ranging from 0 to 7. The environment includes four fixed obstacles located at coordinates (2,1), (3,1), (4,1), and (5,1).

The environment controls the position of an intruder via the inputs `intruderX` and `intruderY`, as well as a counter variable `StaysCounter`. The system controls the positions of two robots, Robot 0 (`robotX0`, `robotY0`) and Robot 1 (`robotX1`, `robotY1`).

Regarding environmental assumptions, the variable `StaysCounter` must be initialized to 0. At every subsequent step, the environment must update `StaysCounter` such that it either increments by 1 or resets to 0. The intruder's coordinates are provided by the environment within the valid grid dimensions. The system is responsible for determining the values of the robot coordinates at each step.
