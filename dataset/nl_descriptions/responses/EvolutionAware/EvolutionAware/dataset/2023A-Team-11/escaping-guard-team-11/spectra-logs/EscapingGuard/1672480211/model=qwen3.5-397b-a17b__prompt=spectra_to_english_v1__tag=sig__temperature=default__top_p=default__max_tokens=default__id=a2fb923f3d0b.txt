

Specification name: EscapingGuard

Named domains:
- Dim: Int(0..D)

Environment variables:
- guardLeftCornerX: Dim
- guardLeftCornerY: Dim

System variables:
- robotX: Dim
- robotY: Dim

This specification describes a reactive system where a robot navigates a grid while a guard monitors the environment. The system controls the robot's horizontal and vertical position, while the environment controls the guard's left corner position. All coordinate variables are integers ranging from 0 to 7.

Initially, the robot must start at position (7, 0), and the guard must start at position (0, 0).

The system must ensure that the robot infinitely often visits three specific target locations during operation. These targets are located at coordinates (0, 0), (0, 7), and (7, 7). The robot is required to return to each of these three locations infinitely many times throughout the system's execution.
