

Specification name: EscapingGuard

Named domains:
- Dim: Int(0..D)

Environment variables:
- guardLeftCornerX: Dim
- guardLeftCornerY: Dim

System variables:
- robotX: Dim
- robotY: Dim

The system operates on a two-dimensional grid where coordinates range from 0 to 7. The system controls the robot's position, while the environment controls the guard's position.

**Initial Conditions**
At the start of operation, the robot is positioned at coordinates (7, 0). The environment initializes the guard at the left corner coordinates (0, 0).

**Static Configuration**
The specification defines fixed obstacle locations at coordinates (2, 2), (2, 3), (2, 4), and (2, 5). Three target locations are defined at coordinates (0, 0), (0, 7), and (7, 7).

**Movement Definitions**
The specification defines a valid movement step for any coordinate position as a transition where the next value is either one greater than, equal to, or one less than the current value. This defines the allowable changes for positions along any dimension.
