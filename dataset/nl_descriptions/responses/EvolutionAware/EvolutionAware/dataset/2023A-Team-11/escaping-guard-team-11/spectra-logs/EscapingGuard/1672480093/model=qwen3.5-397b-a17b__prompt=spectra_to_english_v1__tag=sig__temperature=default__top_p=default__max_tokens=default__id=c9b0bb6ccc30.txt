

Specification name: EscapingGuard

Named domains:
- Dim: Int(0..D)

Environment variables:
- guardLeftCornerX: Dim
- guardLeftCornerY: Dim

System variables:
- robotX: Dim
- robotY: Dim

**Requirements Description**

This specification describes a reactive system where the system controls a robot's position and the environment controls a guard's position. All position coordinates are integers ranging from 0 to 7.

**Initial Conditions**
At the start of operation, the system must initialize the robot at coordinates (7, 0). The environment initializes the guard at coordinates (0, 0).

**System Guarantees**
The system must ensure that the robot visits three specific target locations infinitely often during operation. These target locations are fixed at coordinates (0, 0), (0, 7), and (7, 7). The system is required to revisit each of these targets repeatedly without bound throughout the execution of the system.
