

Specification name: EscapingGuard

Named domains:
- Dim: Int(0..D)

Environment variables:
- guardLeftCornerX: Dim
- guardLeftCornerY: Dim

System variables:
- robotX: Dim
- robotY: Dim

This specification defines the behavior of a robot operating in a two-dimensional grid environment alongside a guard. The coordinate space for all positions is defined by the domain `Dim`, representing integers from 0 to 7 (where D=7).

The system controls the robot's position through the output variables `robotX` and `robotY`. The environment controls the guard's position through the input variables `guardLeftCornerX` and `guardLeftCornerY`.

**Initial Conditions**
At the beginning of operation, the robot must be initialized at coordinates (7, 0). The environment is assumed to initialize the guard at coordinates (0, 0).

**System Guarantees**
The system must satisfy the following liveness requirements regarding the robot's position:
1. The robot must visit Target 1, located at coordinates (0, 0), infinitely often.
2. The robot must visit Target 2, located at coordinates (0, 7), infinitely often.
