

Specification name: EscapingGuard

Named domains:
- Dim: Int(0..D)

Environment variables:
- guardLeftCornerX: Dim
- guardLeftCornerY: Dim

System variables:
- robotX: Dim
- robotY: Dim

The system controls a robot's position on a two-dimensional grid, while the environment controls a guard's position. Both the robot and guard coordinates are integers ranging from 0 to 7.

Initially, the robot must be positioned at coordinates (7, 0). The environment is assumed to initialize the guard at coordinates (0, 0).

The system must guarantee that the robot infinitely often visits Target 1, which is located at coordinates (0, 0).
