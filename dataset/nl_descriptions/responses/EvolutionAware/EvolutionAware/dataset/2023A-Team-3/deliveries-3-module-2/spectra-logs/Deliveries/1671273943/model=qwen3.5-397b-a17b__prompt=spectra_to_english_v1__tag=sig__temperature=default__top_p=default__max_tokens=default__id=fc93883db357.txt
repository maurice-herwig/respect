

Specification name: Deliveries

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)
- Coord: Int(0..DY)

Environment variables:
- lamp0X: DimX
- lamp0Y: DimY
- lamp1X: DimX
- lamp1Y: DimY

System variables:
- robotX0: DimX
- robotY0: DimY
- robotX1: DimX
- robotY1: DimY

**Requirements Description**

The Deliveries specification defines a reactive system that manages the positions of two robots within a two-dimensional grid. The system controls the X and Y coordinates for Robot 0 and Robot 1. The environment provides the X and Y coordinates for Lamp 0 and Lamp 1. All coordinates are integers ranging from 0 to 5, based on the defined dimensions DX and DY.

**Environmental Assumptions**
The environment must satisfy the following safety constraints regarding lamp positions:
*   Lamp 0 must never be located at Y-coordinate 0.
*   Lamp 1 must never be located at Y-coordinate 0.
These conditions must hold at all times during system operation.

**System Guarantees**
The system is responsible for determining the coordinates for Robot 0 and Robot 1 within the defined grid dimensions.
