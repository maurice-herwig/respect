

Specification name: Deliveries

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)
- Coord: Int(0..DY)

Environment variables:
- none

System variables:
- robotX0: DimX
- robotY0: DimY
- robotX1: DimX
- robotY1: DimY
- lamp0X: DimX
- lamp0Y: DimY
- lamp1X: DimX
- lamp1Y: DimY

The system manages the positions of two robots and two lamps on a two-dimensional grid. All position variables for the robots and lamps are controlled by the system. The X and Y coordinates for all entities are integers defined within the specified dimensions.

The specification includes assumptions constraining the lamp positions. It is assumed that the Y-coordinate for Lamp 0 is never 0, and the Y-coordinate for Lamp 1 is never 0. This constraint reflects the requirement that rooms on the ground floor, represented by a Y-coordinate of 0, do not request packages.
