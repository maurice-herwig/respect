

Specification name: Deliveries

Named domains:

Environment variables:
- elevatorY: DimY

- lamp1Y: DimY

System variables:
- robotX0: DimX
- robotY0: DimY
- robotX1: DimX
- robotY1: DimY

**Requirements Description**

The system controls the movement of two robots within a grid environment. The environment provides the vertical position of an elevator and the coordinates of two lamps. The system is responsible for determining the horizontal and vertical coordinates of both robots at each step.

Initially, both robots start at vertical coordinate 0. Their initial horizontal coordinates are unspecified.

The system must satisfy the following safety requirements during operation:
1.  **Collision Avoidance:** The two robots must never occupy the same grid location simultaneously.
2.  **Horizontal Movement:** The horizontal coordinate of each robot may change by at most one unit per step. Specifically, the next horizontal position must be equal to the current position, one unit greater, or one unit less.
3.  **Elevator Interaction:** If the elevator's vertical position in the next step differs from a robot's current vertical position, that robot's horizontal position in the next step must be 0. This constraint applies independently to both robots.
