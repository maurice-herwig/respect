

Specification name: Deliveries

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)
- Coord: Int(0..DY)

Environment variables:
- elevatorY: DimY

System variables:
- robotX0: DimX
- robotY0: DimY
- robotX1: DimX
- robotY1: DimY

The system controls two robots, Robot 0 and Robot 1, operating within a grid where horizontal coordinates (DimX) and vertical coordinates (DimY) range from 0 to 5. The environment controls the vertical position of an elevator, which is fixed at horizontal position 0.

Initially, both Robot 0 and Robot 1 start at vertical position 0.

The system must satisfy the following safety requirements at all times:
1.  **Collision Avoidance:** Robot 0 and Robot 1 must never occupy the same position simultaneously; their horizontal and vertical coordinates cannot be equal at the same time.
2.  **Horizontal Movement:** In each step, the horizontal position of both Robot 0 and Robot 1 may change by at most one unit (increase by 1, decrease by 1, or remain unchanged).
3.  **Elevator Interaction:** If the elevator's vertical position in the next state differs from Robot 0's current vertical position, then Robot 0 must move to horizontal position 0 in the next state.
