

Specification name: Deliveries

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)
- Coord: Int(0..DY)

Environment variables:
- elevatorY: DimY

System variables:
- robotX0: DimX
- robotY0: DimY
- robotX1: DimX
- robotY1: DimY

**Requirements Description**

The **Deliveries** system manages the coordinates of two robots within a grid environment while interacting with an environment-controlled elevator. The environment determines the vertical position of the elevator, while the system controls the horizontal and vertical positions of both Robot 0 and Robot 1.

**Initial Conditions**
At the start of operation, both Robot 0 and Robot 1 must be initialized at vertical position 0.

**Safety Requirements**
1.  **Collision Avoidance:** Robot 0 and Robot 1 must never occupy the same location simultaneously. It is strictly forbidden for both robots to share the same horizontal coordinate and the same vertical coordinate at any time.
2.  **Horizontal Movement Constraints:** In every transition, the horizontal position of Robot 0 (`robotX0`) and the horizontal position of Robot 1 (`robotX1`) must change by at most one unit. Each robot may remain in its current horizontal position, increase its horizontal coordinate by one, or decrease its horizontal coordinate by one, subject to grid boundaries.

**System Behavior and Interaction**
The system must enforce the following interaction rules between Robot 0 and the elevator:
1.  If the elevator's next vertical position differs from Robot 0's current vertical position, then Robot 0 must move to horizontal position 0 in the next step.
2.  If Robot 0 is currently at horizontal position 0, then Robot 0's next vertical position must match the elevator's next vertical position.
