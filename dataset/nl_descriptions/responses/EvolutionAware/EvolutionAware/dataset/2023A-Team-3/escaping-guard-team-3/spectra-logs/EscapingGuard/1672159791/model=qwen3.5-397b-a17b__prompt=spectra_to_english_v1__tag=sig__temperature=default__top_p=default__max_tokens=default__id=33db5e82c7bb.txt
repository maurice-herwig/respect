

Specification name: EscapingGuard

Named domains:
- Dim: Int(0..D)
- DimM: Int(0..DM)

Environment variables:
- mx: DimM
- my: DimM

System variables:
- robotX: Dim
- robotY: Dim

**Requirements Description**

The system controls the position of a robot on a grid using the output variables `robotX` and `robotY`. The environment provides input variables `mx` and `my`. The robot's coordinates are integers ranging from 0 to 7, while the environment inputs are integers ranging from 0 to 6.

At the start of operation, the robot must be initialized at position (7, 0). Simultaneously, the environment inputs `mx` and `my` must be initialized to 0.

During operation, the system must ensure that the robot visits three specific target locations infinitely often:
1. Position (0, 0).
2. Position (7, 7).
3. Position (0, 7).
