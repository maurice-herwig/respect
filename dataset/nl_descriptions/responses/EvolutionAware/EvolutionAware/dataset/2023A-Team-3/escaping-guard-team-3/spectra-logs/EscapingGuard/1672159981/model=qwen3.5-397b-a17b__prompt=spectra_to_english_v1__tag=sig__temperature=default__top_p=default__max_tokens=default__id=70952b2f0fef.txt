

Specification name: EscapingGuard

Named domains:
- Dim: Int(0..D)
- DimM: Int(0..DM)

Environment variables:
- mx: DimM
- my: DimM

System variables:
- robotX: Dim
- robotY: Dim

The **EscapingGuard** specification describes a reactive system that controls a robot's position on a grid. The system manages the robot's horizontal and vertical coordinates, `robotX` and `robotY`, which range from 0 to 7. The environment provides input variables `mx` and `my`, which range from 0 to 6.

**Initial Conditions**
At the start of operation, the robot is positioned at coordinates (7, 0). The environment variables `mx` and `my` are initialized to 0.

**System Guarantees**
The system must ensure that the robot visits the following three target locations infinitely often during every execution:
*   Target 1 at coordinates (0, 0).
*   Target 2 at coordinates (7, 7).
*   Target 3 at coordinates (0, 7).

**Assumptions**
The specification relies on the following assumptions regarding state transitions between consecutive steps:
*   It is assumed that the robot's `robotX` and `robotY` coordinates change by at most 1 unit (the value may remain the same, increase by 1, or decrease by 1).
*   It is assumed that the environment variables `mx` and `my` also change by at most 1 unit.
