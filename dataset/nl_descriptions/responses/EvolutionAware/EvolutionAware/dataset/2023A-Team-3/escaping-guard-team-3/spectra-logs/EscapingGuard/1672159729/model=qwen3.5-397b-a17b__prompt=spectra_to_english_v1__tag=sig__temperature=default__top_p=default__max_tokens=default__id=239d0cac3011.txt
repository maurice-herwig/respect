

Specification name: EscapingGuard

Named domains:
- Dim: Int(0..D)
- DimM: Int(0..DM)

Environment variables:
- mx: DimM
- my: DimM

System variables:
- robotX: Dim
- robotY: Dim

The system controls the robot's position using the variables `robotX` and `robotY`, which represent integer coordinates ranging from 0 to 7. The environment controls the guard's position using the variables `mx` and `my`, which represent integer coordinates ranging from 0 to 6.

The specification defines three target locations as constants: T1 at coordinates (0, 0), T2 at (7, 7), and T3 at (0, 7). Additionally, four fixed obstacle locations are defined at coordinates (2, 2), (2, 3), (2, 4), and (2, 5).

Regarding initial conditions, the system guarantees that the robot initializes at position (7, 0). The environment is assumed to initialize the guard at position (0, 0), which corresponds to the location of target T1.
