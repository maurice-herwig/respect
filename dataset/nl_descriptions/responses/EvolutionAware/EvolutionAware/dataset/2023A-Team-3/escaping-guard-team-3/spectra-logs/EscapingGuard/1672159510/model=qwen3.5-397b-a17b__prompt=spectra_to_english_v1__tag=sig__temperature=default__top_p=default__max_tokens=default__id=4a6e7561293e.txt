

Specification name: EscapingGuard

Named domains:
- Dim: Int(0..D)
- DimM: Int(0..DM)

Environment variables:
- mx: DimM
- my: DimM

System variables:
- robotX: Dim
- robotY: Dim

**Requirements Description**

The system controls the position of a robot on a two-dimensional grid. The robot's coordinates, `robotX` and `robotY`, are system-controlled outputs restricted to the domain `Dim`, which represents integers from 0 to 7. The environment provides input variables `mx` and `my`, restricted to the domain `DimM`, which represents integers from 0 to 6.

The specification defines three fixed target locations within the grid:
- Target 1 (T1) at coordinates (0, 0).
- Target 2 (T2) at coordinates (7, 7).
- Target 3 (T3) at coordinates (0, 7).

There are no formal assumptions restricting the behavior of the environment variables. The system must satisfy the following guarantee:

- **Initial Condition:** At the start of execution, the robot must be located at coordinates `robotX = 7` and `robotY = 0`.
