

Specification name: Deliveries

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)
- Coord: Int(0..DY)

Environment variables:
- elevatorY: DimY

System variables:
- robotX0: DimX
- robotY0: DimY
- robotX1: DimX
- robotY1: DimY

The Deliveries specification models a reactive system involving robot coordinates and an elevator environment. The system controls four output variables representing the horizontal and vertical positions of two robots: `robotX0`, `robotY0`, `robotX1`, and `robotY1`. The environment controls one input variable, `elevatorY`, which represents the vertical position of the elevator. The specification defines the elevator's horizontal position as fixed at 0.

The environment is assumed to adhere to specific safety and liveness constraints regarding the `elevatorY` variable. Regarding safety and next-state behavior, the elevator's vertical position must change by at most one unit between consecutive steps. Specifically, in any transition, the value of `elevatorY` must either increase by one, decrease by one, or remain unchanged.

Regarding liveness, the environment must ensure that the elevator visits the bottom position, 0, infinitely often. Additionally, the environment must ensure that the elevator visits the top position, 5, infinitely often. These assumptions define the valid behaviors of the environment under which the system operates.
