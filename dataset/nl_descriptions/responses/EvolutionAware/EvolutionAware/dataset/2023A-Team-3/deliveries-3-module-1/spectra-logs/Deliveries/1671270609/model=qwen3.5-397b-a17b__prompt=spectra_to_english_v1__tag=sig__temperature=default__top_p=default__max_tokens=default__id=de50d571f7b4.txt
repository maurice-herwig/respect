

The Deliveries specification models a reactive system involving two robots and an elevator operating within a bounded grid. The grid dimensions are determined by constants DX and DY, both defined as 5. The system interacts with an environment that manages the elevator's vertical movement.

Specification name: Deliveries

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)
- Coord: Int(0..DY)

Environment variables:
- elevatorY: DimY

System variables:
- robotX0: DimX
- robotY0: DimY
- robotX1: DimX
- robotY1: DimY

The environment controls the elevator's vertical position, `elevatorY`. It is assumed that the elevator moves gradually along the vertical axis; specifically, at each step, the value of `elevatorY` either remains unchanged, increases by one, or decreases by one. The elevator's horizontal position is fixed at 0. The system controls the horizontal and vertical coordinates for two robots, represented by `robotX0`, `robotY0`, `robotX1`, and `robotY1`.
