### **Requirements for the Elevator and Robot Delivery System**

This system describes an environment containing a single elevator and two robots that must coordinate within a bounded grid.

**Environment-Provided Input:**
- The elevator’s vertical position (`elevatorY`) is controlled by the environment and can take integer values from 0 to 5 (inclusive). The elevator is fixed at the horizontal position `elevatorX = 0`.

**Assumptions on the Environment:**
The environment must ensure that the elevator moves in valid increments—it may move up by one position, down by one position, or remain in its current position at each step. The elevator must never make moves that violate this constraint.

**System-Controlled Outputs:**
The system controls the initial positions of two robots:
- `robotX0` and `robotY0` define the starting coordinates of the first robot (horizontal and vertical positions, respectively).
- `robotX1` and `robotY1` define the starting coordinates of the second robot.

Both robots operate within a grid where horizontal positions (`robotX0`, `robotX1`) range from 0 to 5 and vertical positions (`robotY0`, `robotY1`) range from 0 to 5.

**Initial Conditions and Safety Constraints:**
The specification currently defines only the initial state of the robot positions and imposes constraints on the elevator’s movement. No further guarantees on system behavior, liveness properties, or state transitions are specified. The system is expected to define the robots' starting positions but does not yet enforce dynamic behavior, ongoing safety conditions, or progress requirements beyond this.
