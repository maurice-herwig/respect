

Specification name: Module2

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)
- Coord: Int(0..DY)

Environment variables:
- targetX0: DimX
- targetY0: DimY
- targetX1: DimX
- targetY1: DimY

System variables:
- robotX0: DimX
- robotY0: DimY
- robotX1: DimX
- robotY1: DimY

The system controls two robots, robot 0 and robot 1, operating on a grid where X coordinates range from 0 to 5 and Y coordinates range from 0 to 5. The system determines the positions of the robots (`robotX0`, `robotY0`, `robotX1`, `robotY1`), while the environment provides target coordinates for each robot (`targetX0`, `targetY0`, `targetX1`, `targetY1`).

The environment must satisfy the following assumptions:
1.  **Target Bounds:** The target X coordinates for both robots are never 0. The target Y coordinates for both robots are never 5.
2.  **Target Updates:** Whenever robot 0 is at its target location (where `robotX0` equals `targetX0` and `robotY0` equals `targetY0`), the environment must change `targetY0` in the immediately following step. Similarly, whenever robot 1 is at its target location, the environment must change `targetY1` in the immediately following step.

The system must satisfy the following guarantees:
1.  **Liveness:** Both robot 0 and robot 1 must reach their respective target locations infinitely often.
2.  **Package Counters:** The system maintains two counters, `packages0` and `packages1`, each ranging from 0 to 3.
    *   Both counters initialize to 0.
    *   `packages0` increments when robot 0 is at its target. It resets to 0 when `robotY0` equals 5. If the counter reaches 3, it remains at 3 until reset.
    *   `packages1` increments when robot 1 is at its target. It resets to 0 when `robotY1` equals 5. If the counter reaches 3, it remains at 3 until reset.
3.  **Counter Safety:** If `packages0` equals 3, robot 0 must not be at its target. If `packages1` equals 3, robot 1 must not be at its target.
