**Requirements Description for Module3**

This system controls the starting positions of two robots in a two-dimensional grid, while monitoring the position of an external intruder. The grid spans from coordinate `0` to `6` along both the X and Y axes (inclusive).

### Environment and System Variables
- **Environment-controlled inputs:**
  The environment determines the position of an *intruder*, specified by `intruderX` (X-coordinate) and `intruderY` (Y-coordinate).

- **System-controlled outputs:**
  The system sets the initial positions of two robots:
  - Robot 0: `robotX0` (X-coordinate) and `robotY0` (Y-coordinate)
  - Robot 1: `robotX1` (X-coordinate) and `robotY1` (Y-coordinate)

### Assumptions on the Environment
At all times, if the intruder is on the row where `Y = 1`, its X-coordinate must either be less than `2` or greater than `5`. The environment is restricted to only produce intruder positions that satisfy this condition.

### Guarantees Required from the System
The system must ensure that both robots satisfy the following safety requirement:
- Whenever a robot is on the row where `Y = 1`, its X-coordinate must be either less than `2` or greater than `5`.

This applies separately to both Robot 0 (`robotX0`, `robotY0`) and Robot 1 (`robotX1`, `robotY1`). The robots may occupy any other positions in the grid as long as they adhere to this constraint when on the `Y = 1` row.
