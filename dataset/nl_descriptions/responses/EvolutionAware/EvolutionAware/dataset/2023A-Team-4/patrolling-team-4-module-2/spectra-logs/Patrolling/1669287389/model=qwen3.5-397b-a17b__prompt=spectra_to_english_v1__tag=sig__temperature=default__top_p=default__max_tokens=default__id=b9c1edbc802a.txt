

Specification name: Patrolling

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)

Environment variables:
- Obstacle1X: DimX
- Obstacle1Y: DimY
- Obstacle2X: DimX
- Obstacle2Y: DimY
- Obstacle3X: DimX
- Obstacle3Y: DimY
- Obstacle4X: DimX
- Obstacle4Y: DimY
- Obstacle5X: DimX
- Obstacle5Y: DimY

System variables:
- robotX: DimX
- robotY: DimY

**Requirements Description**

The system controls the position of a robot on a two-dimensional grid. The environment provides the locations of five obstacles. The grid coordinates for both axes range from 0 to 4.

**Environment Assumptions**
The environment maintains the positions of the five obstacles as fixed constants throughout the operation of the system. The specific locations are as follows:
- Obstacle 1 is fixed at X=1, Y=1.
- Obstacle 2 is fixed at X=3, Y=3.
- Obstacle 3 is fixed at X=2, Y=1.
- Obstacle 4 is fixed at X=0, Y=3.
- Obstacle 5 is fixed at X=3, Y=4.

**System Guarantees**
The system must satisfy the following requirements at all times:

1.  **Movement Constraints:** In every step, the robot's position must change by at most one unit in each dimension. Specifically, the next value of the robot's X coordinate (`robotX`) must be equal to the current value, the current value plus one, or the current value minus one. The same constraint applies to the robot's Y coordinate (`robotY`).

2.  **Obstacle Avoidance:** The robot must never share a coordinate value with any obstacle. For each of the five obstacles, the robot's X coordinate must not equal the obstacle's X coordinate, and the robot's Y coordinate must not equal the obstacle's Y coordinate. This means the robot cannot be located in the same row or the same column as any obstacle.
