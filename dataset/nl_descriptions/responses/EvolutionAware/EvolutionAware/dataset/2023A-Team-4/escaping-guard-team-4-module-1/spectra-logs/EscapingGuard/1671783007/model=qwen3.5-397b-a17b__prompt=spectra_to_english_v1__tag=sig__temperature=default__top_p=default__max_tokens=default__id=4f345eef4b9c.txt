

Specification name: EscapingGuard

Named domains:
- Dim: Int(0..D)

Environment variables:
- none

System variables:
- robotX: Dim
- robotY: Dim

The system controls the position of a robot on a grid using two variables, `robotX` and `robotY`, which represent the horizontal and vertical coordinates respectively. Both coordinates are integers ranging from 0 to 7.

Initially, the robot must be positioned at coordinates (7, 0).

The system must ensure the robot avoids obstacles at all times. Specifically, if the horizontal coordinate `robotX` is 2, the vertical coordinate `robotY` must not be 2, 3, 4, or 5.

Additionally, the system must satisfy liveness requirements by visiting three specific target locations infinitely often during operation:
1. Target 1 at coordinates (0, 0).
2. Target 2 at coordinates (7, 7).
3. Target 3 at coordinates (0, 7).
