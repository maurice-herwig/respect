

Specification name: EscapingGuard

Named domains:
- Dim: Int(0..D)

Environment variables:
- none

System variables:
- robotX: Dim
- robotY: Dim

The system controls the movement of a robot on a two-dimensional grid defined by coordinates `robotX` and `robotY`, both ranging from 0 to 7. Three specific target locations are defined: T1 at coordinates (0, 0), T2 at coordinates (7, 7), and T3 at coordinates (0, 7).

Initially, the robot must start at the position where `robotX` is 7 and `robotY` is 0.

Regarding safety, the robot must never occupy an obstacle zone. Specifically, whenever the `robotX` coordinate is 2, the `robotY` coordinate must not be 2, 3, 4, or 5.

Regarding liveness, the robot must visit location T1 infinitely often and must visit location T3 infinitely often.

Additionally, there is an ordering constraint on the visits. Whenever the robot visits location T1, it must not visit location T3 until it has subsequently visited location T2. This ensures that between any visit to T1 and the next visit to T3, the robot must pass through T2.
