

Specification name: EscapingGuard

Named domains:
- Dim: Int(0..D)

Environment variables:
- none

System variables:
- robotX: Dim
- robotY: Dim

The system controls the position of a robot on a two-dimensional grid using the variables `robotX` and `robotY`. Both coordinates are integers ranging from 0 to 7.

Initially, the robot must start at position (7, 0).

The system must ensure the robot avoids obstacle locations at all times. Specifically, if the robot's X-coordinate is 2, its Y-coordinate must not be 2, 3, 4, or 5.

The system must ensure that the robot visits target location T1, defined as position (0, 0), infinitely often.
