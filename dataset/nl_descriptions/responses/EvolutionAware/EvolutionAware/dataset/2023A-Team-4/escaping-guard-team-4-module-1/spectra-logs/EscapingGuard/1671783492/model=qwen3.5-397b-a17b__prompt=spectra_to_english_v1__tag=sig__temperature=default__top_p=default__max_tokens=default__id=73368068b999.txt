

Specification name: EscapingGuard

Named domains:
- Dim: Int(0..D)

Environment variables:
- none

System variables:
- robotX: Dim
- robotY: Dim

The system controls the position of a robot on a two-dimensional grid. The coordinates for the horizontal position `robotX` and the vertical position `robotY` are integers ranging from 0 to 7.

Initially, the robot must be located at position (7, 0).

The system must ensure the following safety conditions hold at all times:
1. The robot must avoid obstacles. Specifically, if the horizontal coordinate `robotX` is 2, the vertical coordinate `robotY` must not be 2, 3, 4, or 5.
2. The horizontal coordinate `robotX` must always be either 0 or 7.

The system must ensure the following liveness conditions are satisfied:
1. The robot must visit the target location (0, 0) infinitely often.
2. The robot must visit the target location (7, 7) infinitely often.
3. The robot must visit the target location (0, 7) infinitely often.
