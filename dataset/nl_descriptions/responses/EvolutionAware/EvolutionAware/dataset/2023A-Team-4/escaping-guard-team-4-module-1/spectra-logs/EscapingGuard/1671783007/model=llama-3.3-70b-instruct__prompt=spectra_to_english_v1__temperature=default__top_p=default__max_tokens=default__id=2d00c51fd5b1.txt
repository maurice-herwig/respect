The EscapingGuard system is a reactive system that controls a robot's movement within a 7x7 grid, where the robot's position is defined by its x and y coordinates (robotX and robotY). The environment does not have direct control over the robot's movement, but its behavior is restricted by assumptions that are not explicitly stated in this specification. 

The system guarantees that the robot will never be on certain obstacles, specifically when the robot's x-coordinate is 2, its y-coordinate will not be 2, 3, 4, or 5. 

Initially, the robot must start at the position (7,0). 

The system also guarantees that the robot will visit each of the target locations (T1, T2, T3) infinitely often. These target locations are defined as follows: T1 is at position (0,0), T2 is at position (7,7), and T3 is at position (0,7). 

In summary, the system ensures the robot starts at a specific location, avoids obstacles, and periodically visits all target locations. The robot's movement is restricted to a 7x7 grid, with its position defined by the system-controlled outputs robotX and robotY.
