

Specification name: CatchingIntruder

Named domains:
- Dim: Int(0..D)

Environment variables:
- none

System variables:
- robotX0: Dim
- robotY0: Dim
- robotX1: Dim
- robotY1: Dim

**Requirements Description**

The system controls the coordinates of two robots, R0 and R1, within a grid defined by the domain `Dim`. The horizontal and vertical positions of robot R0 are controlled by `robotX0` and `robotY0`, respectively, while the positions of robot R1 are controlled by `robotX1` and `robotY1`.

**Initial Conditions**
At the start of operation, both robot R0 and robot R1 must be located at coordinates (0, 0). Specifically, `robotX0` and `robotY0` must initially equal 0, and `robotX1` and `robotY1` must initially equal 0.

**Safety Requirements**
The system must ensure that neither robot enters a static obstacle zone at any time. The obstacle constraint is defined as follows: if a robot's Y-coordinate is 1, its X-coordinate must not be 2, 3, 4, or 5. This requirement applies continuously to both robot R0 and robot R1 throughout system operation.

**Environment Assumptions**
There are no environment-controlled variables, and no assumptions are placed on the environment behavior in this specification.

**System Guarantees**
The system guarantees that the initial positions are set correctly and that the static obstacle avoidance constraint is satisfied always for both robots.
