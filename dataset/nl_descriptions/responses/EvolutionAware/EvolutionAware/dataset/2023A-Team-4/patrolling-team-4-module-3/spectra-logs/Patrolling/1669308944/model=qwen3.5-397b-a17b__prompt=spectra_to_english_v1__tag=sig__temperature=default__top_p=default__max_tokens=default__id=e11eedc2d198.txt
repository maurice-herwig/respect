

Specification name: Patrolling

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)

Environment variables:
- none

System variables:
- robotX: DimX
- robotY: DimY

The system controls the position of a robot using two output variables, `robotX` and `robotY`, which represent the horizontal and vertical coordinates respectively. Both coordinates range from 0 to 4. A specific location is defined as the charging place, which corresponds to the coordinates where `robotX` is 4 and `robotY` is 0.

The system must satisfy the following behavioral guarantees:

1.  **Charging Station Stay Requirement:** Whenever the robot is at the charging place, it must remain at the charging place for the next 5 steps.
2.  **Patrolling Liveness Requirement:** The robot must visit the charging place infinitely often throughout the operation of the system.
