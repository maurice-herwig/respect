

Specification name: Patrolling

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)

Environment variables:
- none

System variables:
- robotX: DimX
- robotY: DimY

The system controls the position of a robot on a grid using two output variables: `robotX` for the horizontal coordinate and `robotY` for the vertical coordinate. Both coordinates range from 0 to 4. The location where `robotX` equals 4 and `robotY` equals 0 is defined as the charging place.

The system must satisfy the following guarantees:

1.  **Charging Duration:** Whenever the robot is at the charging place, it must remain at the charging place for at least five consecutive time steps.
2.  **Return to Charging:** If the robot is not at the charging place for ten consecutive time steps, it must eventually return to the charging place.
