

Specification name: Patrolling

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)

Environment variables:
- none

System variables:
- robotX: DimX
- robotY: DimY

The system controls the position of a robot on a grid using two output variables: `robotX` for the horizontal coordinate and `robotY` for the vertical coordinate. Both coordinates are integers within the range defined by their respective domains. The charging place is located at the specific coordinates where `robotX` equals 4 and `robotY` equals 0.

The system must satisfy the following guarantees regarding the robot's movement and charging behavior:

1.  **Charging Duration:** Whenever the robot is at the charging place, it must remain at the charging place for at least 3 consecutive time steps.
2.  **Excursion Limit:** The robot must not remain away from the charging place for more than 15 consecutive time steps. If the robot is not at the charging place for 15 consecutive steps, it must return to the charging place immediately thereafter.

There are no explicit assumptions restricting the environment, as there are no environment-controlled input variables. There are no specified initial conditions constraining the starting position of the robot.
