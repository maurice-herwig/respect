The Patrolling system is a reactive system that interacts with its environment. The environment controls the locations of three targets, A, B, and C, which are represented by their x and y coordinates (targetAX, targetAY, targetBX, targetBY, targetCX, targetCY). The system controls the location of a robot, which is also represented by its x and y coordinates (robotX, robotY).

The environment is assumed to keep the locations of targets A, B, and C constant over time. 

The system guarantees that the robot will start at the left corner, where its x and y coordinates are both 0. The system also guarantees that the robot will infinitely often visit each of the three targets, A, B, and C, meaning that it will periodically be at the same location as each target. 

The robot's movement is constrained to a grid with dimensions 4x4, where the x coordinate ranges from 0 to 4 (DX) and the y coordinate ranges from 0 to 4 (DY). 

The system's behavior is such that it will repeatedly visit the locations of targets A, B, and C, without any specific requirements on the order or timing of these visits, as long as each target is visited infinitely often.
