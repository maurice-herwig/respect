**Requirements Description for the Patrolling System**

The *Patrolling* system models a robot operating within a bounded, two-dimensional grid of size 5×5 (with coordinates ranging from 0 to 4 in both directions). The system controls the robot's position, specified by two outputs: `robotX` (the robot's horizontal coordinate) and `robotY` (the robot's vertical coordinate), both of which must remain within the defined grid bounds at all times.

The system has no stated assumptions about the environment's behavior, and no additional guarantees, initial conditions, safety constraints, liveness requirements, or state-update rules are specified beyond maintaining valid coordinates. The robot's movement or purpose is not yet defined.
