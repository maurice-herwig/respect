

Specification name: Patrolling

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)

Environment variables:
- targetAX: DimX
- targetAY: DimY
- targetBX: DimX
- targetBY: DimY
- targetCX: DimX
- targetCY: DimY

System variables:
- robotX: DimX
- robotY: DimY

The system controls a robot navigating a two-dimensional grid where both X and Y coordinates range from 0 to 4. The system determines the robot's position using the output variables `robotX` and `robotY`. The environment provides the fixed coordinates for three distinct targets (A, B, and C) via the input variables `targetAX`, `targetAY`, `targetBX`, `targetBY`, `targetCX`, and `targetCY`.

The environment assumes that the target locations are stationary. Once initialized, the coordinates for Target A, Target B, and Target C do not change throughout the operation of the system.

The system guarantees the following behavior:
1.  **Initial Condition:** The robot must start at the origin, with `robotX` equal to 0 and `robotY` equal to 0.
2.  **Movement Safety:** In every step, the robot's movement is constrained. The X coordinate may increase by 1, decrease by 1, or remain unchanged. Similarly, the Y coordinate may increase by 1, decrease by 1, or remain unchanged. This limits the robot to moving to an adjacent cell (including diagonals) or staying in place during each transition.
3.  **Patrol Liveness:** The robot must visit the location of Target A infinitely often. Additionally, the robot must visit the location of Target B infinitely often, and the location of Target C infinitely often.
