The Patrolling system is a reactive system that interacts with an environment containing target locations. The system controls the position of a robot within a grid of size 4x4, with the robot's x-coordinate (robotX) and y-coordinate (robotY) being system-controlled outputs. The environment controls the x and y coordinates of three targets, labeled A, B, and C, with their respective coordinates (targetAX, targetAY, targetBX, targetBY, targetCX, targetCY) being environment-controlled inputs.

The environment is assumed to keep each target at a fixed location, meaning that the x and y coordinates of each target do not change over time.

The system guarantees that the robot starts at the top-left corner of the grid. Additionally, the system ensures that the robot visits each target (A, B, and C) and the top-left corner infinitely often.

At all times, the robot moves exactly one step in either the x or y direction (or stays in the same position), meaning its x and y coordinates can either increase by 1, decrease by 1, or remain the same from one time step to the next. This movement rule applies to both the x and y coordinates of the robot.
