

Specification name: Patrolling

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)

Environment variables:
- targetAX: DimX
- targetAY: DimY
- targetBX: DimX
- targetBY: DimY
- targetCX: DimX
- targetCY: DimY

System variables:
- robotX: DimX
- robotY: DimY

**Requirements Description**

This specification defines a patrolling system operating on a two-dimensional grid where coordinates range from 0 to 4 along both the X and Y axes. The system controls the robot's position, while the environment defines the locations of three static targets.

**Environment Assumptions**
The environment provides the coordinates for three target locations: Target A, Target B, and Target C. Each target is defined by a pair of variables (e.g., targetAX and targetAY for Target A). It is assumed that these target locations remain fixed throughout the operation of the system. Once the environment sets the initial coordinates for any target, those coordinates do not change in any subsequent state.

**System Guarantees**
The system controls the robot's current coordinates, robotX and robotY. The system must ensure that the robot visits each of the three target locations infinitely often. Specifically, the robot must be positioned at Target A infinitely often, at Target B infinitely often, and at Target C infinitely often. This requires the robot to repeatedly return to each target location over an infinite execution timeline.
