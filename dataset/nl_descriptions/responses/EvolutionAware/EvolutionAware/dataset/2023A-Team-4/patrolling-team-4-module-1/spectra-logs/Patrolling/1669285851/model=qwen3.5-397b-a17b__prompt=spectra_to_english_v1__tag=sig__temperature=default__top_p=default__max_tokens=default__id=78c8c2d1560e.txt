

Specification name: Patrolling

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)

Environment variables:
- targetAX: DimX
- targetAY: DimY
- targetBX: DimX
- targetBY: DimY
- targetCX: DimX
- targetCY: DimY

System variables:
- robotX: DimX
- robotY: DimY

The system controls a robot navigating a two-dimensional grid where both X and Y coordinates range from 0 to 4. The system determines the robot's position variables, `robotX` and `robotY`. The environment determines the position variables for three targets: Target A (`targetAX`, `targetAY`), Target B (`targetBX`, `targetBY`), and Target C (`targetCX`, `targetCY`).

The environment is restricted by the assumption that the coordinates for all three targets remain constant throughout operation; the targets are stationary.

Provided the environment satisfies this assumption, the system must satisfy the following guarantees:

1.  **Initial Condition:** The robot must start at the grid coordinates (0, 0).
2.  **Liveness Requirements:** The robot must visit the location of Target A infinitely often. Additionally, the robot must visit the location of Target B infinitely often, and the location of Target C infinitely often.
