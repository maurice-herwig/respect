

Specification name: EscapingGuard

Named domains:
- Dim: Int(0..D)

Environment variables:
- none

System variables:
- robotX: Dim
- robotY: Dim

The system controls the position of a robot on a two-dimensional grid. The system variables `robotX` and `robotY` represent the robot's horizontal and vertical coordinates, respectively, where each coordinate is an integer ranging from 0 to 7.

Internally, the system maintains a turn counter that initializes to 0. This counter cycles continuously through the sequence 0, 1, 2, advancing by one at each step and returning to 0 after reaching 2. The system guarantees that whenever the internal turn counter equals 2, the robot must remain stationary; both `robotX` and `robotY` must retain exactly the same values as in the previous step. At all times, the robot's coordinates must remain within the valid grid boundaries.
