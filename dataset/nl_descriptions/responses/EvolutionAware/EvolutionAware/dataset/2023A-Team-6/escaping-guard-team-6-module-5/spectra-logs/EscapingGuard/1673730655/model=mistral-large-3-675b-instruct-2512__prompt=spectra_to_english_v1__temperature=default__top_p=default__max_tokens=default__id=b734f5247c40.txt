### **Requirements for the EscapingGuard System**

This system describes the behavior of a robot moving within a 7×7 grid (coordinates ranging from 0 to 6). The robot's position is defined by two system-controlled variables:
- **robotX** (horizontal position)
- **robotY** (vertical position)

#### **System Guarantees**
The robot must **always** avoid the following fixed obstacle locations:
- The coordinates (2, 6)
- The coordinates (3, 6)

At no point should the robot occupy either of these positions. The system ensures this safety constraint at all times.
