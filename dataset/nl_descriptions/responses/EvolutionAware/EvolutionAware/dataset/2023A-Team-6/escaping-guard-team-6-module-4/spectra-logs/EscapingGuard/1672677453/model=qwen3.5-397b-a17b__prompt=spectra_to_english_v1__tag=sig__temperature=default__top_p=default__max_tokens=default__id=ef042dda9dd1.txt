

Specification name: EscapingGuard

Named domains:
- Dim: Int(0..D)

Environment variables:
- guardX: Dim
- guardY: Dim

System variables:
- robotX: Dim
- robotY: Dim

The system controls the position of a robot on a two-dimensional grid, while the environment determines the position of a guard. All coordinates for both the robot and the guard are integers ranging from 0 to 7.

The system must ensure that the robot never touches the guard. The guard occupies a 2x2 square area on the grid, with its top-left corner located at the coordinates (guardX, guardY). To satisfy this safety requirement, the robot's position (robotX, robotY) must never coincide with any of the four grid cells covered by the guard. Specifically, at all times, the robot must not be located at the guard's top-left corner (guardX, guardY), top-right corner (guardX + 1, guardY), bottom-left corner (guardX, guardY + 1), or bottom-right corner (guardX + 1, guardY + 1).
