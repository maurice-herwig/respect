**Requirements Description for EscapingGuard System**

The *EscapingGuard* system models the interaction between a robotic agent and an external guarding entity within a two-dimensional grid of size 7×7 (indexed from 0 to 6). The system controls the robot's position, specified by its coordinates `(robotX, robotY)`. The environment controls the position of the guard, defined by the coordinates `(guardX, guardY)` of its top-left corner.

### Environment Assumptions
The specification does not impose explicit restrictions on the environment's behavior. The guard's position may change freely over time.

### System Guarantees
The system must ensure that the robot never occupies any of the four grid positions that form the guard's 2×2 area. Specifically, at every point in time, the robot's coordinates must *not* coincide with any of the following positions relative to the guard's top-left corner:
- `(guardX, guardY)`,
- `(guardX + 1, guardY)`,
- `(guardX, guardY + 1)`, or
- `(guardX + 1, guardY + 1)`.

This safety requirement holds continuously throughout the system's operation. No other constraints (initial conditions, liveness properties, or state transitions) are specified for the system.
