

Specification name: Deliveries

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)
- Coord: Int(0..DY)

Environment variables:
- package0X: DimX
- package0Y: DimY
- package1X: DimX
- package1Y: DimY

System variables:
- robotX0: DimX
- robotY0: DimY
- robotX1: DimX
- robotY1: DimY

The system controls the positions of two robots within a two-dimensional grid, while the environment determines the target locations for two corresponding packages. The grid dimensions for both the X and Y axes range from 0 to 5.

The environment provides the coordinates for Package 0 via the variables `package0X` and `package0Y`, and for Package 1 via `package1X` and `package1Y`. The system controls the coordinates for Robot 0 via `robotX0` and `robotY0`, and for Robot 1 via `robotX1` and `robotY1`.

The system must ensure that Robot 0 reaches the location of Package 0 infinitely often. This requirement is satisfied when the position of Robot 0 matches the location of Package 0, meaning `robotX0` equals `package0X` and `robotY0` equals `package0Y`. This matching condition must occur infinitely many times throughout the system's execution.

Similarly, the system must ensure that Robot 1 reaches the location of Package 1 infinitely often. This requirement is satisfied when the position of Robot 1 matches the location of Package 1, meaning `robotX1` equals `package1X` and `robotY1` equals `package1Y`. This matching condition must also occur infinitely many times throughout the system's execution.
