

Specification name: CatchingIntruder

Named domains:
- Dim: Int(0..D)

Environment variables:
- none

System variables:
- robotX0: Dim
- robotY0: Dim
- robotX1: Dim
- robotY1: Dim

The system controls the positions of two robots, Robot 0 and Robot 1, on a grid where coordinates are integers between 0 and 7. The system outputs the X and Y coordinates for both robots at every step. There are no environment inputs influencing this behavior.

The system must satisfy the following safety guarantees at all times:

1.  **Movement Step Size:** Between any two consecutive states, the value of each coordinate variable (robotX0, robotY0, robotX1, and robotY1) must change by at most 1. Specifically, each coordinate must either remain the same, increase by 1, or decrease by 1 in the next state.
2.  **Non-Diagonal Movement:** Robots are prohibited from moving diagonally. For each robot, at least one of its coordinates must remain unchanged between consecutive states. This means Robot 0 cannot change both robotX0 and robotY0 simultaneously, and Robot 1 cannot change both robotX1 and robotY1 simultaneously. A robot may move horizontally, vertically, or remain stationary, but never change both X and Y coordinates in the same step.
