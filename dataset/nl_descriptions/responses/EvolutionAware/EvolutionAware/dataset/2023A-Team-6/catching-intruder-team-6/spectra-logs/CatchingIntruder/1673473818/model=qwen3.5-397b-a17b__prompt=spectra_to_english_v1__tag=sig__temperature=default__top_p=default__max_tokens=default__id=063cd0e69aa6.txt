

Specification name: CatchingIntruder

Named domains:
- Dim: Int(0..D)

Environment variables:
- none

System variables:
- robotX0: Dim
- robotY0: Dim
- robotX1: Dim
- robotY1: Dim

The system controls the positions of two robots, Robot 0 and Robot 1, on a two-dimensional grid. The coordinates for both robots are defined by the domain `Dim`, which consists of integers ranging from 0 to 7. The system outputs the X and Y coordinates for each robot (`robotX0`, `robotY0`, `robotX1`, `robotY1`). There are no environment-controlled inputs.

The system must ensure the following behavioral guarantees at every step of operation:

**Movement Constraints**
Each robot must move at most one unit step at a time. Specifically, for both Robot 0 and Robot 1, the X and Y coordinates may either remain unchanged, increase by 1, or decrease by 1 from one step to the next. Furthermore, robots are prohibited from moving diagonally. For each robot, at least one coordinate (either X or Y) must remain unchanged during any step. This ensures that a robot moves either horizontally, vertically, or remains stationary, but never changes both coordinates simultaneously.

**Obstacle Avoidance**
The system must prevent both robots from entering specific obstacle zones. Specifically, if a robot's Y coordinate is 1, its X coordinate must not be 2, 3, 4, or 5. This restriction applies permanently to both Robot 0 and Robot 1 throughout the system's operation.
