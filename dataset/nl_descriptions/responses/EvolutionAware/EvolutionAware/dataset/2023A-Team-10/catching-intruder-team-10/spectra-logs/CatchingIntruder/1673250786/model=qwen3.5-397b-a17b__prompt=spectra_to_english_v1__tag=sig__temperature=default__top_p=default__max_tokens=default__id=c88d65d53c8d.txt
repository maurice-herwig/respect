

Specification name: CatchingIntruder

Named domains:
- Dim: Int(0..D)

Environment variables:
- none

System variables:
- robotX0: Dim
- robotY0: Dim
- robotX1: Dim
- robotY1: Dim

The system controls the coordinates of two robots on a two-dimensional grid. The variables `robotX0` and `robotY0` represent the position of Robot 0, while `robotX1` and `robotY1` represent the position of Robot 1. All coordinate values are integers ranging from 0 to 7.

The system must satisfy the following guarantees at all times:

1. **Obstacle Avoidance:** Neither robot may ever occupy an obstacle position. The forbidden positions are those where the Y-coordinate is 1 and the X-coordinate is 2, 3, 4, or 5. Specifically, the positions (2,1), (3,1), (4,1), and (5,1) are prohibited for both robots.

2. **Collision Avoidance:** The two robots must never occupy the same position simultaneously. It is required that `robotX0` differs from `robotX1` or `robotY0` differs from `robotY1` at all times.

3. **Movement Constraints:** At every step, each robot must move exactly one unit distance either horizontally or vertically. Remaining stationary is not permitted.
   - For Robot 0: Either `robotX0` changes by exactly +1 or -1 while `robotY0` remains unchanged, or `robotY0` changes by exactly +1 or -1 while `robotX0` remains unchanged.
   - For Robot 1: Either `robotX1` changes by exactly +1 or -1 while `robotY1` remains unchanged, or `robotY1` changes by exactly +1 or -1 while `robotX1` remains unchanged.
