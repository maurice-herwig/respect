

Specification name: CatchingIntruder

Named domains:
- Dim: Int(0..D)

Environment variables:
- none

System variables:
- robotX0: Dim
- robotY0: Dim
- robotX1: Dim
- robotY1: Dim

The system controls the coordinates of two robots, Robot 0 and Robot 1, on a grid where the dimension size D is 7. The variables `robotX0` and `robotY0` represent the position of Robot 0, while `robotX1` and `robotY1` represent the position of Robot 1. All position variables are integers ranging from 0 to D.

Initially, Robot 0 starts at position (0, 0) and Robot 1 starts at position (7, 0).

Throughout operation, the system must ensure the following safety requirements:
1.  **Obstacle Avoidance:** Neither Robot 0 nor Robot 1 may ever occupy the obstacle locations at coordinates (2, 1), (3, 1), (4, 1), or (5, 1).
2.  **Collision Avoidance:** The two robots must never occupy the same position simultaneously.

Regarding movement behavior:
1.  **Robot 0 Movement:** At every step, Robot 0 must move exactly one unit in either the X direction or the Y direction. It cannot remain stationary nor move diagonally.
2.  **Robot 1 Movement:** Once Robot 0 has reached position (0, 7), Robot 1 must also move exactly one unit in either the X direction or the Y direction at every step. Prior to Robot 0 reaching this position, Robot 1 is constrained only by the obstacle and collision avoidance requirements.
