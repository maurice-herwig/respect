

Specification name: CatchingIntruder

Named domains:
- Dim: Int(0..D)

Environment variables:
- none

System variables:
- robotX0: Dim
- robotY0: Dim
- robotX1: Dim
- robotY1: Dim

**Requirements Description**

The system controls the positions of two robots, Robot 0 and Robot 1, on a two-dimensional grid. The coordinates for both robots are defined by the domain Dim, which represents integers from 0 to 7 (where D is 7).

**Initial Conditions**
At the start of operation, Robot 0 is positioned at coordinates (0, 0), and Robot 1 is positioned at coordinates (7, 0).

**Safety Requirements**
The system must ensure that both robots avoid specific obstacle locations at all times. The forbidden obstacle coordinates are (2, 1), (3, 1), (4, 1), and (5, 1). Additionally, the robots must never collide; they are prohibited from occupying the same position simultaneously, meaning their X and Y coordinates cannot be identical at the same time.

**Movement Dynamics**
At every step, each robot must move exactly one unit along either the horizontal or vertical axis. Specifically, for each robot, either the X-coordinate must increase or decrease by 1 while the Y-coordinate remains unchanged, or the Y-coordinate must increase or decrease by 1 while the X-coordinate remains unchanged. Diagonal movements and remaining stationary are not permitted. All positions must remain within the valid coordinate range of 0 to 7.
