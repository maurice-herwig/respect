

Specification name: CatchingIntruder

Named domains:
- Dim: Int(0..D)

Environment variables:
- none

System variables:
- robotX0: Dim
- robotY0: Dim
- robotX1: Dim
- robotY1: Dim

The system controls the grid positions of two robots, Robot 0 and Robot 1. Each robot's position is defined by an X coordinate and a Y coordinate, where all coordinates are integers ranging from 0 to 7.

The system must ensure that both robots avoid specific obstacle locations at all times. Neither Robot 0 nor Robot 1 may ever occupy the coordinates (2, 1), (3, 1), (4, 1), or (5, 1). Additionally, the two robots must never collide; they are prohibited from occupying the same X and Y coordinates simultaneously.

Movement transitions are constrained to maintain orthogonal motion for unit steps. For each robot, if the X coordinate changes by exactly one unit between consecutive steps, the Y coordinate must remain unchanged. Conversely, if the Y coordinate changes by exactly one unit between consecutive steps, the X coordinate must remain unchanged.
