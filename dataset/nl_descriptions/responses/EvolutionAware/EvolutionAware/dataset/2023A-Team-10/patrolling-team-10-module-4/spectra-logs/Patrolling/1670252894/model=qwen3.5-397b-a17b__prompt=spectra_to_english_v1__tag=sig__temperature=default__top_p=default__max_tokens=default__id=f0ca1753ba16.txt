

Specification name: Patrolling

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)
- Dim: Int(0..4)

Environment variables:
- movingObstacleX: DimX
- movingObstacleY: DimY

System variables:
- robot: Dim[2]

The system controls the position of a robot on a grid, while the environment controls the position of a moving obstacle. The robot's position is stored in the variable `robot`, where `robot[0]` represents the X-coordinate and `robot[1]` represents the Y-coordinate. The moving obstacle's position is defined by the environment variables `movingObstacleX` and `movingObstacleY`. All coordinates range from 0 to 4.

The system must satisfy the following safety guarantees:

1.  **Collision Avoidance (Moving Obstacle):** The robot must never occupy the same coordinates as the moving obstacle. That is, it is never the case that `robot[0]` equals `movingObstacleX` and `robot[1]` equals `movingObstacleY` simultaneously.
2.  **Collision Avoidance (Static Obstacles):** The robot must never occupy any of the following specific static obstacle positions: (1, 1), (3, 3), (2, 1), (0, 3), or (3, 4).
3.  **Movement Constraints:** In every step, the robot's movement is limited. For both the X-coordinate (`robot[0]`) and the Y-coordinate (`robot[1]`), the value in the next state must be either equal to the current value, one less than the current value, or one greater than the current value. This ensures the robot moves at most one unit in any direction or remains stationary at each step.
