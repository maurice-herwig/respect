

Specification name: Deliveries

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)
- Coord: Int(0..DY)

Environment variables:
- none

System variables:
- robotX0: DimX
- robotY0: DimY
- robotX1: DimX
- robotY1: DimY

The **Deliveries** system controls the positions of two robots within a grid defined by the specified domains. All position variables are system-controlled outputs; there are no environment-controlled inputs. The horizontal coordinates `robotX0` and `robotX1` are constrained to the **DimX** domain, and the vertical coordinates `robotY0` and `robotY1` are constrained to the **DimY** domain.

Regarding initial conditions, both robots must start at vertical position 0. Specifically, `robotY0` must be 0 and `robotY1` must be 0 at the beginning of execution.

Regarding safety requirements, the system must ensure that the two robots never collide. A collision is defined as both robots occupying the same horizontal coordinate and the same vertical coordinate simultaneously. The system must guarantee that this collision condition never holds at any point during operation.
