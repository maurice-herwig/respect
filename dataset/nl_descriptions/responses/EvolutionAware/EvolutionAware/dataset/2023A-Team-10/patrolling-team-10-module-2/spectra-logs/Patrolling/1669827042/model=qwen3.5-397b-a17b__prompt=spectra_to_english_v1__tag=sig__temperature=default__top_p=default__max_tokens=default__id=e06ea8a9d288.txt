

Specification name: Patrolling

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)

Environment variables:
- none

System variables:
- robotX: DimX
- robotY: DimY
- movingObstacleX: DimX
- movingObstacleY: DimY

The system controls the variables `robotX`, `robotY`, `movingObstacleX`, and `movingObstacleY`. The variables `robotX` and `movingObstacleX` belong to the domain `DimX`, which consists of integer values from 0 to 4. The variables `robotY` and `movingObstacleY` belong to the domain `DimY`, which consists of integer values from 0 to 4. The system selects values for these variables within their respective domains throughout operation.
