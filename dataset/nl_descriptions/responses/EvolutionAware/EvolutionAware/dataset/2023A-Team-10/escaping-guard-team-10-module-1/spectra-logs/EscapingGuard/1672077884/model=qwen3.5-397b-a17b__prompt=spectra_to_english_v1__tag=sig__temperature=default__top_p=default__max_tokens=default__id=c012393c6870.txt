

Specification name: EscapingGuard

Named domains:
- Dim: Int(0..D)

Environment variables:
- Obstacles: Dim[4][2]
- targets: Dim[3][2]

System variables:
- robot: Dim[2]

The EscapingGuard specification defines the interface for a reactive system operating within a bounded two-dimensional grid. The coordinate space is established by the domain Dim, which consists of integer values ranging from 0 to 7.

The system controls the `robot` variable, which represents the current position of the robot as a pair of coordinates within the grid.

The environment controls the `Obstacles` variable, which specifies the locations of four distinct obstacles, each defined by a pair of coordinates. The environment also controls the `targets` variable, which specifies the locations of three distinct targets, each defined by a pair of coordinates.
