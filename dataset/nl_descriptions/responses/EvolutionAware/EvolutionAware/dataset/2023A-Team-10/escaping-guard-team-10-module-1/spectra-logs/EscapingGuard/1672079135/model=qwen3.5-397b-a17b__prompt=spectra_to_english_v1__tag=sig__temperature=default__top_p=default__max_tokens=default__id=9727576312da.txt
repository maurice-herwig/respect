

Specification name: EscapingGuard

Named domains:
- Dim: Int(0..D)

Environment variables:
- Obstacles: Dim[4][2]
- targets: Dim[3][2]

System variables:
- robot: Dim[2]

The system controls the position of a robot on a two-dimensional grid, while the environment controls variables representing obstacle and target configurations. The grid coordinates for all variables range from 0 to 7.

Initially, the robot is positioned at coordinates (7, 0).

Regarding safety and movement, the system must ensure that the robot never occupies any of the following fixed obstacle locations: (2, 2), (2, 3), (2, 4), or (2, 5). Additionally, in every transition, each coordinate of the robot's position must change by at most one unit. Specifically, for each dimension, the next position must be equal to the current position, one greater than the current position, or one less than the current position.

Regarding liveness, the system guarantees that the robot will infinitely often visit each of the following three target locations: (0, 0), (7, 7), and (7, 0).
