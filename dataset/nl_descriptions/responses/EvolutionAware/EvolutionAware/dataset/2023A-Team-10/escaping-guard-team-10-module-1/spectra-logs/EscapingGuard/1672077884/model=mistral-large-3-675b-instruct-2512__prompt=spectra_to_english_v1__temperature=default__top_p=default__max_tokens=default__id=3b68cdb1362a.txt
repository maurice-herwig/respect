**Requirements for the EscapingGuard Reactive System**

This system describes the behavior of a robot operating in a 7×7 discrete grid (with coordinates ranging from 0 to 6). The robot's position is controlled by the system, while the environment provides fixed obstacles and target locations.

**Environment-Provided Inputs:**
1. **Obstacles:** The environment defines up to four obstacles, each occupying a specific grid coordinate `[x, y]` where both `x` and `y` range from 0 to 6.
2. **Targets:** The environment specifies up to three target locations, each given as a coordinate `[x, y]` in the same grid.

**System-Controlled Outputs:**
- **Robot:** The system controls the robot’s position as a single coordinate `[x, y]` on the grid.

**Assumptions on the Environment:**
- The environment provides valid obstacle and target coordinates, all within the 7×7 grid bounds.

**Initial Conditions:**
- The specification does not impose any initial constraints on the robot’s position.

**System Guarantees:**
- The specification does not yet define any safety, liveness, or next-state behavior for the robot. Its movement or interactions with obstacles and targets remain unspecified.
