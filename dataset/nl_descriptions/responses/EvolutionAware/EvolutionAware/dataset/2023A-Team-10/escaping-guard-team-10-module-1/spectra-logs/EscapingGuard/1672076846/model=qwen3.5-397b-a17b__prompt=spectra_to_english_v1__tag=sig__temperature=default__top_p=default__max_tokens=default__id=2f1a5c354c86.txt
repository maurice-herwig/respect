

The EscapingGuard specification defines a reactive system operating within a bounded two-dimensional grid. The coordinate space is restricted to integer values between 0 and 7. The environment controls the input variables representing the positions of obstacles and targets within this space. The system controls the output variable representing the position of a robot. All spatial variables are structured as arrays of coordinates within the specified domain.

Specification name: EscapingGuard

Named domains:
- Dim: Int(0..D)

Environment variables:
- Obstacles: Dim[4][2]
- targets: Dim[3][2]

System variables:
- robot: Dim[2]
