

Specification name: EscapingGuard

Named domains:
- Dim: Int(0..D)

Environment variables:
- Obstacles: Dim[4][2]
- targets: Dim[3][2]

System variables:
- robot: Dim[2]

**Requirements Description**

This specification defines the behavior of a reactive system involving a robot operating within a bounded integer space. The constant `D` is defined as 7, meaning the domain `Dim` consists of integers ranging from 0 to 7 inclusive.

**Variable Control**
The environment controls the input variables `Obstacles`, a 4x2 array, and `targets`, a 3x2 array. All elements within these arrays must hold values within the `Dim` domain. The system controls the output variable `robot`, which is an array of 2 elements, each also constrained to the `Dim` domain.

**Initial Conditions**
Upon initialization of the system, the `robot` variable must start in a specific state:
- The first element, `robot[0]`, must be initialized to 7.
- The second element, `robot[1]`, must be initialized to 0.

**System Guarantees**
The system must ensure that the robot's position changes gradually over time. At every step of the system execution, the transition from the current state to the next state for each component of the `robot` array must satisfy the following constraint:
- For both `robot[0]` and `robot[1]`, the value in the next state must be either equal to the current value, one greater than the current value, or one less than the current value.

This constraint applies continuously throughout the operation of the system.
