### **Requirements Description for the *EscapingGuard* Reactive System**

This system models the behavior of a **robot** that operates in a discrete 2D grid of size **8×8** (where coordinates range from 0 to 7 in both dimensions). The robot's movement and decision-making are influenced by two environment-controlled inputs: **obstacles** and **targets**.

#### **Environment-Controlled Inputs:**
1. **Obstacles** – The environment provides a set of up to **four obstacles**, each defined by its **2D position** on the grid. The robot must avoid these obstacles.
2. **Targets** – The environment provides a set of up to **three targets**, each defined by its **2D position** on the grid. The robot is expected to interact with these targets in some manner (though the exact behavior is not specified in this partial description).

#### **System-Controlled Output:**
1. **Robot** – The system controls the **position of a single robot**, represented as a **2D coordinate** on the grid.

#### **Initial Conditions:**
No explicit initial conditions are specified for the robot's position, obstacles, or targets. The system and environment may begin in any valid state.

#### **Behavioral Requirements:**
Since this specification only declares variables and does not include assumptions (`asm`) or guarantees (`gar`), there are no constraints on the environment's behavior or the system's reactions. The robot’s movement rules, obstacle avoidance, and target interaction are not yet defined in this partial description.
