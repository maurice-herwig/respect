

Specification name: Patrolling

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)
- Dim: Int(0..5)

Environment variables:
- goalsX: Dim[3]
- goalsY: Dim[3]

System variables:
- robotX: DimX
- robotY: DimY
- isGoalBlocked: boolean[3]

**Requirements Description**

The Patrolling system defines a reactive interaction between a robot and an environment containing three goals. The environment provides the coordinates for the three goals via the inputs `goalsX` and `goalsY`. The system controls the robot's position using outputs `robotX` and `robotY`, and manages the blocking status of the goals using the output array `isGoalBlocked`.

The system must satisfy the following guarantees regarding the goal blocking status:

1.  **Goal 0 Safety Requirement:** The first goal (index 0) must never be blocked. The system must ensure that `isGoalBlocked[0]` is always false.
2.  **Goal 1 Liveness Requirement:** The blocking status of the second goal (index 1) must change infinitely often. The system must ensure that `isGoalBlocked[1]` is true infinitely often and false infinitely often.
3.  **Goal 2 Liveness Requirement:** The blocking status of the third goal (index 2) must change infinitely often. The system must ensure that `isGoalBlocked[2]` is true infinitely often and false infinitely often.
