

Specification name: Patrolling

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)
- Dim: Int(0..5)

Environment variables:
- targets: Dim[3][2]

System variables:
- robotX: DimX
- robotY: DimY
- IsTargetBlocked: boolean[3]

The Patrolling specification describes a reactive system where the system controls the position of a robot and the blocked status of three targets, while the environment provides the target configuration. The system outputs include the robot's horizontal coordinate `robotX` and vertical coordinate `robotY`, both constrained to their respective dimensions, as well as the boolean array `IsTargetBlocked` which indicates the blocked status for each of the three targets. The environment input consists of the `targets` array.

The system must satisfy specific liveness requirements regarding the target blocked status. For each target index 0, 1, and 2, the system guarantees that the corresponding value in `IsTargetBlocked` becomes true infinitely often and becomes false infinitely often. This ensures that the blocked status for every target toggles repeatedly throughout the system's operation.
