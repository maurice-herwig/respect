

Specification name: Patrolling

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)
- Dim: Int(0..5)

Environment variables:
- targetA: Dim[2]
- targetB: Dim[2]
- targetC: Dim[2]

System variables:
- robotX: DimX
- robotY: DimY
- IsTargetBlocked: boolean[3]

**Requirements Description**

The Patrolling system defines a reactive interaction between an environment and a system. The environment provides input values representing the coordinates of three targets via the variables `targetA`, `targetB`, and `targetC`. The system controls the output variables `robotX` and `robotY`, which represent the robot's position, and the `IsTargetBlocked` array, which indicates the blocked status for three target indices.

The system must satisfy specific liveness guarantees regarding the `IsTargetBlocked` array. For each index 0, 1, and 2, the system guarantees that the value of `IsTargetBlocked` at that index becomes true infinitely often. Additionally, for each index 0, 1, and 2, the system guarantees that the value becomes false infinitely often. This requires the system to continually toggle the blocked status for each target index throughout the operation, ensuring that no index remains permanently true or permanently false.
