

Specification name: Patrolling

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)
- Dim: Int(0..5)

Environment variables:
- goalsX: Dim[3]
- goalsY: Dim[3]

System variables:
- robotX: DimX
- robotY: DimY
- isGoalBlocked: boolean[3]

**Behavioral Requirements**

The system manages a patrolling operation where it controls the robot's position and the blocked status of three goals, while the environment determines the coordinates of those goals. The system must satisfy specific liveness requirements regarding the blocked status of each goal.

For each of the three goal indices (0, 1, and 2), the system guarantees that the corresponding `isGoalBlocked` signal is true infinitely often during execution. Additionally, for each of the three goal indices, the system guarantees that the corresponding `isGoalBlocked` signal is false infinitely often during execution. This ensures that the blocked status for every goal visits both true and false states repeatedly throughout the system's operation.
