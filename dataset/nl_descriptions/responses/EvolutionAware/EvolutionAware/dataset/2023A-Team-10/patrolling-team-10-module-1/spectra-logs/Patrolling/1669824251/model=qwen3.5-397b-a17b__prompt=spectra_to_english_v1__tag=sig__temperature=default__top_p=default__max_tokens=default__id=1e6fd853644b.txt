

Specification name: Patrolling

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)
- Dim: Int(0..5)

Environment variables:
- goals: Dim[3][2]

System variables:
- robotX: DimX
- robotY: DimY
- isGoalBlocked: boolean[3]

The Patrolling system defines the behavior of a robot interacting with a set of three goals. The environment controls the `goals` variable, which specifies the configuration of the three goals using dimension values. The system controls the robot's position via the `robotX` and `robotY` variables, as well as the `isGoalBlocked` array, which contains three boolean flags indicating the blocked status of each corresponding goal.

The system must satisfy specific liveness requirements regarding the blocked status of the goals. For each goal index from 0 to 2, the system guarantees that the corresponding `isGoalBlocked` flag becomes true infinitely often during execution. Additionally, for each goal index from 0 to 2, the system guarantees that the corresponding `isGoalBlocked` flag becomes false infinitely often. These requirements ensure that the blocked status for every goal toggles between true and false repeatedly throughout the system's operation.
