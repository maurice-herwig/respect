### **Requirements Description for the EscapingGuard System**

This system governs an interaction between an environment and a reactive component in a two-dimensional grid where each dimension spans integer values from 0 to 6 (inclusive).

#### **Environment-Controlled Inputs**
The environment controls the position of a **"guard"**, represented as a two-element array of coordinates, `guard[0]` and `guard[1]`, each ranging from 0 to 6.

#### **Assumptions on the Environment**
At every step, the environment must ensure that in each dimension, the guard's position either:
- remains unchanged,
- increases by exactly one, or
- decreases by exactly one.

This means the guard can move at most one step per turn in any direction or stay in place.

#### **System Guarantees**
The specification does not yet impose any requirements on how the system should react to the guard's movements. Currently, no guarantees (safety, liveness, or initial conditions) are enforced on the system's behavior.

The specification only defines the constraints on the environment’s allowed behavior. Future requirements may impose conditions on the system's outputs or responses.
