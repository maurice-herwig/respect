

Specification name: EscapingGuard

Named domains:
- Dim: Int(0..D)

Environment variables:
- guard: Dim[2]

System variables:
- none

The EscapingGuard specification defines a reactive system context involving a bounded dimensional space. The domain Dim represents integer values ranging from 0 to 7. The environment controls the input variable guard, which is an array containing two elements of type Dim. There are no system-controlled output variables. The specification defines a predicate moveDist that characterizes a valid transition for a position, where the value in the next state is either equal to, one greater than, or one less than the current value. The environment variable guard is constrained to hold values within the Dim domain.
