

Specification name: PatrollingTeam8Module2

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)
- Dim: Int(0..D)

Environment variables:
- target1: Dim[2]
- target2: Dim[2]
- target3: Dim[2]

System variables:
- robotX: DimX
- robotY: DimY

**Requirements Description**

This specification defines the behavior of a robot patrolling among three targets. The environment provides the coordinates for the targets, while the system controls the robot's position.

**Environment Assumptions**
The environment provides the locations for `target1`, `target2`, and `target3`. It is assumed that the coordinates for all three targets remain constant throughout the execution of the system; the targets do not move.

**System Guarantees**
The system must control the robot's position variables, `robotX` and `robotY`, to satisfy the following requirements:

*   **Initial Condition:** At the beginning of execution, the robot must start at position (0, 0).
*   **Liveness Requirements:** The robot must reach the location of `target1` infinitely often. Similarly, the robot must reach the location of `target2` infinitely often, and the location of `target3` infinitely often.
