- fixedObstacle1: Dim[2]

System variables:
- none

This specification defines the behavior of obstacles within the environment. The constant D is defined as 4, meaning all coordinate values range from 0 to 4.

**Environment Assumptions**

The environment controls five fixed obstacles and one moving obstacle. Each obstacle is represented by a pair of coordinates (index 0 and index 1).

The five fixed obstacles remain stationary at specific coordinates throughout the system operation:
- fixedObstacle1 is always at coordinates (1, 1).
- fixedObstacle2 is always at coordinates (2, 1).
- fixedObstacle3 is always at coordinates (0, 3).
- fixedObstacle4 is always at coordinates (3, 3).
- fixedObstacle5 is always at coordinates (3, 4).

The moving obstacle has the following behavior constraints:
- **Initial Condition:** Initially, the moving obstacle is located at coordinates (0, 2).
- **Horizontal Movement:** The horizontal coordinate (index 0) must change at every time step. Specifically, the value must increase or decrease by exactly 1 unit in each step. The horizontal coordinate cannot remain the same between consecutive states.
- **Vertical Movement:** The vertical coordinate (index 1) is constrained only by the domain Dim.

**System Guarantees**

There are no system-controlled variables or guarantees defined in this module.
