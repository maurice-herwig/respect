

Specification name: PatrollingTeam8Module1

Named domains:
- Dim: Int(0..D)

Environment variables:
- fixedObstacle1: Dim[2]
- fixedObstacle2: Dim[2]
- fixedObstacle3: Dim[2]
- fixedObstacle4: Dim[2]
- fixedObstacle5: Dim[2]
- movingObstacle: Dim[2]

System variables:
- none

**Requirements Description**

This specification module defines the behavior of obstacles within a patrolling environment. The domain `Dim` represents integers ranging from 0 to 4. All variables listed are controlled by the environment; there are no system-controlled outputs defined in this module.

**Environment Assumptions**
The environment manages five fixed obstacles and one moving obstacle. The positions of the five fixed obstacles remain constant throughout execution:
- `fixedObstacle1` is always located at coordinates (1, 1).
- `fixedObstacle2` is always located at coordinates (2, 1).
- `fixedObstacle3` is always located at coordinates (0, 3).
- `fixedObstacle4` is always located at coordinates (3, 3).
- `fixedObstacle5` is always located at coordinates (3, 4).

The `movingObstacle` has specific initial and transitional constraints. Initially, the `movingObstacle` is located at coordinates (0, 2). Regarding its movement, the first coordinate (index 0) is constrained such that between any two consecutive states, its value changes by at most one unit. Specifically, the value of the first coordinate in the next state must be equal to the current value, one greater than the current value, or one less than the current value.

**System Guarantees**
This module does not impose any guarantees on system-controlled variables.
