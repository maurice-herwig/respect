

Specification name: PatrollingTeam8Module2

Named domains:
- DimX: Int(0..DX)
- DimY: Int(0..DY)
- Dim: Int(0..D)

Environment variables:
- target1: Dim[2]
- target2: Dim[2]
- target3: Dim[2]

System variables:
- robotX: DimX
- robotY: DimY

The system controls the robot's horizontal and vertical position coordinates using the variables `robotX` and `robotY`. The environment provides the positions of three targets, `target1`, `target2`, and `target3`, where each target position consists of two coordinate values.

The specification defines assumptions regarding the behavior of the environment. It is assumed that the targets are stationary and do not change position during operation. Specifically, for each of the three targets, both coordinate values must remain constant at every step. The value of each coordinate in the next state must always equal its value in the current state.
