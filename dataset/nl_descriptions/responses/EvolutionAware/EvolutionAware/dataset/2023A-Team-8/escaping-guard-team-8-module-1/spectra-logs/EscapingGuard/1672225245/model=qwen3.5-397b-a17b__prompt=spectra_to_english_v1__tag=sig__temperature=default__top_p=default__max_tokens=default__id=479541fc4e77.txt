

### Requirements Description

The **EscapingGuard** system controls the position of a robot on a two-dimensional grid. The system manages two output variables, `robotX` and `robotY`, which represent the horizontal and vertical coordinates of the robot, respectively. Both coordinates are integers constrained to the domain `Dim`, ranging from 0 to 7.

**Initial Conditions**
Upon system start, the robot must be positioned at coordinates `robotX` = 7 and `robotY` = 0.

**Movement Behavior**
The system regulates robot movement based on an internal cycling condition, `robotCanMove`, which takes values between 0 and 2. This condition increments automatically at every step and wraps around modulo 3.

1.  **Stationary Phase:** When `robotCanMove` is 0, the robot must remain stationary. Both `robotX` and `robotY` must retain their current values in the next state.
2.  **Movement Phase:** When `robotCanMove` is greater than 0, the robot is permitted to move. In this state, each coordinate may either remain unchanged, increase by 1, or decrease by 1 in the next state.

Throughout operation, the coordinates must always remain within the valid range of 0 to 7.

### Interface Specification

Specification name: EscapingGuard

Named domains:
- Dim: Int(0..D)

Environment variables:
- none

System variables:
- robotX: Dim
- robotY: Dim
