

Specification name: EscapingGuard

Named domains:
- Dim: Int(0..D)

Environment variables:
- none

System variables:
- robotX: Dim
- robotY: Dim

The system controls the position of a robot on a two-dimensional grid where both coordinates range from 0 to 7. The system variables `robotX` and `robotY` represent the robot's current horizontal and vertical position, respectively.

Initially, the robot is positioned at `robotX` = 7 and `robotY` = 0.

The robot's movement is subject to a periodic stationary constraint. Every third step, the robot must remain at its current position. During the other steps, the robot may move to an adjacent grid cell or stay put; specifically, each coordinate may increase by 1, decrease by 1, or remain unchanged between steps.

The robot must never occupy the following obstacle positions: (2, 2), (2, 3), (2, 4), or (2, 5).

The robot is required to visit the following three target positions infinitely often: (0, 0), (7, 7), and (0, 7).

Additionally, there is a constraint on the order of visitation for these targets. After the robot visits target (0, 0), it must visit target (7, 7) before it is permitted to visit target (0, 7).
