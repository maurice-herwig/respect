

Specification name: EscapingGuard

Named domains:
- Dim: Int(0..D)

Environment variables:
- none

System variables:
- robotX: Dim
- robotY: Dim

The system controls the robot's position using the variables `robotX` and `robotY`. Both coordinates are integers ranging from 0 to 7. The system must ensure that initially, the robot is positioned such that `robotY` equals 0 and `robotX` equals 7.
