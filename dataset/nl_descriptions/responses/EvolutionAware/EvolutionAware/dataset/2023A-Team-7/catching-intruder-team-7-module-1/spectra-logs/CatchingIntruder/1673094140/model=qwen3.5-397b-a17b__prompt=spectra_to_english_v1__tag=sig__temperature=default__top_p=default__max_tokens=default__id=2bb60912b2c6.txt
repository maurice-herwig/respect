

Specification name: CatchingIntruder

Named domains:
- Dim: Int(0..D)

Environment variables:
- intruderX: Dim
- intruderY: Dim

System variables:
- robotX0: Dim
- robotY0: Dim
- robotX1: Dim
- robotY1: Dim

**Requirements Description**

The system models the movement of two robots and an intruder on a two-dimensional grid. All position coordinates belong to the domain **Dim**, which consists of integers from 0 to 7 (where the constant D is defined as 7).

**Environment Assumptions**
The environment controls the intruder's position variables, `intruderX` and `intruderY`.
*   **Initial Condition:** At the start of the system, the intruder's Y-coordinate (`intruderY`) must be 7.
*   **Movement Constraints:** In every step, the intruder's position must update such that each coordinate changes by at most 1 (it may increase by 1, decrease by 1, or remain unchanged). Furthermore, the intruder cannot move diagonally; at least one of the coordinates (`intruderX` or `intruderY`) must remain unchanged in each step.

**System Guarantees**
The system controls the position variables for two robots: Robot 0 (`robotX0`, `robotY0`) and Robot 1 (`robotX1`, `robotY1`).
*   **Initial Conditions:**
    *   Robot 0 must start at position (0, 0). Specifically, `robotX0` must be 0 and `robotY0` must be 0.
    *   Robot 1 must start at position (7, 0). Specifically, `robotX1` must be 7 and `robotY1` must be 0.
*   **Movement Constraints:** Both robots must adhere to the same movement rules as the intruder. In every step, each robot's X and Y coordinates may change by at most 1. Additionally, diagonal movement is prohibited for both robots; for each robot, at least one coordinate must remain unchanged in each step. All coordinate values must remain within the valid domain of 0 to 7.
