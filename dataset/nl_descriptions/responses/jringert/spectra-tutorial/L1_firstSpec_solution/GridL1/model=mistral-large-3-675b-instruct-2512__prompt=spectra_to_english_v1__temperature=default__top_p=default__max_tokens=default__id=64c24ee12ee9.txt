### **Requirements for the Grid Movement System**

This system controls the movement of a robot on a 5×5 grid (coordinates ranging from 0 to 4 in both the X and Y directions).

**Inputs (Environment-Controlled):**
- The environment provides the robot’s current position on the grid, specified by `robX` (X-coordinate) and `robY` (Y-coordinate), each ranging from 0 to 4.

**Outputs (System-Controlled):**
- The system issues a `move` command at each step, which can be `UP`, `DOWN`, `LEFT`, `RIGHT`, or `STAY`.

**Initial Conditions:**
- At the start, the robot is positioned at the origin: `robX = 0` and `robY = 0`.

**Assumptions on the Environment:**
- The environment ensures that if the system issues an `UP` command, the robot’s Y-coordinate decreases by 1 in the next state (i.e., the robot moves upward as instructed).

**Guarantees Provided by the System:**
- **Boundary Safety:**
  The system ensures the robot never attempts to move outside the grid:
  - If the robot is at the left edge (`robX = 0`), it never issues a `LEFT` command.
  - If the robot is at the right edge (`robX = 4`), it never issues a `RIGHT` command.
  - If the robot is at the bottom (`robY = 0`), it never issues an `UP` command.
  - If the robot is at the top (`robY = 4`), it never issues a `DOWN` command.
