### Requirements Description for Reactive System *GridA1*

#### **Environment and System Variables**
The environment controls the position of a robot on a 21×21 grid, represented by two integer values, `robX` and `robY`, each ranging from 0 to 20.
The system controls a `move` command, which can be one of five actions: `UP`, `DOWN`, `LEFT`, `RIGHT`, or `STAY`.

#### **Assumptions on the Environment**
1. **Initial Condition**: The robot starts at position `(0, 0)`.
2. **Immediate Effect of Moves**: Whenever the system issues a `UP` command, the environment guarantees that in the next state, the robot’s vertical position (`robY`) will decrease by 1. *(No similar guarantees are made for other moves.)*

#### **System Guarantees**
The system must ensure the following constraints hold at all times to prevent invalid moves:
- If the robot is at the left edge of the grid (`robX = 0`), the system must not issue a `LEFT` command.
- If the robot is at the right edge (`robX = 4`), the system must not issue a `RIGHT` command.
- If the robot is at the bottom edge (`robY = 0`), the system must not issue an `UP` command.
- If the robot is at the top edge (`robY = 4`), the system must not issue a `DOWN` command.

*(Note: The grid appears constrained to a 5×5 subregion (0 to 4) for movement safety, despite the environment variable ranges.)*
