

Specification name: GridL1

Environment variables:
- robX: Int(0..4)
- robY: Int(0..4)

System variables:
- move: {UP, DOWN, LEFT, RIGHT, STAY}

The system interacts with an environment that maintains the robot's position on a grid. The environment controls the horizontal and vertical coordinates, `robX` and `robY`, while the system controls the movement command, `move`.

Initially, the environment sets both `robX` and `robY` to 0.

Regarding ongoing behavior, the environment is assumed to respond to the system's movement commands. Specifically, whenever the system issues an `UP` command, the environment ensures that the `robY` coordinate decreases by 1 in the subsequent state.
