

Specification name: GridA3

Named domains:
- Coord: Int(0..5)

Environment variables:
- rob: Coord[2]

System variables:
- move: {UP, DOWN, LEFT, RIGHT, STAY}

This specification describes a reactive system where the system issues movement commands via the variable `move`, and the environment controls the robot's position via the variable `rob`. The variable `rob` consists of two coordinates, `rob[0]` and `rob[1]`, each ranging from 0 to 5. The variable `move` takes a value from the set {UP, DOWN, LEFT, RIGHT, STAY}.

The environment is assumed to update the robot's position coordinates in the next state based on the current movement command issued by the system. Specifically, if the system issues an UP command, the environment must decrease the second coordinate (`rob[1]`) by one while keeping the first coordinate (`rob[0]`) unchanged. If the system issues a DOWN command, the environment must increase the second coordinate (`rob[1]`) by one while keeping the first coordinate (`rob[0]`) unchanged. If the system issues a LEFT command, the environment must decrease the first coordinate (`rob[0]`) by one while keeping the second coordinate (`rob[1]`) unchanged. If the system issues a RIGHT command, the environment must increase the first coordinate (`rob[0]`) by one while keeping the second coordinate (`rob[1]`) unchanged.

The system must satisfy two guarantees regarding the robot's position. First, whenever the robot is at position (0, 0), meaning both `rob[0]` and `rob[1]` are 0, the robot must be at position (5, 5), meaning both `rob[0]` and `rob[1]` are 5, in the immediately following state. Second, the robot must visit position (0, 0) infinitely often throughout the operation of the system.
