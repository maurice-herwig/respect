

Specification name: TrafficA3b

Environment variables:
- carA: boolean
- carB: boolean

System variables:
- greenA: boolean
- greenB: boolean
- emergency: boolean

This specification describes a reactive system managing traffic lights for two intersections, A and B. The environment controls the detection of cars at each intersection, while the system controls the green light signals for each intersection and an emergency status signal.

**Environment Assumptions**
The environment must satisfy the following constraints regarding car presence. If a car is detected at intersection A (`carA` is true) and the light for A is not green (`greenA` is false), the car must remain detected at A in the next step. Similarly, if a car is detected at intersection B (`carB` is true) and the light for B is not green (`greenB` is false), the car must remain detected at B in the next step. Furthermore, whenever the system sets the `emergency` signal to true, the environment must ensure that the car detection status for both intersections (`carA` and `carB`) remains unchanged in the next step. Finally, it is assumed that infinitely often, cars are present at both intersection A and intersection B simultaneously.

**System Guarantees**
The system must ensure that the green light signals for intersection A (`greenA`) and intersection B (`greenB`) are never active at the same time.
