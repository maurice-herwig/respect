

Specification name: TrafficA3a

Environment variables:
- carA: boolean
- carB: boolean

System variables:
- greenA: boolean
- greenB: boolean

This specification describes a traffic light controller interacting with car sensors. The environment controls the input signals `carA` and `carB`, indicating the presence of cars at intersections A and B respectively. The system controls the output signals `greenA` and `greenB`, indicating whether the traffic lights for A and B are green.

The environment is assumed to behave according to the following constraints. First, if a car is present at intersection A (`carA` is true) while the light A is not green (`greenA` is false), the car remains present in the next time step. The same stability condition applies to intersection B: if `carB` is true and `greenB` is false, `carB` remains true in the next step. Additionally, infinitely often, it is not the case that cars are present at both intersections simultaneously; that is, the state where both `carA` and `carB` are true must be false infinitely often.

The system must satisfy the following guarantee. At all times, the lights for A and B must not be green simultaneously; specifically, it is never the case that both `greenA` and `greenB` are true.
