

Specification name: TrafficL4

Environment variables:
- carA: boolean
- carB: boolean

System variables:
- greenA: boolean
- greenB: boolean

The system controls traffic light signals based on car presence sensors. The environment provides inputs indicating whether cars are present at locations A and B, while the system determines whether the traffic lights for A and B are green.

**Environment Assumptions**
The environment is assumed to satisfy the following behavior: whenever a car is detected at location A (`carA` is true), a car must be detected at location B (`carB` is true) within 0 to 3 time steps.

**System Guarantees**
The system must satisfy the following requirements:
1.  **Safety:** The system must never allow both `greenA` and `greenB` to be true simultaneously.
2.  **Liveness:** If a car is present at location A (`carA` is true) while the light for A is not green (`greenA` is false) for 4 consecutive time steps, the system must eventually set `greenA` to true.
