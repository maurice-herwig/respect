The TrafficL4 system manages the traffic lights for two intersections. The system controls the green light status for each intersection, while the environment controls the presence of cars at each intersection.

The environment's behavior is restricted by the following assumptions: 
The environment must eventually trigger a sequence of up to three car appearances at intersection A, but these car appearances can occur at any time.

The system guarantees the following behavior: 
The traffic lights must always be synchronized, meaning that both lights cannot be green at the same time.
If a car is present at intersection A and the green light is not on, then the green light must turn on after at least four time units.
