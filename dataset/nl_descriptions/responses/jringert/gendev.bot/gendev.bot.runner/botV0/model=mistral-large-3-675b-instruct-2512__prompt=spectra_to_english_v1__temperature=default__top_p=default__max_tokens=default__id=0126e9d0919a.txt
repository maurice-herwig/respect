### **Requirements Description for Reactive System: BotV0**

**Environment and System Variables:**
The system controls the movements of two motors, represented by the output variables `leftM` and `rightM`, which can each take one of three commands:
- `FWD` (forward),
- `BWD` (backward),
- `STP` (stop).

**Initial Condition:**
At the very start of operation, the system must ensure that both motors (`leftM` and `rightM`) are in the stopped (`STP`) state.
