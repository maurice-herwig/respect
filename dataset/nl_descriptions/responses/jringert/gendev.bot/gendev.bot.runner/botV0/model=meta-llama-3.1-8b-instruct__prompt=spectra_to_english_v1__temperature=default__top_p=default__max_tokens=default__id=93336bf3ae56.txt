The BotV0 system is a reactive system that interacts with its environment. The environment controls the inputs to the system, while the system controls the outputs.

The environment provides two inputs: leftMotor and rightMotor, each of which can be commanded to move forward, backward, or stop.

The system's behavior is governed by the following assumptions about the environment: at the initial state, both the left motor and the right motor must be stopped.

The system's guarantees include the following requirements: at the initial state, both the left motor and the right motor must be stopped. This ensures that the system starts in a safe state.
