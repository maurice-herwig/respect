The system, in turn, controls six buckets, denoted as `buckets[0]` through `buckets[5]`, each capable of holding up to `B` (14) units of water, and a variable `bucketToEmpty` that indicates which bucket to prioritize emptying, with a value ranging from 0 to `N-1` (5).

Otherwise, the next state of `buckets[i]` will be the current state of `buckets[i]` plus the next state of `waterFills[i]`. This ensures that the system maintains a specific relationship between the water fills and the buckets based on the `bucketToEmpty` variable.
