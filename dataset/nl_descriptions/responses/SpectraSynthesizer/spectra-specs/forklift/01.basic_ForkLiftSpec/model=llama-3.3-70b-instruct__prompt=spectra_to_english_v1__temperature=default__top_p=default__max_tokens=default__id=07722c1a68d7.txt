- Whenever the distance is far, the system must not issue the "lift" command.
- Whenever the distance is close, the system must not issue the "go" command.
- The system can only issue the "drop" command if it has previously issued the "lift" command and has not issued the "drop" command since then.
- The system must issue the "drop" command infinitely often.
- The system must issue the "go" command infinitely often.
