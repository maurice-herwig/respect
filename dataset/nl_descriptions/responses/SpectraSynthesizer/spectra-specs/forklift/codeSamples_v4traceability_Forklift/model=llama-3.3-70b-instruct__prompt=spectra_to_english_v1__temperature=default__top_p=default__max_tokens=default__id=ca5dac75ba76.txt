The Forklift system is a reactive system that interacts with its environment. The environment controls two inputs: an obstacle sensor that can be either BLOCKED or CLEAR, and an emergency stop signal emgOff. The system controls two outputs: the left motor (lMot) and the right motor (rMot), each of which can be in one of three states: STOP, FWD (forward), or BWD (backward).

The system must always ensure that both motors are stopped initially. The system must also guarantee that if the obstacle is BLOCKED, it will not move both motors forward simultaneously. Additionally, when the emergency stop signal emgOff is active, the system must stop both motors.

The system must also ensure that it will infinitely often be in a state where either both motors are moving forward or the emergency stop signal is active.

The environment is assumed to behave in such a way that if both motors are stopped, the obstacle will remain in its current state. The environment is also assumed to respond to the system's backward motion or stopping of both motors by eventually clearing the obstacle or stopping both motors, unless it is already in a responsive state.

In general, the environment's response to certain triggers, such as the system's backward motion, is defined as eventually responding to the trigger, and then remaining in the responsive state until the trigger is deactivated. The environment will infinitely often respond to such triggers.
