The Forklift system is a reactive system that interacts with its environment. The environment controls two inputs: an obstacle sensor that indicates whether the path is blocked or clear, and an emergency stop signal. The system controls two outputs: the left motor and the right motor, each of which can be in one of three states: stop, forward, or backward.

The environment is assumed to behave in certain ways. Specifically, when the system's motors are both stopped, the obstacle sensor's state does not change. Additionally, the environment is assumed to respond to the system's motors moving backward by either clearing the obstacle or stopping the motors.

The system must guarantee certain behaviors. Initially, and at all times, both motors must be stopped. If the obstacle sensor indicates that the path is blocked, the system must not move both motors forward at the same time. If the emergency stop signal is active, the system must stop both motors. Furthermore, the system must ensure that either both motors move forward or the emergency stop signal is active infinitely often.

In terms of liveness, the system must periodically move forward or enter an emergency stop state. The system's motors are also expected to respond to certain conditions: when the motors move backward, the system should eventually respond by either clearing the obstacle or stopping the motors. This response is considered to have occurred if the obstacle is cleared or the motors are stopped, and once a response has occurred, it remains so until the motors move backward again.
