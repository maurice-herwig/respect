The Elevator system is a reactive system that interacts with its environment. The environment controls the current floor, which can be LOWER, MIDDLE, UPPER, or NONE. The system controls the elevator's motor direction, which can be set to move forward (FWD), backward (BWD), or stop (STOP).

The environment is assumed to always have a valid floor setting when the elevator is stopped, meaning the floor will not be NONE when the elevator's motor is in the STOP state.

The system guarantees that it will start in a stopped state, with the elevator's motor set to STOP. Additionally, the system aims to continuously move the elevator forward (FWD) over time.

The system also guarantees that it will change direction at specific floors: when the current floor is LOWER, the elevator will move forward (FWD), and when the current floor is UPPER, the elevator will move backward (BWD). These direction changes will occur infinitely often, as the system repeatedly visits these floors.

Overall, the Elevator system is designed to operate in a cyclic manner, moving between floors and changing direction as needed, while ensuring safe operation by starting from a stopped state and responding to the environment's floor settings.
