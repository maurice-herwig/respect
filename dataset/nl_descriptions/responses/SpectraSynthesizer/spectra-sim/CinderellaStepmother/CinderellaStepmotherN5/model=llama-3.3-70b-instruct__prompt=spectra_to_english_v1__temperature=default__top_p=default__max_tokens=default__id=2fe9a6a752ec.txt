The system, Cinderella, interacts with its environment through a set of variables. The environment controls the amount of units to fill in each of five units, represented by the variable `unitsToFill`. The system controls two variables: `buckets`, which represents the amount of units in each of five buckets, and `firstToEmpty`, which represents the index of the first bucket to empty.

The environment is assumed to always provide a total of `A` (5) units to fill across all five units.

Initially, all buckets are empty, with each containing 0 units.

The system guarantees that it will update the buckets based on the units to fill provided by the environment. Specifically, for buckets that are in the adjacent set of buckets to empty (defined as the `C` (2) buckets starting from the `firstToEmpty` index, wrapping around to the start if necessary), the system will update the bucket to match the units to fill provided by the environment in the next step. For buckets that are not in this adjacent set, the system will add the units to fill provided by the environment in the next step to the current amount in the bucket.
