

Specification name: TrafficLightNonWellSep

Environment variables:
- carA: boolean
- carB: boolean

System variables:
- greenA: boolean
- greenB: boolean
- maintenance: boolean

**Requirements Description**

This specification defines a traffic light controller system that interacts with an environment detecting vehicle presence on two roads, A and B.

**Environment Assumptions**
The environment controls the inputs `carA` and `carB`. Initially, no vehicles are present on either road; both `carA` and `carB` are false. Throughout operation, vehicles must appear infinitely often on both road A and road B. Additionally, if the system activates `maintenance`, the environment ensures that `carA` is false in the immediately following step.

**System Guarantees**
The system controls the outputs `greenA`, `greenB`, and `maintenance`. Initially, `maintenance` is inactive. The system must ensure safety by never allowing `greenA` and `greenB` to be true simultaneously. Regarding liveness, the system must ensure that infinitely often, `carA` is present while `greenA` is active. Similarly, the system must ensure that infinitely often, `carB` is present while `greenB` is active.
